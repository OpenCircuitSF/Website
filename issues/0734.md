## Resolution notes

> 🟢 Resolved 2026-11-19 — a public, read-only REST API at `/api/public/v1/` serves `#0729`'s six public operations from the same registry as `/mcp`, with a generated OpenAPI 3.1 document, CORS `*` on these routes only, and no auth; the rate-limit criterion moved to `#0730`.

## Description

The user decided on 2026-11-19 that the new Docs section (`#0735`) should document a **public, read-only REST API** that needs no key. That API serves the same data as the public MCP server (`#0729`). The only REST API today is `/api/v1` (`#0675`), and it needs an admin key.

**REST and MCP must not drift.** The admin side solved this by building both adapters over one operation registry (`internal/api`, `#0675`/`#0679`). The public side should do the same: one set of public read operations, with the MCP adapter and the REST adapter both built from it. This is a separate registry instance from the admin one, so `#0729`'s rule that the admin and public servers stay separate still holds.

## Acceptance criteria

- [ ] Read-only endpoints under **`/api/public/v1/`**, one for each `#0729` tool:
  - `GET events` (upcoming, with `limit`/`after`/`before`);
  - `GET events/search` (`query`, `from`, `to`, `include_past`, `limit`);
  - `GET events/{id-or-slug}`;
  - `GET newsletter`;
  - `GET newsletter/{id-or-slug}`;
  - `GET about`.

  They have the same fields, caps, time format and URLs as the MCP tools. *(Plan, accepted by the orchestrator 2026-11-19: the path parameter is `{slug}` and `id == slug`; an event slugged `search` is shadowed by `events/search` and documented.)*
- [ ] The REST routes and the public MCP tools are generated from one definition. A test asserts that every public MCP tool has a REST route and every route has a tool, with matching schemas. If `#0729` has already shipped hand-written tools, this issue moves them onto the shared definition.
- [ ] No auth: an `Authorization` header is ignored, there is never a 401, and there is no OAuth metadata. These are `GET`-only. Any other method gets 405. *(Plan: the 405 is JSON and carries CORS; `OPTIONS` is a 204 preflight.)*
- [ ] Unknown, draft and unpublished items return the same 404 body (test). The data-exposure tests from `#0729` also cover every REST route.
- [ ] `GET /api/public/v1/openapi.json` is generated from the shared definition. A guard ties it to the routes. *(Plan: generated at startup, not checked in; `TestOpenAPIMatchesRegistry` compares it to the registry.)*
- [ ] CORS `Access-Control-Allow-Origin: *` on these routes only, so browser apps elsewhere can read them. The admin `/api/v1` CORS behaviour is unchanged (test).
- [ ] `#0730`'s per-IP rate limit, logging and 60 s list cache apply. REST and MCP share one per-IP budget. *(Moved to `#0730`'s verification (orchestrator, 2026-11-19): `#0734` landed first. `publicapi.NewHTTPRouter(reg, baseURL, limit)` takes the limiter as an explicit third argument, typed `func(http.Handler) http.Handler` for now and passed `nil` in `main.go` beside a `#0730` comment; `#0730` swaps the type for `*publicapi.Limiter`, a one-line change. Logging and the cache go in `Registry.Invoke`, which this adapter already calls. `publicapi.writeJSONError` is the package's error writer, Retry-After included, for `#0730` to reuse.)*
- [ ] `Cache-Control` suits public data. Responses are gzip-compressible through `#0716`. *(Plan: successes `public, max-age=60`, errors `no-store`, the OpenAPI document `public, max-age=300`.)*
- [ ] Route-table wiring tests. `docs/api.md` gets a short section separating the public API from the admin `/api/v1`.

### Files and changes

1. **`internal/api/public.go`** (the file `#0729` created). Add:
   - `func BindURL(op Operation, r *http.Request) (any, *Error) { return bind(op, nil, r.PathValue, r.URL.Query()) }`. Its doc says: the REST binder for a GET operation, so the public adapter binds by exactly the same rules as `/api/v1/`.
   - `type URLParam struct { Name, JSONName string; InPath bool }`.
   - `func (op Operation) URLParams() []URLParam`, built from `op.fields` where `source != fromBody`, in field order.

2. **`internal/publicapi/http.go` (new).**
   - `func NewHTTPRouter(reg *Registry, baseURL string) http.Handler`. Freeze `reg` and build the OpenAPI bytes once, panicking on error. Then build an inner `http.ServeMux`:
     - `GET OpenAPIPath` → the document, `Content-Type: application/json`, `Cache-Control: public, max-age=300`.
     - For each op, `GET <op.Path>` → `serve(reg, op)`.
     - The catch-all `Prefix` → JSON **405** (`Allow: GET, HEAD, OPTIONS`) when the path matches a known route under some other method (probe with `GET`, as `api.NewHTTPRouter` does), otherwise JSON **404** `{"error":{"code":"not_found","message":"no such API endpoint"}}`.
   - Wrap the whole inner mux in `cors(next)`:
     - It **always** sets `Access-Control-Allow-Origin: *`.
     - On `OPTIONS` it answers **204** with `Access-Control-Allow-Methods: GET, HEAD, OPTIONS`, `Access-Control-Allow-Headers: *` and `Access-Control-Max-Age: 86400`, and returns.
     - There is no `Allow-Credentials`, and no cookie is read.
   - `serve(reg, op)`:
     - `in, e := api.BindURL(op.Operation, r)`.
     - Then `out, err := reg.Invoke(r.Context(), op, in)`.
     - On error, write `api.AsError(op.Name, err)` as the `api.ErrorBody` envelope with `Cache-Control: no-store`.
     - On success, write 200, `Content-Type: application/json`, `Cache-Control: public, max-age=60`, and the body `json.NewEncoder(w).Encode(out)`.
   - **Never** read `Authorization` or call anything from `middleware`'s token family. `#0729`'s import guard already enforces that for this package.
   - Give `writeJSONError(w, *api.Error)` a local copy of `api`'s `writeError`, including `Retry-After`, because `#0730` returns 429s.
   - `func Mount(mux *http.ServeMux, h http.Handler)` registers `"<METHOD> /api/public/v1/"` for `GET`, `OPTIONS`, `POST`, `PUT`, `PATCH` and `DELETE`, so every method reaches the router's JSON and CORS answer, not the mux's plain 405 or the SPA. Copy the comment from `api.Mount`.

3. **`internal/publicapi/openapi.go` (new).** `buildOpenAPI(reg, baseURL) ([]byte, error)`, modelled on `internal/api/openapi.go`, with deterministic `json.MarshalIndent` maps.
   - `openapi: "3.1.0"`.
   - `info`: title `Open Circuit SF public API`, `version` from `reg.Version()`, and a description: `Read-only public data about Open Circuit SF's events and newsletter issues. No key or account; an Authorization header is ignored. Times are RFC 3339 with an offset in America/Los_Angeles. limit defaults to 10 and is capped at 50; query is cut to 200 characters. Every error is {"error":{"code","message","fields"}}. The same operations are MCP tools at https://www.opencircuitsf.com/mcp.`
   - `servers: [{url: TrimRight(baseURL, "/")}]`, and top-level `security: []`, with **no** `securitySchemes`.
   - Per op:
     - `operationId` = `op.Name`, plus `x-mcp-tool: op.Name`
     - `summary`, and `description: op.Describe()`
     - `parameters` from `op.URLParams()`, with each schema from `op.InputSchema().Properties[JSONName]`, `in: path` with `required: true` for `InPath`, otherwise `in: query`
     - `responses`: `200` (the `op.OutputSchema()`), `400` and `500`, plus `404` when the path has `{`. All error responses `$ref` `#/components/schemas/Error` (`jsonschema.ForType(api.ErrorBody)`).
   - Add `429` only once `#0730` has landed (it returns 429 then). If it has, include it with `Retry-After`. Do not document a 401 or 403 anywhere.
