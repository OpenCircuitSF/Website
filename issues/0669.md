## Description

This came up in `#0666`'s review. `web/src/lib/topics/TargetPicker.svelte` and the choice between series and across in `CurrentDemo.svelte` are marked up as radio groups, but each option is its own Tab stop and the arrow keys do nothing.

They work, but they don't follow the ARIA radio-group pattern:

- the group is one Tab stop, using a roving `tabindex`;
- the arrow keys move the selection.

Audit the other guide demos for the same gap. That includes `BaudDemo`, the topic demos added in `#0667`, and anything else that uses `role="radio"`. Then fix them in one shared helper.
