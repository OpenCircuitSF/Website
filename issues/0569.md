## Description

Brennan, 2026-10-17, on the deployed `#0568` page (workshop 6, 21 links
created, 15 posts drafted):

> It is a list of all of the links but what is it going to post? ... Tell me
> how this is supposed to be useful.

On the page, the 21-row links table fills three screens. The post text is
visible only after clicking a small grid cell labelled "Link ready" or "Ready
to post". Neither label says what will be posted or when.

## Acceptance criteria

SPA only. Reuse the existing API: the workshop outreach view already returns
the posts with body, status, `scheduled_at` and `posted_at`, and the
composer's endpoints already exist. No Go or migration change unless one is
strictly required. If one is, stop and report instead.

- [ ] **Posts list replaces the grid** on the workshop outreach page,
      `OutreachWorkshop.svelte`. There is one card per channel × wave, grouped
      by wave in order (Announce, Reminder, Last call). Each card shows:
      - channel and wave
      - **the full post text**, as it will be posted, with the short link
        shown
      - a plain status line:
        - "Posted <date/time> · view post" when posted, linking to the
          remote URL if one is stored
        - "Posts automatically <weekday time>" when scheduled
        - "Not scheduled" for an automatic-channel draft
        - "Post by hand: copy and paste" for a manual channel
        - "Failed: <fixed reason>" with Retry when failed
        - "Not drafted" with a Draft button when there is no post
      - the actions:
        - automatic channels: **Edit**, **Post now**, and
          **Schedule…**/**Unschedule**
        - manual channels: **Edit**, **Copy text**, **Mark posted**

      **Edit** opens the existing `OutreachComposer` inline in that card.
      Character counts and over-limit warnings stay.
- [ ] **Order on the page:**
      1. header
      2. a one-line summary, for example "15 posts drafted · 0 scheduled ·
         0 posted · 0 clicks"
      3. the bulk actions (Draft all, Schedule all), with a one-sentence
         explanation each
      4. the posts list
      5. **"Tracked links (N)", collapsed by default** (a `<details>`
         element holding the existing links table and Create missing links)
      6. results
- [ ] The workshop editor's own outreach summary is unchanged. The
      `OutreachPanel` grid may remain for other callers or be removed if
      nothing else uses it; keep its tests green or update them to match.
- [ ] Destructive or outward actions keep their confirmations. Post now
      asks "Post this to Bluesky now?".
- [ ] jsdom tests:
      - cards render the body text and each status line variant
      - Edit opens the composer
      - the links table is collapsed by default
      - manual channels show Copy and not Post now

      Verified with `ISSUE=0569 scripts/check.sh web` (plus Go only if Go was
      touched). No browser on the host; state that the evidence is jsdom.
