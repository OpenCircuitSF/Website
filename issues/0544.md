## Description

Phase 1 of the Outreach design: from a published workshop, an admin starts
outreach (which ensures the workshop's ShortLinks campaign), drafts one post
per channel × wave, **Prepares** a draft (creates its tagged short link and
puts the real short URL in the text), copies content for manual channels, and
marks posts as posted. Automatic Bluesky/Mastodon posting is `#0545`.

Design doc: https://claude.ai/artifact/DzCWVhfcqJbc9uSfWLVfhG (sections
"ShortLinks REST API", "Data model on this site", "Admin workflow proposals").
Mockups: https://claude.ai/artifact/4Ckwb6QmWYyfYyAEszAKa2 (artboards 1 and 2).

### Decisions (so the implementer does not have to make them)

1. **No custom link key.** ShortLinks `docs/links.md` §3: *custom aliases are
   never deduplicated*. Only a generated-key `POST /api/links` de-duplicates on
   `destination_url`, which is the whole retry-safety story. `CreateLinkRequest.Key`
   stays empty; the key ShortLinks returns is stored.
2. **UTMs are baked into `destination_url` AND sent as discrete fields**, the
   same as ShortLinks' own UTM builder (`docs/utm.md`, "bake into
   `destination_url` AND store discretely"). The baked query makes every
   channel × wave destination unique, so dedup can never collapse two posts
   onto one link.
3. **The short URL is built, not returned.** `shortlinks.Link` has only `Key`;
   the display host is `Me().BaseURL`. The handler fetches it once and
   caches it on success (mutex-guarded field; a failure is not cached).
   `short_url = strings.TrimRight(base, "/") + "/" + key`.
4. **Draft text is generated server-side in Go**, because Prepare must put the
   real short URL into the stored body, atomically. The body carries the
   literal token `{link}` until Prepare substitutes it.
5. **Statuses used in this issue:** `draft`, `manual`, `posted`. The
   others (`scheduled`, `queued`, `failed`) are in the CHECK constraint for
   `#0545` but nothing here writes them. "Prepared" is not a status — it is
   `short_url IS NOT NULL`.
6. **`ON DELETE CASCADE`** from `workshops` → `outreach` → `outreach_posts`.
   The ShortLinks campaign and links survive a workshop delete; that is
   acceptable (they are inert) and keeps `workshops.Store.Delete` untouched.
7. **Channel and wave lists live only in Go** and are shipped to the SPA in
   the GET response. No TypeScript copy, so no parity guard is needed. No DB
   CHECK on `channel`/`wave` either (adding a channel must not need a
   migration); the handler validates them.

### Step 2 — `internal/outreach` (new package; pure code + store)

`channels.go` — fixed lists, in display order:

| name | label | utm_source | utm_medium | char_limit | automatic |
|---|---|---|---|---|---|
| bluesky | Bluesky | bluesky | social | 300 | true |
| mastodon | Mastodon | mastodon | social | 500 | true |
| instagram | Instagram | instagram | social | 0 | false |
| tiktok | TikTok | tiktok | video | 0 | false |
| youtube | YouTube | youtube | video | 0 | false |

`char_limit` 0 means no limit enforced. Waves: `announce` (label "Announce",
no offset), `reminder` ("Reminder", 7 days before `starts_at`), `last-call`
("Last call", 1 day before). Exported: `type Channel struct`, `type Wave
struct{ Name, Label string; DaysBefore int }`, `Channels() []Channel`,
`Waves() []Wave`, `ChannelByName(string) (Channel, bool)`,
`WaveByName(string) (Wave, bool)`, `const LinkToken = "{link}"`.

`templates.go`:
- `type Facts struct{ Slug, Title string; StartsAt *time.Time; LocationName, LocationAddress *string }`
  — built by the handler from `workshops.Workshop`.
- `DestinationURL(siteBaseURL string, f Facts, ch Channel, w Wave) string`
  → `{base}/workshops/{slug}?` + `url.Values{utm_source, utm_medium,
  utm_campaign=slug, utm_content=wave}.Encode()` (sorted keys — deterministic,
  which dedup depends on). Empty base yields a relative URL, as
  `AdminWorkshopsHandler` does.
- `Draft(ch Channel, w Wave, f Facts) string`. Date as `Mon, Jan 2 · 3:04 PM`
  in `America/Los_Angeles` (load once; import `time/tzdata` as
  `internal/seo/fallback.go` does); nil `StartsAt` → `Date TBA`; place =
  `LocationName`, else `Location TBA`. Lead line per wave: announce `New
  workshop: {title}`, reminder `One week to go: {title}`, last-call
  `Tomorrow: {title}`. Then `{date} · {place}`, a blank line, then a call to
  action line ending in `{link}`: `Details and signup: {link}` for
  bluesky/mastodon/youtube/tiktok; instagram uses `Link in bio — {link}` (IG
  captions are not clickable, the URL is still shown for the bio).
- `Fingerprint(f Facts) string` — hex SHA-256 of title, `StartsAt` in UTC
  RFC 3339 (empty if nil), location name, location address, joined with
  `\x1f`. Summary/body edits never make a draft stale.

`store.go` (all SQL for both tables; follow `internal/crt/store.go`'s shape):
- Types `Outreach{ID, WorkshopID int64; CampaignSlug string; CreatedAt time.Time; UpdatedAt, ArchivedAt *time.Time}`,
  `Post{ID, OutreachID int64; Channel, Wave, Body, Status, SourceFingerprint string; ShortLinkKey, ShortURL, RemoteID, RemoteURL, LastError *string; ScheduledAt, PostedAt, UpdatedAt *time.Time; CreatedAt time.Time}`,
  `Summary{OutreachID, WorkshopID int64; WorkshopSlug, WorkshopTitle, WorkshopStatus, CampaignSlug string; StartsAt *time.Time; Counts map[string]int; CreatedAt time.Time}`.
- Sentinels: `ErrNotFound`, `ErrPostExists` (unique violation on the slot),
  `ErrPostLocked` (status is `posted`), `ErrNotPrepared`.
- Methods: `GetByWorkshop(ctx, workshopID)`, `Create(ctx, workshopID, slug) (Outreach, bool, error)`
  — `INSERT … ON CONFLICT (workshop_id) DO NOTHING RETURNING …`, no row →
  select the existing one, `created=false`; `ListSummaries(ctx)` (join
  `workshops`, count posts by status, newest `starts_at` first);
  `ListPosts(ctx, outreachID)`; `GetPost(ctx, id)`;
  `CreatePost(ctx, outreachID, channel, wave, body, fingerprint)`;
  `UpdatePostBody(ctx, id, body string, fingerprint *string)` (nil leaves the
  fingerprint alone — a hand edit; non-nil is a regenerate);
  `SetPrepared(ctx, id, key, shortURL, status string)`;
  `MarkPosted(ctx, id, remoteURL *string, now time.Time)`; `DeletePost(ctx, id)`.
- Every state-guarded write is a conditional `UPDATE`/`DELETE … WHERE id=$1 AND
  status <> 'posted'` (plus `short_url IS NOT NULL` for MarkPosted); on zero
  rows, re-`SELECT` to classify into `ErrNotFound` / `ErrPostLocked` /
  `ErrNotPrepared`. All set `updated_at = now()`.
- `SetPrepared` does the substitution in SQL so it is atomic with the write:
  `body = CASE WHEN position('{link}' in body) > 0 THEN replace(body, '{link}', $3)
  ELSE body || E'\n\n' || $3 END`, `WHERE id=$1 AND short_link_key IS NULL AND
  status <> 'posted'`. Zero rows and the row is already prepared → return it
  unchanged (idempotent; two racing Prepares get the same key from dedup).

### Step 4 — handler `internal/handlers/admin_outreach.go`

```go
type outreachStore interface { /* the store methods above */ }
type outreachWorkshopReader interface {
    GetByID(ctx context.Context, id int64) (workshops.Workshop, error)
}
type shortLinker interface {
    Enabled() bool   // nil *shortlinks.Client satisfies and reports false
    Me(ctx context.Context) (*shortlinks.Me, error)
    EnsureCampaign(ctx context.Context, slug, name string, req shortlinks.CreateCampaignRequest) (*shortlinks.Campaign, error)
    CreateLink(ctx context.Context, req shortlinks.CreateLinkRequest) (*shortlinks.Link, error)
}
func NewAdminOutreachHandler(store outreachStore, ws outreachWorkshopReader,
    links shortLinker, auditor *audit.Logger, baseURL string) *AdminOutreachHandler
```

Always guard with `links != nil && links.Enabled()` (a nil `*Client` inside
the interface is non-nil). Routes (all admin-only):

| Method | Path | Behaviour |
|---|---|---|
| GET | `/admin/outreach` | `{"outreach": [summary…]}` for the top-level tab |
| GET | `/admin/workshops/{id}/outreach` | always 200 (404 only for an unknown workshop): the panel view below |
| POST | `/admin/workshops/{id}/outreach` | start. 503 not configured; 409 unless `status == published`; existing row → 200, else EnsureCampaign then `Create` → 201 + audit |
| POST | `/admin/outreach/{id}/posts` | body `{"channel","wave","body"?}`; omitted/empty body → `Draft(...)`. 400 unknown channel/wave or body > 5000 bytes; 409 `ErrPostExists`; 201 |
| PATCH | `/admin/outreach-posts/{id}` | body exactly one of `{"body": "…"}` or `{"regenerate": true}`; 400 for neither/both; 409 locked. Regenerate = `Draft(...)` then, if prepared, replace `{link}` with `short_url` in Go before saving, and store the current fingerprint |
| POST | `/admin/outreach-posts/{id}/prepare` | 503 not configured; 409 workshop not published; already prepared → 200 unchanged, **no ShortLinks call**; else CreateLink → `SetPrepared` (status `manual` for non-automatic channels, else stays `draft`) → 200 + audit |
| POST | `/admin/outreach-posts/{id}/posted` | body `{"remote_url"?}`; must be absolute http(s), ≤ 2048 chars, else 400; 409 not prepared or already posted; 200 + audit |
| DELETE | `/admin/outreach-posts/{id}` | 409 if posted; 204 + audit |

Use `/admin/outreach-posts/…`, not `/admin/outreach/posts/…`: the latter
overlaps `/admin/outreach/{id}/posts` and Go 1.22's mux panics at
registration on two equally specific overlapping patterns.

Prepare's `CreateLinkRequest`: `DestinationURL` = `DestinationURL(...)`,
`CampaignSlug` = stored slug, `UTMSource/UTMMedium/UTMCampaign/UTMContent`
as baked, `Placement` = channel name, `Title` = `"{workshop title} — {channel label} {wave label}"`,
`Key` empty. Start's `EnsureCampaign(slug=workshop slug, name=workshop slug,
req{Description: title, StartsAt/EndsAt from the workshop (RFC 3339, omitted if nil),
DefaultUTMCampaign: slug})`; store the **returned** `Campaign.Slug`.

ShortLinks error mapping (never echo the upstream error body or token):
`ErrUnavailable` → 503; `ErrRateLimited` → 429 with the upstream
`Retry-After` if exposed; everything else → 502 `{"error":"ShortLinks request failed"}`,
logged server-side with the error (the client already redacts the token).

JSON views (snake_case, timestamps RFC 3339 UTC, nullables as `null`):

```
post: {id, outreach_id, channel, wave, body, status, prepared, stale,
       short_link_key, short_url, destination_url,
       utm: {source, medium, campaign, content},
       scheduled_at, posted_at, remote_url, last_error, created_at, updated_at}
panel: {available, unavailable_reason,   // "", "shortlinks_not_configured", "workshop_not_published"
        workshop: {id, slug, title, status, starts_at},
        outreach: null | {id, workshop_id, campaign_slug, created_at},
        channels: [{name, label, utm_source, utm_medium, char_limit, automatic}],
        waves: [{name, label, suggested_at}],   // starts_at minus DaysBefore; null for announce or nil starts_at
        posts: [post…]}
```

`stale` = status ≠ `posted` && `source_fingerprint != Fingerprint(current facts)`.
`destination_url`/`utm` are computed for every post (prepared or not) so the
SPA builds no URLs itself.

Non-blocking findings (recommended follow-ups, not filed; the orchestrator
allocates numbers):

1. **The audit-on-winner check in Prepare does not hold under the race it
   targets.** Two racing Prepares send an identical generated-key request.
   ShortLinks de-duplicates it, so both calls get the **same** key. The
   losing call's `SetPrepared` returns the winner's row, and the check
   `*updated.ShortLinkKey == link.Key` is then true for it too, so the race
   writes two `outreach_post.prepared` rows. The code comment claims only
   the winner audits. Remedy: have `Store.SetPrepared` return
   `(Post, bool, error)`, with the bool true only when its `UPDATE` touched
   a row. The handler should audit only on true. Add a store assertion that
   a second call reports false. The cost today is a duplicate audit row on a
   double-click race, with no data loss. A natural fit for `#0545`, which
   edits this handler anyway.
2. `shortLinksBase` holds the handler mutex across the `Me()` network call,

   This is harmless at admin scale. Note it only if `#0545`'s worker starts
   calling Prepare.
