## Description

Phase 1 of the Outreach design: from a published workshop, an admin starts
outreach (which ensures the workshop's ShortLinks campaign), drafts one post
per channel × wave, **Prepares** a draft (creates its tagged short link and
puts the real short URL in the text), copies content for manual channels, and
marks posts as posted. Automatic Bluesky/Mastodon posting is `#0545`.

Design doc: https://claude.ai/artifact/DzCWVhfcqJbc9uSfWLVfhG (sections
"ShortLinks REST API", "Data model on this site", "Admin workflow proposals").
Mockups: https://claude.ai/artifact/4Ckwb6QmWYyfYyAEszAKa2 (artboards 1 and 2).

## Acceptance criteria

- [ ] New migrations (next numbers after `000030`) for `outreach` (one per workshop, `shortlinks_campaign_slug`, timestamps, `archived_at`) and `outreach_posts` (`channel`, `wave`, `body`, `short_link_key`, `short_url`, `status` ∈ draft/scheduled/queued/posted/failed/manual, `scheduled_at`, `posted_at`, `remote_id`, `remote_url`, `last_error`, unique (outreach, channel, wave)). SQL lives in a new store package that owns the tables.
- [ ] Fixed channel list in code: name, `utm_source`, `utm_medium`, character limit, automatic vs manual — bluesky (social, 300, auto), mastodon (social, 500, auto), instagram (social, manual), tiktok (video, manual), youtube (video, manual). Waves: announce, reminder (7 days before), last-call (1 day before).
- [ ] UTM scheme exactly as the design: `utm_campaign`=workshop slug, `utm_source`=channel, `utm_medium`=channel kind, `utm_content`=wave. Destination = the workshop's public URL.
- [ ] Admin API (behind the existing admin auth): start outreach for a workshop (only published, not canceled), get outreach + posts, create/update a draft, prepare (create link via `#0543`'s client; idempotent), mark posted (with optional post URL), delete a draft. Each mutation writes an audit row with new audit actions.
- [ ] Draft text generated from a per-channel template using title, date/time, place and short URL; regenerate offered when the workshop's date/place changes after drafting (stale flag).
- [ ] UI: an **Outreach** panel in `WorkshopEditor.svelte` (channels × waves grid with status, as artboard 1) and a composer (artboard 2: text with exact character count against the channel limit, tracked-link box with UTM chips, **Copy content** and **Mark posted** for manual channels). Decision logic in `web/src/lib/outreach.ts`, unit-tested; components stay thin.
- [ ] A top-level **Outreach** admin tab exists (routing via `adminRouter.ts`), listing workshops with outreach; results content arrives in `#0546`.
- [ ] Outreach is unavailable (panel explains why) when ShortLinks is not configured; routes are omitted under `STORAGE=json` like the mailing routes.
- [ ] Go handler/store tests (DB-backed) and web tests; verified with `ISSUE=0544 scripts/check.sh`.
