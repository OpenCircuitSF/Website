## Description

`#0194` committed the 34-case shape matrix precisely so three successive passes
would stop rebuilding and deleting the same evidence. Its own phase-3 review
noticed the issue's Part 1 has the identical problem, untouched.

**Nothing in the tree asserts that the Go walk reaches every non-test `.go`
file.** The 95-collected-equals-95-on-disk measurement has now been derived by
scratch probe and thrown away by `#0181`'s pass-2 review, `#0187`'s
implementation, `#0187`'s review, `#0194`'s implementation, and `#0194`'s
review — five times.

It matters more here than for the matrix, because that invariant is **the only
thing that would ever detect `#0194`'s name-based `SkipDir` swallowing a real
directory.** `skipVendoredDirNames` matches any directory called `node_modules`
or `dist` at any depth. The tree has exactly one of each today, both genuinely
vendored, and the doc comment states the choice — but if someone adds
`internal/dist/` the walk silently stops covering it, and every guard built on
that walk quietly narrows with no test failing.

A dozen-line committed test closes both halves: it pins the invariant and makes
the skip's bluntness detectable.

## Acceptance criteria

- [ ] A committed test asserts the shipped walk collects exactly the set of non-test `.go` files on disk under the three roots, set-identical in both directions
- [ ] It runs against the shipped `scanDirForCitations` (or its collection step), not a replica of the walk predicate — see `#0197` on this tracker's replica history
- [ ] Adding a non-test `.go` file under a directory the skip swallows makes the test fail — demonstrated by planting one under a new `internal/dist/`, then removing it
- [ ] Adding an ordinary non-test `.go` file anywhere in the three roots does **not** fail it
- [ ] The test's failure message names the files present-but-uncollected and collected-but-absent, so the direction of the drift is obvious
- [ ] `#0194`'s three-way skip proof still holds, and `#0187`'s 34-case matrix still passes
- [ ] `ISSUE=0200 scripts/check.sh go ./internal/...` passes with zero skips

## Notes

Reported by `#0194`'s phase-3 review under `CLAUDE.md` §9.

The review instrumented the shipped `scanDirForCitations` rather than
re-implementing its predicate, and measured 95 collected, no duplicates, against
95 from `find` — and 95 again excluding `node_modules`/`dist`. That
instrumentation is the test, nearly written.

A second, smaller point from the same review, worth folding in only if it is
cheap: two of the matrix's seven "acceptable misses" (`docs` as prose,
`docs.google.com`) are arguably **boundary checks** — strings that were never
citations at all — which is why their notes read thinner than the other five.
The matrix is faithful to `#0187`'s grouping and should stay that way unless
regrouping is a deliberate decision, so do not silently recategorise them.

Also noted there, not worth its own issue: `[further-shape] {#if} block test
expression` survives a fully broken fragment walk, because its fixture also puts
the citation in `<script>`. Still a valid catch assertion — just not an
isolating one.
