## Description

Delete the Svelte views and TypeScript helpers that manage short links, campaigns, and click analytics. The passkey views and UI primitives stay.

## Acceptance criteria

- [ ] Deleted views: `Dashboard.svelte`, `LinkDetail.svelte`, `CampaignsList.svelte`, `CampaignDetail.svelte`
- [ ] Deleted lib modules: `links.ts`, `utm.ts`, `charts.ts`, `campaigns.ts`, `linkDetail.ts`, `utmFieldGuide.ts` and their tests
- [ ] Deleted components: `BatchCreateLinks.svelte`, `ClicksChart.svelte`, `CampaignClicksChart.svelte`, `UTMBarChart.svelte`, `UtmField.svelte`, `UtmConventions.svelte`
- [ ] Retained lib modules: `webauthn.ts`, `api.ts`, `events.ts`, `stores.ts`, `types.ts`, `account.ts`, `admin.ts`, `branding.ts`, `Panel.svelte`, `Button.svelte`, `Footer.svelte` and their tests
- [ ] Retained views: `Login.svelte`, `Account.svelte`, `Admin.svelte`, `RegisterVerify.svelte`, `RecoverVerify.svelte`
- [ ] `api.ts` and `types.ts` pruned of link/click/campaign endpoints and types
- [ ] `stores.ts` `View` union reduced to the surviving views (replaced wholesale by the router in #0014)
- [ ] `npm run check` and `npm test` pass; `npm run build` succeeds

## Notes

PRD §3.2. The full ShortLinks manifest is `~/Developer/brennanMKE/ShortLinks/web/src/{views,lib}/` — every file there is named in the delete or retain list above, so there is nothing to go looking for.

**`lib/events.ts` is a trap.** Its only importer in ShortLinks is `Dashboard.svelte`, which this issue deletes — so it looks orphaned and safe to remove. It is the SSE client and #0048 needs it. Keep it and its test.

**`Admin.svelte` is retained**, not deleted; #0009 ports it. `App.svelte` will still reference deleted views — leave it in a minimal working state here (login + account only) and let #0014 replace its navigation entirely.

`branding.ts` stays but its `APP_NAME` becomes `Open Circuit SF`. `SHORT_URL_BASE` in `links.ts` disappears with the file.
