# 0644 — Add upcoming events: a slow ShortLinks can turn the fallback into an error, and the month field has no hint

## Description

From `#0643`'s review.

1. The upcoming-events handler's 45-second limit covers its database calls as well as the ShortLinks calls. If slow but successful ShortLinks calls use it up, the next database call fails and the click returns an error instead of falling back to plain links. Fix: give the database calls the request's own context and keep the 45-second context only for the ShortLinks calls.
2. Safari on macOS shows the month field as a plain text box. Add `placeholder="YYYY-MM"` and a `pattern` to the input in `CampaignEditor.svelte`.
3. The `.events-status:empty` rule may never match, because the template leaves whitespace inside the paragraph (cosmetic).

## Acceptance criteria

- [ ] An exhausted ShortLinks deadline still produces the appended block with plain links, proved by a handler test.
- [ ] The month field shows a `YYYY-MM` hint.
- [ ] An empty status paragraph takes no space.
