# 0055 — Emit JSON-LD Event structured data

| | |
|---|---|

## Description

Structured data in each workshop page's server-injected head, making sessions eligible for rich results in search.

## Acceptance criteria

- [ ] JSON-LD `Event` object injected server-side into `/workshops/{slug}`
- [ ] Fields: name, startDate, endDate, eventStatus, eventAttendanceMode, location, description, organizer, image, url
- [ ] Canceled workshops emit `EventCancelled` status
- [ ] Organizer is Open Circuit SF with the site URL — no venue is named as organizer
- [ ] Validated against Google's Rich Results Test with no errors
- [ ] JSON string values escaped correctly; a title containing quotes does not break the block

## Notes

PRD §7.4. Structured data goes in the server-injected head, not the SPA — search crawlers that do render JavaScript are the exception, not the rule.

Escaping matters as much here as in #0019: an apostrophe or quote in a workshop title that breaks the JSON block silently invalidates the whole thing, and the failure is invisible without validation.
