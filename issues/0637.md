## Description

Found in `#0635`'s review, which judged `#0622`-`#0628` and `#0635` together against the user's notes.

1. **Automatic Reminder wording can be false.** Bluesky's `One week out:` and Mastodon's `One week to go until` are fixed text, though a Reminder can be scheduled at any time.
2. ~~**Video cells on the board** say only `Post by hand`, so the day appears only inside an open section.~~
3. **The board's preview line** is Bluesky's text only, so video text cannot be compared across sections without switching.
4. ~~**Announce video** says `No set day: post when you are ready.` even after the automatic posts have gone out.~~
5. **The phone page is still long:** 4,200-4,600 px at 390 px wide, and before a section is chosen the Video link is 1,030-1,230 px down, below an 844 px screen.
6. **Video captions can be thin:** TikTok and YouTube keep only the summary's first sentence, so Hack Night's reads `Got a project that's been sitting on the shelf?` alone.
7. ~~**After the jump to Video,** the automatic posts' `Schedule for later…` and `Unschedule` sit directly above it without naming what they apply to.~~
8. **Estimated, not measured:** a three-line strip at 390 px is about 92 px against 88 px of clearance, which would tuck the Video heading about 4 px under it.

## Acceptance criteria

- [ ] A Reminder's generated wording stays true whenever it is scheduled, with Bluesky and Mastodon goldens changed only on purpose.
- [x] Board video cells show the row's day, and Announce video falls back to the day the automatic posts went out.
- [ ] The user can see what will be posted for video in each section without switching sections.
- [ ] On a phone, Video can be reached from the first screen.
- [ ] The bulk controls name what they apply to, and the heading clears a three-line strip.
- [ ] The user decides whether captions should keep more than the first sentence.
