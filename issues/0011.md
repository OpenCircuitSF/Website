## Description

Replace ShortLinks' GitHub-style palette with the Open Circuit terminal palette in **both light and dark**, driven by `prefers-color-scheme` with an explicit `data-theme` override. A working reference implementation exists in `placeholder/index.html`.

## Acceptance criteria

- [ ] Both token sets from PRD §4.2 defined with the exact values given
- [ ] Light on bare `:root`; dark restated under `@media (prefers-color-scheme: dark)` guarded by `:root:not([data-theme="light"])`, and again under `:root[data-theme="dark"]`
- [ ] `color-scheme: light dark` on `:root` and `<meta name="color-scheme" content="light dark">` in `index.html`
- [ ] Blocking inline script in `<head>` applies the stored theme before first paint — no flash of the wrong palette
- [ ] Theme toggle cycles auto → light → dark; auto removes the attribute rather than pinning the current OS value
- [ ] Choice persisted in `localStorage`, wrapped in try/catch (Safari private mode throws)
- [ ] Focus rings use `--accent`, not `--border-strong` — the latter is under 3:1 in both themes
- [ ] Contrast re-measured and matching the table in PRD §4.2
- [ ] Spacing (`--space-1`..`--space-6`), radius, border width, and type scale tokens retained
- [ ] Font tokens point at the self-hosted families from #0012
- [ ] `body` sets an explicit `--bg-page` background and `--text` color
- [ ] Global form control, table, and `.field` styling restated against the new tokens with no literal hex left outside `:root`
- [ ] `Panel.svelte` and `Button.svelte` render correctly with no per-component color changes

## Notes

PRD §4.2. Port the token block, the toggle script, and the motif CSS from `placeholder/index.html` — it is already validated in both themes at 305 px, 390 px, and desktop widths.

Light mode is designed as a *printed listing*, not an inverted dark theme: paper-white panels, near-black text, deep green accent, same prompt / `[ OK ]` / cursor motifs. The motifs carry the identity, not the darkness.

Two rules that are easy to get wrong and expensive to retrofit:

**Body copy uses `--text`, never `--accent`.** Green is for prompts, `[ OK ]` rows, links, labels, and short status lines. Long paragraphs of saturated green on black are physically tiring to read.

**No literal hex outside `:root`.** ShortLinks accumulated stray hex values in components that had to be hunted down and tokenized later when dark mode was added. Start clean.

Every interactive control needs a visible focus ring at `--border-strong` or `--accent` — never signal state by color alone.
