## Description

Part of `#0695` (Agent API, part 2). v1 event outreach drafting.

## Plan

New file `v1_outreach_posts.go`. Extract from `admin_outreach.go`: `startOutreach(ctx, ip, actorID, workshopID)`, `createPost(ctx, …, outreachID, channel, wave, body)`, `updatePost(ctx, …, id, body *string, regenerate bool, customized *bool)`, `deletePost(ctx, …, id)` and `resetOutreach(ctx, …, workshopID)`. Each returns `(view, error)` with sentinel errors. Map them with a new `outreachAPIError` that mirrors `guidePostAPIError`: `ErrPostLocked`/`ErrPostInFlight` → Conflict, `ErrNotFound` → NotFound, field errors → Validation.

| Tool | Method, path | Scope | Flags |
|---|---|---|---|
| `start_event_outreach` | POST `/api/v1/events/{id}/outreach` | outreach:write | idempotent by nature (returns the existing outreach) |
| `create_outreach_post` | POST `/api/v1/outreach/{id}/posts` | outreach:write | `Idempotency: true`, 201 |
| `update_outreach_post` | PATCH `/api/v1/outreach-posts/{id}` | outreach:write | exactly one of `body`/`regenerate` |
| `delete_outreach_post` | DELETE `/api/v1/outreach-posts/{id}` | outreach:write | **DESTRUCTIVE** |
| `reset_event_outreach` | POST `/api/v1/events/{id}/outreach/reset` | outreach:write | **DESTRUCTIVE** (only while nothing is public, as in the admin) |

**Tests:** for each op, success, 409 on a posted post, 404, and 403 without the scope. Each write records an audit row with the token's id (`TestGuidePostV1Audit*` is the model). An idempotent replay of `create_outreach_post` creates one row.

## Resolution

`b0be04ed`. `admin_outreach.go`'s Start, CreatePost, PatchPost, DeletePost and Reset now wrap transport-free `startOutreach`, `createPost`, `updatePost`, `deletePost` and `resetOutreach(ctx, ip, actorID *int64, …)`. These return `*outreachOpError` (status, field, the admin message unchanged) or `outreachLinksError` (a ShortLinks failure). `writeOutreachError` writes these for the admin routes, so admin responses are byte-for-byte as before. All audit writes go through `recordCtx`, which attributes a write to the API token that made it. `ensureLinks`/`ensureLinksFor` now take `(ctx, ip, *actorID)` instead of `*http.Request`, and the hand-links caller is updated. The new `auditFlyerLinkCtx` is the request-free sibling of `auditFlyerLink`.

New `v1_outreach_posts.go`: `outreachAPIError` (mirrors `guidePostAPIError`: 404 → NotFound, 409 → Conflict, 503 / ShortLinks → Unavailable, 400 → Validation with the field) and `outreachWriteOperations`, registered in `v1_registry.go`. It adds five tools, all `outreach:write`:
- `start_event_outreach`: returns the existing outreach when one exists. `MayBeUnavailable`.
- `create_outreach_post`: `Idempotency`, 201.
- `update_outreach_post`.
- `delete_outreach_post`: Destructive.
- `reset_event_outreach`: Destructive.

Post times are converted to Pacific. Op lists are updated in `TestBuildV1RegistryListsOperations`, `specTools`, `docs/api.md` and `docs/mcp.md`.

Note: in this API a validation error is **400**, not 422.
