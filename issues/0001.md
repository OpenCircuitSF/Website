## Description

Copy the ShortLinks repository into this repo as the starting skeleton, rewrite the Go module path, and get a clean build before anything is stripped or added. Everything in Phase 0 builds on this.

## Acceptance criteria

- [ ] `go.mod` initialised as `module github.com/brennanMKE/OpenCircuitSF`, Go 1.26.x (ShortLinks is on `go 1.26.3`)
- [ ] All `internal/*` packages, `cmd/`, `web/`, `migrations/`, `deploy/`, `scripts/`, `Makefile`, `.gitattributes` copied from `~/Developer/brennanMKE/ShortLinks`
- [ ] Every `github.com/brennanMKE/ShortLinks/...` import rewritten to `github.com/brennanMKE/OpenCircuitSF/...`
- [ ] `cmd/shortlinks/` renamed to `cmd/opencircuit/`; binary name is `opencircuit`
- [ ] `.gitignore` excludes `.env`, `web/dist/*` (whitelisting `!web/dist/index.html`), the `opencircuit` root binary, and OS junk
- [ ] `.env.example` present (rewritten in #0007)
- [ ] `go build ./...` and `go vet ./...` pass
- [ ] `go test ./...` passes — record any pre-existing failures rather than fixing unrelated breakage

## Notes

PRD §3. The module path is settled in `CLAUDE.md` §2 — do not re-derive it.

Source tree is `~/Developer/brennanMKE/ShortLinks`. Copy it wholesale; there is nothing to search for at this stage. **Merge `scripts/` rather than replacing it** — this repo already carries `scripts/list-issues-by-phase`, which is not in ShortLinks and must survive the copy. Do the copy mechanically first and strip in #0002/#0003 — a single combined pass makes it impossible to tell a porting mistake from a deliberate deletion.

`web/dist/index.html` must stay committed as a minimal placeholder so `//go:embed all:dist` compiles from a clean checkout before any `npm run build` has run.
