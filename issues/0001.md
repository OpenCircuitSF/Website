> 🟢 Resolved 2026-08-18 — ShortLinks skeleton ported under `github.com/brennanMKE/OpenCircuitSF` with a clean `go build` and `go vet`, and the sole `internal/config` test failure independently confirmed pre-existing in the ShortLinks source tree.

## Root cause

Not applicable — this is foundation-laying feature work, not a bug fix. ## Fix

Copied `internal/`, `cmd/shortlinks` (renamed `cmd/opencircuit`), `web/` (excluding `node_modules/` and ShortLinks' built `dist/` assets — only `web/dist/index.html` carried over as the placeholder), `migrations/` (wholesale, unrenumbered — renumbering is #0004), `deploy/`, `Makefile`, `.gitattributes`, `.env.example`, `go.mod`, and `go.sum` from `~/Developer/brennanMKE/ShortLinks`. `scripts/` was merged via `rsync --exclude 'list-issues-by-phase'` so the existing `scripts/list-issues-by-phase` survived untouched alongside ShortLinks' `dev.sh`, `sim.sh`, `deploy.sh`, `db-status.sh`, and `scripts/db/`. Rewrote `module github.com/brennanMKE/ShortLinks` to `module github.com/brennanMKE/OpenCircuitSF` in `go.mod` and every matching import path across all 67 `.go` files that referenced it via `sed`. Pointed the Makefile's `build` target at `./cmd/opencircuit` producing `opencircuit`. Left the existing `.gitignore`, `PRD.md`, `README.md`, `CLAUDE.md`, `HANDOFF.md`, `LICENSE`, `assets/`, `placeholder/`, and `issues/` untouched, per the task's explicit prohibition on overwriting them.

Did not touch remaining "ShortLinks"/"shortlinks" branding strings inside copied source (doc comments, `web/index.html` `<title>`, `deploy/systemd/shortlinks.service`, `web/src/lib/branding.ts` `APP_NAME`, `.env.example` values) — those are explicitly in scope for later issues (#0002/#0003 strip passes, #0006 docs, #0007 config, deploy-phase issues), not #0001, whose acceptance criteria are limited to module path, import rewrite, cmd rename, binary name, `.gitignore`, `.env.example` presence, and a clean build/vet/test.
