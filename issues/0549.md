# 0549 — Outreach cannot generate printable flyers with per-location QR codes

| | |
|---|---|

## Description

The flyer workflow from the design doc's "Flyers" section and mockup
artboards 4–6: pick a workshop, a photo (upload or cover image) with a focal
point, a template and tagline; tick locations and copies; **Generate** one
ShortLinks link per (workshop, location) under the workshop's campaign; fetch
and cache each link's QR code; print full-page or half-size-double flyers,
each with its location's QR code, short URL and a small location label.

## Acceptance criteria

- [ ] Migrations for `outreach_flyers` (`workshop_id`, `photo`, `focal_x`, `focal_y`, `template`, `tagline`, timestamps) and `outreach_flyer_links` (`flyer_id`, `location_id`, `copies`, `short_link_key`, `short_url`, `qr_svg`, `put_up_at`).
- [ ] **The QR code is unique to the workshop and location** (user decision 2026-10-16): one link per (workshop, location), tagged `utm_source=flyer`, `utm_medium=print`, `utm_content=<location code>`, `utm_campaign=<workshop slug>`, `placement=<location name>`, in the workshop's ShortLinks campaign; reprints and other flyers for the same workshop and location reuse it.
- [ ] QR SVG fetched server-side from `GET /api/links/{key}/qr.svg` and cached in the database; it is sanitized/served so it cannot inject script into the admin page (render as `<img>` from a same-origin admin endpoint, or strip to safe SVG elements).
- [ ] Three templates (photo top, full photo, split) in the light print palette (`#30800C` on white).
- [ ] Print page (admin-only route) using CSS `@page { size: letter portrait }`: **full page** = one 8.5 × 11 in flyer per sheet; **half-size double** = two 5.5 × 8.5 in portrait flyers per letter sheet, each rotated 90°, with a dashed cut line at 5.5 in; halves fill in location order. Text and QR stay inside a 0.25 in safe area. Each flyer shows the location label (name · code) beside the QR code.
- [ ] Photo uses the existing media upload; warns under 1,275 × 1,650 px for full page.
- [ ] **Put up** per location (sets `put_up_at`); the results view gets a "Flyers by location" table (scans this workshop and all workshops) using ShortLinks stats per link.
- [ ] Layout math (cropping around the focal point, half filling, sheet counts) in a tested `web/src/lib` module.
- [ ] Verified with `ISSUE=0549 scripts/check.sh`; the print page checked in a real browser print preview where possible, and the verification says which evidence it rests on.

## Notes

- No external CDN or third-party requests from the print page (CLAUDE.md §9); fonts must be the site's own.
