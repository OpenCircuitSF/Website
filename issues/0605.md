## Description

From `#0604`'s review. A takedown leaves the deleted post's
`outreach_engagement` rows attached to the post row. After a re-post, the
card shows the old post's counts until the next capture, and those rows skew
`EngagementDue`'s last-captured time.

## Acceptance criteria

- [ ] `CompleteTakedown` deletes that post's `outreach_engagement` rows in
      the same transaction. Alternatively, filter reads to
      `captured_at >= posted_at`. State which, and why.
- [ ] Test: engagement captured before a takedown is not shown after it,
      and `EngagementDue` treats the re-posted row as never captured.
- [ ] Verified with `ISSUE=0605 scripts/check.sh go ./internal/outreach/... ./internal/handlers/... ./internal/db/...`. Zero skips.
