## Description

On 2026-11-15 the user asked for the ESP32-C3 guide set: 15 topics in all, split across `#0670`, `#0671` and `#0672` so three agents can build them at once. Each one is built in its own worktree on the topic-guide framework from `#0656`, `#0666` and `#0667`. Every new topic sets `"set": "esp32"`, a set that already exists in the catalog. The board is the ESP32-C3 SuperMini.

Guides in this issue:

- `esp32-c3-boot-reset-buttons` — the BOOT and RESET buttons
- `esp32-c3-wont-upload` — the board that won't upload
- `esp32-c3-serial-output` — where did my Serial output go?
- `platformio-first-project` — your first project in PlatformIO
- `esp32-ota-updates` — updating over WiFi

## Acceptance criteria

1. Each guide has its entry in `guides.json` with `"set": "esp32"`, a body in `topics.ts` and an interactive demo.
2. The logic is in a plain TS module with unit tests. Each demo has one jsdom behaviour test.
3. Illustrations are SVG rendered to PNG with `rsvg-convert`, or inline SVG. Never use a browser.
4. Facts are checked against Espressif's ESP32-C3 datasheet or Technical Reference Manual, or the arduino-esp32 docs.
5. `ISSUE=0670 scripts/check.sh` passes, and so do the scoped Go checks (`internal/guides`, `internal/seo`, `cmd/opencircuit`).
