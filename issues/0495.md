# 0495 — Nothing pins that the CRT editor's command warnings pass the command budget rather than defaulting

## Description

`#0397` made the admin editor warn when a **command** overflows the glass, using
a prefix-aware budget two characters smaller than an output line's. Two call
sites in `web/src/views/admin/CrtCommands.svelte` pass it explicitly:

	crtOverBudgetWarning(newCommand, CRT_COMMAND_LINE_CHARS)   // create form
	crtOverBudgetWarning(draft.command, CRT_COMMAND_LINE_CHARS) // row editor

**Nothing asserts either argument is there.** `#0397`'s reviewer measured it:
changing the create form to `crtOverBudgetWarning(newCommand)` — dropping the
budget so it falls back to the full output width — leaves the suite green at 45
files / 4,111 tests.

The row editor's call is pinned only **incidentally**, by the live-region
allowlist quoting the argument inside its `match` string. Breaking it reports a
*stale allowlist entry*, not a wrong budget — the right alarm for the wrong
reason, and it would be silenced by anyone updating the allowlist to match.

## Why the existing test does not cover it

`crtCommands.test.ts` drives `crtOverBudgetLines` **directly**, with a locally
built string and two imported constants. It proves the function distinguishes
the two budgets correctly; it never observes the Svelte call sites.

`#0397`'s second pass **documented this in the test itself** rather than leaving
it to read as coverage it does not provide — that comment is the reason this
issue can be narrow.

## Why it was left out of scope, twice

`#0397`'s first review found it and deliberately excluded it from the bounce; its
second review confirmed the pin was not built and that the corrected prose no
longer claims otherwise. Both were right: the bounce was about false statements,
and building a new guard inside it would have grown a transcription pass into a
design one.

**The defect is latent, not live.** The longest seeded command is
`subscribe --interests` at 21 characters — 23 with the `> ` prefix — against a
34-character command budget. Nothing overflows today; this protects the feature's
whole point, which is operators typing commands of their own.

## Acceptance criteria

1. **Re-measure the gap before fixing it.** Drop the budget argument at the
   create form in a **copy**, confirm the suite stays green, and restore
   byte-identically with SHA-256. Never `git stash` (`CLAUDE.md` §8a). A gap
   that has closed since this was filed should be reported, not papered over.
2. **Pin both call sites** — the create form and the row editor. Assert each
   passes `CRT_COMMAND_LINE_CHARS`, not merely that it passes something.
3. **Choose the instrument deliberately and say why.** Two precedents exist and
   they point different ways: `#0398` used an **AST structural guard** over the
   `.svelte` source, after establishing by measurement that a jsdom mount could
   not observe its seam — the CRT `onMount` bails at `getContext('2d')`, and
   `matchMedia` and `IntersectionObserver` are absent too. This seam is in the
   **admin editor**, not the canvas, so a mount may well reach it —
   `CrtCommands.behavior.test.ts` already mounts that component. **Establish
   which applies here rather than inheriting either answer**, and state whether
   your proof rests on a mount or a source scan (`CLAUDE.md` §1: jsdom is not a
   browser, and a claim should say which evidence it rests on).
4. **Prove it fails.** Drop the argument at each site in turn and confirm your
   pin fails **naming that site**. A guard never seen to fail is not a guard
   (`CLAUDE.md` §8).
5. **Do not rely on the live-region allowlist.** It catches this incidentally
   and reports the wrong cause; the pin must stand on its own.
6. **Do not weaken `#0398`'s structural guard or the live-region count.** Both
   moved repeatedly during the CRT work — that count went 12 → 13 → 14 in one
   day — and each move was measured. If your change adds a live region, measure
   the new count the way those passes did: instrument a throwaway copy and read
   the subtree size. **Do not count braces — that returns 38.**
