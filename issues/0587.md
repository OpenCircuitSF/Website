## Batch 7 from the review

*Closes:* E1, E3, E4, E5. *Effort:* **S**.

1. The Schedule all dialog ticks a wave by default when its drafts exist,
   lists only chosen posts in full weight, and its heading names the waves
   ("Schedule the Reminder and Last call?"); the button is never "Schedule
   0 posts" while rows are listed in full weight.
2. The dialog states that by-hand channels are not scheduled.
3. Each row shows its time with the zone and a per-row inline edit; the
   dialog links to the posting-hour setting.
4. The composer's schedule hint for Announce reads "usually goes out now";
   a passed suggestion is named with its date.

## Resolution

1. `OutreachScheduleAllDialog.svelte`: a drafted Reminder/Last call starts ticked; only chosen posts are listed; the heading names the chosen waves ("Schedule the Reminder and Last call?", "Schedule posts?" when none); the button reads "Nothing chosen" (disabled) instead of "Schedule 0 posts".
2. The dialog says "Posts you make by hand (Instagram, TikTok, YouTube) are not scheduled."
3. Rows show `formatPacificWeekdayTime` (with PT); "Change time" opens a labelled Pacific `datetime-local` per row (`toPacificInput`/`fromPacificInput`), past times block Schedule; a link goes to Settings -> Outreach (`adminSettingsHash('outreach')`). The confirm sends `times` (post id -> RFC 3339); `ScheduleAll` validates each against the single-Schedule lead window (400 otherwise) and applies it. Skipped suggestions also show Pacific.
4. `scheduleHint` in `lib/outreach.ts`: Announce reads "The announcement usually goes out now. Pick a time only if you want to wait."; a passed suggestion is named with its date; used by `OutreachComposer.svelte`.
