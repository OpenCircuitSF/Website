## Description

`#0281`'s guard flags any unscoped `ClaimDue`/`OrphanSweep` call outside
`internal/outbox`, and fails closed below **5 call sites found** against 32
measured. `#0281`'s review verified that floor is honoured and that the
name-collision handling is structurally sound.

**But 32 counts every call site, and 20 of them are inside `internal/outbox`,
where calls are exempt.** Only **12** are outside the package — the population
the guard actually checks. So the floor proves the scan reached the *exempt*
rows, not the *checked* ones.

Measured by `#0281`'s reviewer: narrowing `claimKindsGuardScanRoots` to
`[]string{"."}` leaves **23 sites (above the floor of 5), zero of them
evaluated, and the guard reports PASS.**

This is the same population-mismatch shape `#0275` criterion 4a closed for the
sibling guards, where a floor counted 247 walked files against 110 parsed. It is
not a bounce on `#0281`: criterion 4 as written is met, the constant's own
comment admits the limit, and CLAUDE.md §8 warns against stacking further
in-file checks without thought.

## Acceptance criteria

1. A second floor asserts the count of **non-exempt** call sites — those outside
   `internal/outbox` — is plausible. Five against today's 12 is the reviewer's
   suggestion; justify whatever number you pick in a comment.
2. Both floors survive. The existing one still proves the walk found the tree at
   all; the new one proves it found the population being checked. Say in the
   comment which each covers.
3. Prove the new floor fires: narrowing `claimKindsGuardScanRoots` to `{"."}`
   must fail, where today it passes with zero sites evaluated. Demonstrate the
   before state too.
4. Per CLAUDE.md §8, the oracle must not be the same bytes as the subject, and
   an empty extraction must be an error rather than an input.
5. **Consider whether this belongs in `#0300`'s external harness instead.**
   `#0300` is open to pin every guard-family floor from outside the files they
   live in, precisely because in-file constants can be edited to `0` with the
   suite staying green. If that is the better home, say so and close this as
   folded in rather than building both.
6. `ISSUE=NNNN scripts/check.sh go ./internal/outbox/... ./internal/mailing/... ./internal/handlers/...`
   passes with no skips.
