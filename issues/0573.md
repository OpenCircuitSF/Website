## Resolution

New `outreach_hashtags` server setting (default `#SanFrancisco #Electronics`, each `#` plus letters or digits, at most six, duplicates dropped, CamelCase in the help text), validated in `serversettings`. The handler (`SetHashtags`) puts it in `Facts.Hashtags` and `Draft` appends it as the final line for every channel; the length fit counts it. Tests: facets land on the appended tags and the limit check includes them (`TestDraftHashtagsAreFacetsAndCounted`), a handler test checks drafts end with the line, and validation cases. Decision: the optional per-workshop hashtags were not done (they need a column on `outreach` and an editor field; the site-wide set covers Monday). That part of the criteria is open for the reviewer to file.
