## Description

`#0519`'s first slice serves the home page's heading and "What this is" copy in raw HTML, but not the "Next up" list of upcoming workshops, which the SPA fetches from `/api/workshops`. It is the most time-sensitive, link-rich content on the home page.

## Acceptance criteria

1. The home page's raw HTML lists upcoming workshops with plain links to their detail pages, using the same selection and ordering as the SPA.
2. Invalidation matches the workshop cache (`#0319`, `#0325`), so a newly published or canceled workshop is reflected promptly.
3. No duplicated content after mount.
4. `ISSUE=NNNN scripts/check.sh` passes.
