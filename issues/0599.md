## Resolution

Admin nav is now option A with the section named "Newsletter".
`adminRouter.ts` orders the groups Workshops · Newsletter · System (Campaigns
first in Newsletter), gives each a `landing`, adds `sectionGroup()`, and
relabels Pending → "Pending confirmations" and CRT session → "Home screen".
`Admin.svelte` has two labelled `<nav>`s: row one with four section tabs,
and row two with only the active group's screens (none on Overview or
not-found). The ≤480px `<select>` and the header Account | Admin tab row are
gone, and "Account" is a plain link beside Sign out. Implemented in
`d38730f7`; review fixes in `d123ced9`.

## Resolution notes

- Row one marks a section tab `aria-current="true"` and Overview
  `aria-current="page"`. That is deliberate and matches the review doc's
  Option A: a section tab names the current section, not the current page,
  while Overview is the page.
- The review commit removed `.subtab`'s `margin-bottom:-1px`. Row two
  scrolls (`overflow-x:auto`, so `overflow-y` computes to `auto` too), and a
  border hanging 1px past the box would be clipped and give a 1px vertical
  scroll. The 2px accent edge now sits just above the row's 1px rule.
- Evidence is jsdom only. No Safari render was made (see Review notes).

     takes the global link style. The test that finds it by role/name still

- Verification, re-run by the reviewer after the fix:
