## Description

`docs/deployment.md`'s Prerequisites section tells you to clone
`github.com/brennanMKE/OpenCircuitSF`. **That URL 404s.** The repository is
`github.com/OpenCircuitSF/Website` — the owner and repo halves are transposed,
and it is attributed to the user account rather than the organisation.

`HANDOFF.md` and `PRD.md` carry the same owner/repo assumption and need the
same sweep.

Measured 2026-09-12: `git remote -v` and `gh repo view` both give
`OpenCircuitSF/Website` (200); the documented form returns 404.

## How it was found

`#0509`'s third review pass, which caught the identical mistake in four
freshly-written `curl` URLs for the release-download steps. Those four are
fixed in `#0509`. This issue covers the **pre-existing** occurrences, which
predate that work — the `git clone` line dates to `ccf134d` (`#0064`).

## The wrinkle that makes a literal fix the wrong fix

`CLAUDE.md` §2 records a **pending rename**: the GitHub repo is to go
`Website` → `OpenCircuitSF`. After it lands the correct URL becomes
`OpenCircuitSF/OpenCircuitSF`. So hardcoding today's correct literal buys a
second staleness on the day of the rename.

`#0509` solved this for the release URLs by deriving the value at runtime:

    REPO="$(gh repo view --json nameWithOwner -q .nameWithOwner)"

That survives the rename automatically. Prose cannot do the same trick, so the
question here is whether each occurrence should name the literal, describe the
repo without a URL, or (for command examples) derive it.

## Acceptance criteria

1. No document instructs the reader toward a URL that 404s today.
2. Every occurrence is considered against the pending rename — say, per
   occurrence, whether it is a literal, a derivation, or a rephrase, and why.
   **Either answer is acceptable per occurrence; an unexamined one is not.**
3. `docs/deployment.md`, `HANDOFF.md` and `PRD.md` are all swept, plus any
   other tracked file naming the repo. Say what you searched.
4. Editing `PRD.md` means running `internal/db`; editing a Go comment means
   `internal/handlers` (`CLAUDE.md` §5).
5. Resolved issue files are out of scope — dated records, same boundary
   `#0508` and `#0511` apply.

## Relation

- Found by [#0509](0509.md)'s third review pass; the four live `curl` URLs are
  fixed there, this is the pre-existing remainder.
- `CLAUDE.md` §2 — the pending rename that makes a literal fix short-lived.
- [#0511](0511.md) — a repo URL is **not** a restricted identifier; the repo is

## Notes

Low urgency: nobody clones the repo during a deploy, and the people who have it
checked out already got it from somewhere that worked. It matters for the next
person following the docs from scratch.

## Fix

Measured first, per the issue's own method: `git ls-remote
https://github.com/brennanMKE/OpenCircuitSF.git` → "Repository not found";
`git ls-remote https://github.com/OpenCircuitSF/Website.git` → resolves
(main + tag `v0.1.0`). Search used: `grep -rn brennanMKE` and
`-OpenCircuitSF/Website|-OpenCircuitSF/OpenCircuitSF` over every tracked
non-`issues/` file, plus URL-shaped patterns; Go-source hits are the
module path's import statements, correct per `CLAUDE.md` §2 and left
alone. Resolved issue files untouched (criterion 5); the one open issue
file with a URL-shaped match, `issues/0509.md:1140`, quotes the 404 as
the bug it found — a dated record, left alone.

Per-occurrence decisions:

- `PRD.md` header **Repository:** — literal
  `github.com/OpenCircuitSF/Website` plus an inline pointer to the
  pending rename (§14 Q5). A document header cannot derive at runtime.
- `PRD.md` **Go module:** — left; the module path, not a URL, and
  `CLAUDE.md` §2 settles it.
- `docs/deployment.md` clone line — literal
  `https://github.com/OpenCircuitSF/Website.git` with the stale
  "target name" caveat struck and a dated correction: the box has no
  `gh` (`ssh photon command -v gh` → only `/usr/bin/git`), so #0509's
  derivation pattern is unavailable there; the release steps keep
  deriving on the workstation and survive the rename.
- `HANDOFF.md` §2.1 — the "Current remote" and "Decide" URL literals
  struck with dated `#0515` corrections naming what is measured today;
  the module path sentence kept.
- `deploy/systemd/{opencircuit,opencircuit-backup,opencircuit-backup-alert}.service`
  and `opencircuit-backup.timer` — `Documentation=` keys, found by the
  sweep ("any other tracked file naming the repo"): literal, since an
  installed unit file cannot derive; now
  `https://github.com/OpenCircuitSF/Website`.
