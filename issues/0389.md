## Description

`outbox.Store.Counts` builds five `count(*) FILTER (WHERE status = $n)` columns
from one positional argument list. **Swapping `StatusQueued` and `StatusSent` in
that list** — so `Counts.Queued` reports sent rows and `Counts.Sent` reports
queued rows — leaves the **entire `internal/outbox` package green.** Measured by
`#0382`/`#0386`'s reviewer on a throwaway export with its own scratch database.

`#0386`'s fixed `TestOutbox_Counts` asserts `after.Queued == before.Queued+1`
and `after.Sent == before.Sent+1` around one row moved into each state — and **a
symmetric relabelling satisfies both deltas identically.**

**Pre-existing, not a regression from `#0386`.** The old `>= 1` / `>= 1` pair was
equally blind. `#0386` made the test **strictly stronger** — it now kills three
of four `Counts` mutants including all-zeros, and the dropped-`FILTER` mutant it
catches satisfied the old floor. This is the one mutant that survives.

**It is `#0364`'s finding one layer up**: the deltas are individually sound but
**jointly unable to tell the two labels apart**. Each assertion passes for a
reason that does not distinguish the thing it names.

## The fix the reviewer measured

A **single asymmetric assertion**: after enqueuing the queued row but **before**
claiming and sending the other, assert

```
mid.Queued == before.Queued+2 && mid.Sent == before.Sent
```

No swap can satisfy that — the asymmetry is what breaks the symmetry the
relabelling exploits.

## Acceptance criteria

1. `TestOutbox_Counts` fails under the `Queued`/`Sent` swap. **Prove it by
   running that exact mutation**, in a `git archive` export with your own
   database (§8b), never the tracked tree.
2. The three mutants `#0386` already kills still fail: all-zeros, `Queued`
   filtering `'sending'`, and `Queued` dropping its `FILTER`. **Re-run all
   three** — a fix that closes the swap while opening one of these is a net
   loss.
3. **Consider the same shape for the other columns.** `#0380` added `Skipped` to
   this query and `#0378` moved rows into it; `Abandoned` and `Skipped` are both
   terminal and could be swapped for each other by the same argument. Say
   explicitly whether that swap also passes today, and whether your fix closes
   it — **do not silently scope to `Queued`/`Sent`.**
4. **Do not weaken anything to achieve it.** `#0354`, `#0358` and `#0363` each
   shipped a check that could not fail, and `#0364` exists because an assertion
   can pass for the wrong reason. The added assertion must itself be shown to
   discriminate.
5. `TestOutbox_Counts` must still pass **run alone** — that was `#0386`'s
   deliverable, verified by running all 41 tests in the package individually.
   Re-confirm; a fix that reintroduces residue dependence undoes it.
6. Per §5 name the specific tests that ran; the mailing subsystem needs
   Postgres. `gofmt` stability. Run `./internal/outbox/...` and
   `./internal/handlers/...` — both own repo-wide guards (`#0381`). No
   `<file>.go:<int>` citation in any comment (`#0352`).
7. **Measure any population figure yourself**; the orchestrator propagated a
   stale `42 / 12` nine times this phase when the real figure is `44 / 12`.
