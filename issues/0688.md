## Description

`.gitignore` line 19 is `coverage.*`. It is meant for Go coverage profiles, but it is unanchored, so it also matches source files at any depth. `#0678`'s implementer wrote `internal/cadence/coverage.go`. Git never tracked it, the merge to main failed to build (`undefined: Event`), and removing the worktree deleted the file. The file was restored from the implementer's transcript as `compute.go`.

Fix:

1. Anchor the pattern, or narrow it to the files actually produced: for example `/coverage.out`, `/coverage.html` and `*.coverprofile`.
2. Add a guard test that no `*.go`, `*.ts` or `*.svelte` path under `internal/`, `cmd/` or `web/src/` is matched by `.gitignore` (`git check-ignore`). This catches the next pattern that is too broad.
3. Add a line to AGENTS.md §8a: before removing a worktree, run `git status --ignored` and check that nothing you wrote is ignored.
