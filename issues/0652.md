## Description

User request, 2026-11-08: "I'd like to have my Home Assistant run a daily task which checks if there is any engagement on Bluesky or Mastodon. We could do it through the OCSF website using an API token."

Every admin route today needs a passkey session. Home Assistant can't hold one, so it needs a long-lived token the admin creates, can see listed, and can revoke. This issue builds the token mechanism only. `#0653` adds the engagement endpoint that uses it.

Decisions, so planning doesn't reopen them:
- **Admin-created and shown once.** The admin names the token, for example "Home Assistant". The secret is shown a single time, at creation. Only a hash is stored: SHA-256 of a high-entropy random secret is enough, and a slow KDF isn't needed. The listing shows name, scope, created, last used and a short non-secret prefix.
- **Scoped, read-only.** Each token carries scopes. The only one now is `engagement:read`. A token never grants admin-session powers, never reaches `/admin/*` routes, and is never accepted for anything that writes.
- **Header.** `Authorization: Bearer <token>`. The token is never accepted in a query string, because it would end up in Apache logs.
- **Routes.** Token-authenticated endpoints live under a new prefix, `/api/v1/…`, separate from the session-authenticated admin API. A missing, unknown or revoked token returns `401`, and the response body never says which of the three it was. A valid token without the required scope returns `403`.
- **Revocable.** Revoking takes effect on the next request. `last_used_at` is updated at most about once a minute per token, so polling doesn't turn into a write per request.
- **Audited.** Creation and revocation are audit-log entries. Requests that use a token are not audited individually.
- **Desktop admin UI.** A section in Settings lists tokens and offers create and revoke. Admin pages are desktop-only.
- **New migration.** The production schema is at 50, so use `000051` or whatever is next at the time.

## Acceptance criteria

- [ ] An admin can create a named token with the `engagement:read` scope. The secret is shown once and is never retrievable again.
- [ ] Only a hash of the secret is stored. A test proves the plaintext never reaches the database.
- [ ] An `/api/v1/` route accepts `Authorization: Bearer`. It returns `401` for a missing, wrong or revoked token, `403` for a missing scope, and never accepts the token from the query string. Each case has a test.
- [ ] A token cannot authenticate any `/admin/*` route. There is a test.
- [ ] Revoking a token stops it on the next request. The list shows last-used time and a non-secret prefix.
- [ ] Create and revoke are audited.
- [ ] The token's secret is never logged or written into audit metadata.

### Design in one paragraph

A new package, `internal/apitokens`, owns the `api_tokens` table, token generation and hashing. A token is `ocsf_` followed by 43 characters of unpadded URL-safe base64 over 32 random bytes, 48 characters in all. The database stores only `sha256(token)` (32 bytes, unique), plus the first 12 characters as a non-secret display prefix. A request is authenticated by hashing the presented token and looking it up by that hash. A new middleware, `middleware.RequireAPIToken(resolver, scope)`, reads **only** the `Authorization: Bearer` header. It never reads a cookie or the query string. It answers `401` for a missing, malformed, unknown or revoked token, always with the same body, and `403` when the scope is missing. Token routes are kept in a list on the handler, and `mountAndServe` registers every route in that list as `GET` only, behind the middleware. `#0653` adds its route to the same list with one `AddV1Route` call. `RequireSession` also refuses any `ocsf_` token before it looks anything up, so an API token can never authenticate `/admin/*`.

**Constant-time comparison is not needed here, and that is deliberate.** No secret is compared in Go. The lookup is an index equality on the SHA-256 digest, and a timing difference in that lookup could only reveal bytes of a hash that cannot be reversed. Do not add `crypto/subtle`.

### 2. `internal/apitokens`

`token.go`, with no database access:

    const (
        TokenPrefix         = "ocsf_"
        TokenLength         = 48           // len(TokenPrefix) + 43
        DisplayPrefixLength = 12
        ScopeEngagementRead = "engagement:read"
        LastUsedInterval    = time.Minute
    )
    // KnownScopes is every scope a token may carry; the migration's CHECK must match.
    var KnownScopes = []string{ScopeEngagementRead}
    var (
        ErrNotFound       = errors.New("apitokens: token not found")      // unknown, malformed or revoked
        ErrAlreadyRevoked = errors.New("apitokens: token already revoked")
    )
    func Generate() (secret string, err error)   // TokenPrefix + base64.RawURLEncoding(32 bytes from crypto/rand)
    func Hash(secret string) []byte              // sha256.Sum256([]byte(secret)), over the whole string, prefix included
    func LooksLikeToken(s string) bool           // strings.HasPrefix(s, TokenPrefix) && len(s) == TokenLength
    func IsKnownScope(s string) bool

A session token is 43 characters, so `LooksLikeToken` can never be true for one. That is what makes the `RequireSession` refusal in §3 safe.

`store.go`:

    type Token struct {
        ID         int64
        Name       string
        Prefix     string     // display_prefix
        Scopes     []string
        CreatedBy  *int64
        CreatedAt  time.Time
        LastUsedAt *time.Time
        RevokedAt  *time.Time
    }
    type Store struct{ pool *pgxpool.Pool }
    func NewStore(pool *pgxpool.Pool) *Store
    func (s *Store) Create(ctx context.Context, name string, scopes []string, createdBy *int64, now time.Time) (Token, string, error)
    func (s *Store) List(ctx context.Context) ([]Token, error)
    func (s *Store) Revoke(ctx context.Context, id int64, now time.Time) (Token, error)
    func (s *Store) Resolve(ctx context.Context, secret string, now time.Time) (Token, error)

- **Create** calls `Generate`, then `INSERT INTO api_tokens (name, token_hash, display_prefix, scopes, created_by, created_at) VALUES ($1,$2,$3,$4,$5,$6) RETURNING id`, with `display_prefix = secret[:DisplayPrefixLength]`. It returns the populated `Token` and the secret. The secret is the second return value. It is never stored, and nothing in the package logs it.
- **List**: `SELECT id, name, display_prefix, scopes, created_by, created_at, last_used_at, revoked_at FROM api_tokens ORDER BY (revoked_at IS NOT NULL), created_at DESC, id DESC`. Return an empty slice, not nil.
- **Revoke**: `UPDATE api_tokens SET revoked_at = $2 WHERE id = $1 AND revoked_at IS NULL RETURNING <same columns>`. If no row comes back, run `SELECT EXISTS (SELECT 1 FROM api_tokens WHERE id = $1)`, then return `ErrAlreadyRevoked` if the row exists and `ErrNotFound` if it does not.
- **Resolve**: if `!LooksLikeToken(secret)`, return `ErrNotFound` without a query. Otherwise run `SELECT <same columns> FROM api_tokens WHERE token_hash = $1 AND revoked_at IS NULL` with `Hash(secret)`. `pgx.ErrNoRows` becomes `ErrNotFound`. **The throttle:** if `LastUsedAt == nil || now.Sub(*LastUsedAt) >= LastUsedInterval`, run `UPDATE api_tokens SET last_used_at = $2 WHERE id = $1 AND (last_used_at IS NULL OR last_used_at <= $3)` with `$3 = now.Add(-LastUsedInterval)`, then set `tok.LastUsedAt = &now`. Return an update error wrapped; do not swallow it. Polling every second therefore writes at most once a minute, and the conditional `WHERE` keeps concurrent requests from writing twice.

`main_test.go` copies `internal/serversettings/main_test.go`, using `testdb.Lock`, `testdb.Connect` and a package `testDBPool`. Add a `testPool(t)` helper that skips when the pool is nil and runs `DELETE FROM api_tokens` both before the test and in `t.Cleanup`.

### 3. Middleware: `internal/middleware/apitoken.go`

    // APIToken is the principal RequireAPIToken attaches; it never carries the secret.
    type APIToken struct {
        ID     int64
        Name   string
        Prefix string
        Scopes []string
    }
    type APITokenResolver interface {
        Resolve(ctx context.Context, secret string, now time.Time) (apitokens.Token, error)
    }
    const apiTokenContextKey contextKey = 1   // userContextKey is 0
    func APITokenFromContext(ctx context.Context) (*APIToken, bool)
    func RequireAPIToken(resolver APITokenResolver, scope string) func(http.Handler) http.Handler

`RequireAPIToken`, in order:
1. Read `r.Header.Get("Authorization")`. Accept it only when it has the case-insensitive `bearer ` scheme, using the same test as `sessionToken`, and the trimmed remainder is non-empty and `apitokens.LooksLikeToken`. **Never** read `r.URL.Query()` or any cookie. If this check fails, call `writeAPIUnauthenticated(w)`.
2. Call `resolver.Resolve(r.Context(), tok, nowFunc())`. `errors.Is(err, apitokens.ErrNotFound)` gives `writeAPIUnauthenticated(w)`. Any other error gives `writeJSONError(w, 500, "internal_error")`.
3. If `scope != ""` and `!slices.Contains(t.Scopes, scope)`, call `writeJSONError(w, http.StatusForbidden, "forbidden")`. An empty scope means any valid token, which only `/api/v1/token` uses.
4. Set `Cache-Control: no-store`, attach `&APIToken{…}` to the context and call `next`.

`writeAPIUnauthenticated` sets `WWW-Authenticate: Bearer realm="opencircuitsf"`, then calls `writeUnauthenticated(w)`. Every 401 case therefore has an identical body and identical headers. Nothing in the middleware logs.

In `internal/middleware/auth.go`, in `RequireSession` immediately after `token := sessionToken(r)` and its empty check, add the following. Its comment says why: API tokens authenticate `/api/v1/` only and never a session route, `#0652`.

    if apitokens.LooksLikeToken(token) {
        writeUnauthenticated(w)
        return
    }

### 4. Handlers: `internal/handlers/api_tokens.go`

    type apiTokenStore interface {
        Create(ctx context.Context, name string, scopes []string, createdBy *int64, now time.Time) (apitokens.Token, string, error)
        List(ctx context.Context) ([]apitokens.Token, error)

    // APIv1Route is one token-authenticated route. mountAndServe registers each as GET only.
    type APIv1Route struct {
        Path    string        // must start with "/api/v1/"
        Scope   string        // "" = any valid token
        Handler http.Handler
    }
    type APITokensHandler struct {
        store   apiTokenStore
        auditor *audit.Logger
        now     func() time.Time
        v1      []APIv1Route
    }
    func NewAPITokensHandler(store apiTokenStore, auditor *audit.Logger) *APITokensHandler
    func (h *APITokensHandler) AddV1Route(path, scope string, handler http.Handler)
    func (h *APITokensHandler) V1Routes() []APIv1Route
    func (h *APITokensHandler) Resolver() middleware.APITokenResolver
    func (h *APITokensHandler) List(w, r)     // GET  /admin/api-tokens
    func (h *APITokensHandler) Create(w, r)   // POST /admin/api-tokens
    func (h *APITokensHandler) Revoke(w, r)   // POST /admin/api-tokens/{id}/revoke
    func (h *APITokensHandler) Describe(w, r) // GET  /api/v1/token

- `NewAPITokensHandler` registers the built-in route `{"/api/v1/token", "", http.HandlerFunc(h.Describe)}`. `AddV1Route` panics if `path` lacks the `/api/v1/` prefix, or if `scope != ""` and the scope fails `apitokens.IsKnownScope`. `#0653` calls `apiTokensH.AddV1Route("/api/v1/engagement", apitokens.ScopeEngagementRead, engagementH)` in `servePostgres`.
- JSON view, used by List, Create and Revoke: `{"id","name","prefix","scopes","created_at","last_used_at","revoked_at"}`. The last two are `null` when unset, and the field is named exactly `prefix`. There is **no** secret field on the view.
- **List** returns `200 {"tokens":[…]}`.
- **Create** decodes `{"name": string, "scopes": []string}` with `decodeJSON`. A decode failure gives `400 "invalid request body"`. Then:
  - `name = strings.TrimSpace(name)`. Empty gives `400 "name is required"`. `utf8.RuneCountInString(name) > 100` gives `400 "name must be 100 characters or fewer"`.
  - Empty `scopes` gives `400 "at least one scope is required"`. Any unknown scope gives `400 "unknown scope: <s>"`. Remove duplicates, keeping order.
  - Call `store.Create(ctx, name, scopes, &u.ID, h.now())`.
  - Record the audit entry: `audit.Entry{ActorID: &u.ID, Action: audit.ActionAPITokenCreated, TargetType: audit.TargetAPIToken, TargetID: &tok.ID, Metadata: map[string]any{"name": tok.Name, "prefix": tok.Prefix, "scopes": tok.Scopes}, IP: clientIP(r)}`. Write the map inline, because the audit-metadata guard resolves inline literals. Use no other keys and never the secret.
  - Set `Cache-Control: no-store` and respond `201 {"token": view, "secret": secret}`.
- **Revoke** parses `{id}` with `strconv.ParseInt`. A bad value gives `400 "invalid id"`. `ErrNotFound` gives `404 "token not found"`, and `ErrAlreadyRevoked` gives `409 "token already revoked"`. On success, record the audit entry `{… Action: audit.ActionAPITokenRevoked, TargetID: &tok.ID, Metadata: map[string]any{"name": tok.Name, "prefix": tok.Prefix}, IP: clientIP(r)}` and respond `200 {"token": view}`.
- **Describe** reads `middleware.APITokenFromContext` and responds `200 {"name","prefix","scopes"}`. Home Assistant setup (`#0654`) uses it to check that a token works.
- Without a session user, Create and Revoke answer `401 "unauthenticated"`, the same as `AdminServerSettingsHandler.Patch`. Skip the audit when `h.auditor == nil`. **Never log a request body or the secret** anywhere in this file.
