## Description

`scripts/browser_nav_guard_test.sh` installs `trap cleanup EXIT INT TERM`
(`#0609`). An `INT` or `TERM` trap that does not exit returns control to the
script: Ctrl-C runs `cleanup` (stopping and deleting the Tart clone and
releasing the lease), and then the script carries on with its next step
against a VM that no longer exists, failing noisily, and runs `cleanup` a
second time from the `EXIT` trap. Nothing leaks, but an interrupt should stop
the run.

## Acceptance criteria

- [ ] `INT` and `TERM` exit the script (130 and 143) so that `cleanup` runs
      once, from the `EXIT` trap: `trap cleanup EXIT; trap 'exit 130' INT;
      trap 'exit 143' TERM`, or equivalent.
- [ ] `cleanup` stays idempotent and still removes the clone, the lease and
      the build directory on every exit path.
- [ ] Verified by interrupting a real `scripts/check.sh browser-nav` run
      mid-way: it stops promptly, prints no further step output, and leaves no
      `ocsf-browsernav-*` clone (`tart list`) or held lease behind. A full run
      still passes all 17 assertions.
- [ ] `shellcheck` and `bash -n` pass.
