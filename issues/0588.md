## Resolution

1. **Channel toggle.** New server setting `outreach_channels` (comma list, default `bluesky,mastodon,instagram`) in `internal/serversettings`, migration `000042_outreach_channels_setting` (widens the key CHECK; `docs/database.md` row and the `000001`-`000042` range in it and `AGENTS.md`; test template rebuilt). Settings → Outreach shows one checkbox per channel; the last channel left on cannot be switched off. The handler reads it per request (`SetEnabledChannels`), so a save applies at once. Disabled channels are not drafted (Draft all), refused by `POST /admin/outreach/{id}/posts` (409), get no new tracked links (`ensureLinks`), and are left out of the panel's `channels` and `posts` (so the summary line, cards, Post by hand, Announce button and Schedule all need no client filter), the links table, the per-workshop results (channels and posts) and the overview (`posts_total`, `posts_posted`, `scheduled`, `posted_channels` recomputed from enabled posts; `enabled_channels` returned and fed to `postsCellText`'s `isEnabled`). **Existing posts and links for a disabled channel are kept**, only hidden and uncounted; switching the channel back on brings them back (tested). Click totals still include every real click.
2. **Mark posted / Unmark.** The dialog with the optional "Link to the post" field was already in place (#0581). Added `POST /admin/outreach-posts/{id}/unmark` (`Store.MarkUnposted`: status back to `manual`, `posted_at` and `remote_url` cleared; audited as `outreach_post.unmarked`). Refused (409) for a post whose channel the site posts itself (`channelConfigured`), since that post is really public, and for a post that is not posted. The card shows **Unmark** on a hand-posted posted card, through the in-app dialog (never `window.confirm`), which says nothing is removed from the network.
3. **Flyer link.** The Instagram card's link opens this workshop's newest flyer (`flyerLinkFor`, from `listOutreachFlyers` loaded once by the workshop page), else "Make a flyer", which opens the flyers page with the workshop preselected (`#/outreach?view=flyers&workshop=N`). **Not done: the downloadable PNG of the flyer face.** The flyer face is HTML and CSS drawn in the browser; a PNG needs a client-side rasteriser (a new dependency, or an SVG foreignObject round trip) that jsdom cannot exercise and I may not run a browser to check. Suggest a follow-up issue (orchestrator to file); it fits batch 9's single Print action.
4. **Caption and bio.** "Copy text" is "Copy caption" on hand-posted cards; the link row reads "Put this in your bio" and is hidden when the body already contains the short URL (`showBioLink`).
