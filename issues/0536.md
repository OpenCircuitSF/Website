## Description

While mutation-proofing `#0525` (removing the noindex middleware wrap to prove
the new wiring test fails), the mutated run consistently reported
`context deadline exceeded` from `mountAndServe`'s return after SIGTERM, where
the green path returns `nil`. The observation appeared only in an
already-failing run and has not been reproduced on a passing tree, so it may be
benign shutdown timing — but it is exactly the silent-decline shape CLAUDE.md
§5 warns about (`#0470`): a shutdown that surfaces as a bare expired deadline
with no error in it.

## Acceptance criteria

- [ ] Characterize the shutdown path: under what conditions does `mountAndServe` return a deadline error after SIGTERM rather than `nil`, and is the deadline doing real work or masking a hang?
- [ ] If the error is timing-dependent noise, make the decline path say so explicitly (named error or log line) rather than a bare deadline; if it masks a real hang, fix the hang.
- [ ] `#0525`'s test still passes unchanged.
