## Description

Measured on production, 2026-09-12: `/`, `/workshops/programming-leds`, and `/archive/09-2026` all carry `og:url` but **no `<link rel="canonical">`**.

The apex-to-`www` and HTTP-to-HTTPS redirects already cover the largest duplicate case. What remains are variants that return 200 with the same content: tracking parameters (`?utm_source=…`, `?fbclid=…`), and any other query string or casing a link happens to carry. Without a canonical, search engines choose one themselves and can split a page's ranking signals across the variants.

> 🟢 Resolved 2026-09-13 — canonical emitted for all eight indexable routes and
> pinned equal to og:url by test; none on private/token/404/unknown/draft/
> withheld paths; parameter-free under query strings; HTML-escaped at
> injection. The dist placeholder guard's token inventory and the committed
> placeholder both carry the new token, so `npm run build` output stays
> consistent with it. All six criteria verified.

## Acceptance criteria

1. Every indexable public route — `/`, `/about`, `/privacy`, `/workshops`, `/workshops/{slug}`, `/subscribe`, `/archive`, `/archive/{slug}` — serves `<link rel="canonical">` in its server HTML, injected alongside the existing meta tags (`#0019`).
2. The canonical URL is built from `BASE_URL`, has no query string or fragment, and uses the same path form as `og:url`. **It must equal `og:url`**; add a test that fails if they diverge.
3. No canonical is emitted for private or token routes (`/confirm`, `/preferences`, `/unsubscribe`, `/admin`, `/account`, `/auth`, `/login`), or for unknown, draft, or withheld slugs — never point a canonical at a page that is not publicly available.
4. Requesting a public page with `?utm_source=x` still yields the parameter-free canonical.
5. The URL is HTML-escaped where injected.
6. `ISSUE=NNNN scripts/check.sh go ./internal/seo/... ./cmd/opencircuit/...` passes with no skips.

## Root cause

No route emitted `<link rel="canonical">`; URL variants returning 200 (?utm_source=, other query strings) split ranking signals.

## Fix

RouteMeta gained a `Canonical` field, set alongside og:url for the six static marketing routes and for published workshop and published archive detail pages. `substitute` replaces a new whole-element token (`%%OC_CANONICAL%%`) with `canonicalLink(m.Canonical)` — `<link rel="canonical" href="…">` built with `html.EscapeString` at injection — or "" where no canonical is allowed. Private/token routes, the fallback and 404 buckets, and unknown/draft/never-published-canceled/withheld slugs emit none. Built from BASE_URL with no query or fragment: the middleware passes r.URL.Path only, so ?utm_source=x yields the parameter-free canonical.
