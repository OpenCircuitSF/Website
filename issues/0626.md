## Description

Instagram, TikTok and YouTube cards live in a collapsed **Post by hand** row at the bottom of the page, with video channels collapsed a second time. **Copy caption** copies the post body, and whether that holds the real ShortLink is not established for each channel.

## Acceptance criteria

- [ ] Instagram, TikTok and YouTube Shorts cards appear inside their wave, and the bottom **Post by hand** row is gone.
- [ ] ~~Each card has one copy button whose clipboard text is the full paste-ready post, including that platform and wave's ShortLink and never a raw `{link}` token.~~ **Correction (2026-11-04, user's note below):** these platforms make links hard to use, so each channel offers two copy actions: **Copy with link**, the full post with that platform and wave's ShortLink, and **Copy text only**, which leaves out the URL and reads cleanly without it. Neither ever contains a raw `{link}` token.
- [ ] Within a wave, the three video channels appear as one compact **Video** group, one row per platform, because the same video goes to all three. Each row has its own copy actions and its own posted state.
- [ ] Copying each of the three channels in one wave yields three different URLs.
- [ ] The card shows the text and its ShortLink before copying, and marking a post as posted still works.
- [ ] If the ShortLink is not available, the card says so instead of copying text with a missing link.
- [ ] The Instagram card still offers its flyer tools.

## Notes

Depends on `#0623` and `#0625`. The Instagram copy action should make clear that it is for Reels.

Found while planning `#0622` and `#0623`, for this issue's planner:

- Instagram drafts deliberately carry no link (`noLinkChannels` in `internal/outreach/store.go`), so **Copy with link** must add `short_url` itself. TikTok and YouTube bodies already include it. **Copy text only** must remove it from those.
- `waveRowStatus` counts only automatic posts, so a wave with only hand-posted channels reads `Drafted · not scheduled` even once they are marked posted.
