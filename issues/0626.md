## Description

Instagram, TikTok and YouTube cards live in a collapsed **Post by hand** row at the bottom of the page, with video channels collapsed a second time. **Copy caption** copies the post body, and whether that holds the real ShortLink is not established for each channel.

## Plan

Written 2026-11-05 against `3b72b6b6`. All paths are under `web/src/` unless they start with `issues/`. No Go, API or migration change. `hand_links` is not used by this issue (decision 3).

### What the code does today

- A hand-posted channel means `!sendsItself(c)`, which is `instagram`, `tiktok`, `youtube`, **and Bluesky or Mastodon while they are not connected**. Those last two must not lose their cards when the bottom row goes.
- Draft text comes from `draftParts` in `internal/outreach/templates.go`, and `internal/outreach/outreach_test.go` pins it:
  - TikTok and YouTube: `lead`, summary, `Sign up: {link}`, `Open Circuit SF: https://www.opencircuitsf.com`, hashtags. The token becomes the real URL when the post gets its link.
  - Instagram: `lead`, summary, `Sign up at the link in our bio.`, hashtags. Never a URL.
  - Mastodon: `Sign up here: {link}`, or `Spots are limited, so you can sign up here: {link}`. Bluesky: no URL.
- Each slot has its own `short_url`, so three channels already give three URLs. A hand post with no link happens only if ShortLinks failed or is not set up. `CreatePost` and `Prepare` both reuse the slot's existing link.
- `OutreachPostCards.svelte` is mounted only by the bottom row. It already owns which card is editing, the discard dialog and the notices, so it is reused once per section.
- Save message writes only to automatic posts (`messageTargets`), so editing the shared Message never changes hand-posted text. This issue leaves that alone.

### Decisions already made

Apply these. Do not reopen them.

1. **The Video group is Instagram, TikTok and YouTube, by channel name, not `utm_medium`.** Instagram's medium is `social`, yet the criterion and the user's note put it with the other two. Its visible name becomes **Instagram Reels**. That is how the copy action "makes clear it is for Reels", and the server's label stays `Instagram` everywhere else. Not-connected Bluesky or Mastodon go in a second group headed **Post by hand** in the same section, using the same row.
2. **Text-only removes the whole sentence holding a link, not just the URL.** Taking out only the URL is what leaves "Sign up at today." Removing the sentence always reads cleanly, and its cost is losing other words in that sentence, which is why the row shows the text-only version before copying. Every URL goes, not only the ShortLink, so `Open Circuit SF: https://…` leaves too. Bracketed asides are removed alone. A lead-in left dangling on the line above goes with it.
3. **An unwritten section offers nothing to copy.** There is no text, and `#0623` deliberately does not draft into an unwritten section because that changes automatic scheduling (`PlanScheduleAll`, `waveRowStatus`). **The `BuildResults` gap is therefore not reached by this issue:** every copy action, including **Copy link**, needs a post, and a post in a slot holds that slot's link key, so its clicks reach the channel. `BuildResults` stays unchanged. Clicks that arrive before a post exists are matched once it does, because matching runs on each results read. The section says one line instead (below).
4. **Copy with link uses only `post.short_url`, never `hand_links`.** A link the post does not hold would not be attributed to it. A missing link shows a note and **Create link** (the existing `prepareOutreachPost`, which reuses the slot's link). **Copy text only** still works with no link, since it does not need one and can never contain a token.
5. **The clipboard falls back to selected text.** "Please try again" cannot help when the browser has refused. `Copied` never shows on a failure. The clipboard call must stay synchronous inside the click, because Safari refuses it otherwise: nothing may be awaited before `writeClipboard` is called.
6. **Hand-posted rows keep Copy link as a third, plain button.** Instagram already has it for the bio (`#0588`), and it is what the user needs on a platform where links only work in a profile. It appears on every video row, for consistency. Report this in the resolution notes so the user can veto it.
7. **After Mark posted, the copy buttons go**, as the Mark posted dialog already tells the user; **Unmark** brings them back. Only **Copy link** stays on a posted row.
8. **The Message box is hidden only when no automatic post can change any more**: every post in `autos` is `posted` or `queued`. It is not hidden for a section of customized drafts, because **Use shared message** needs its text.
9. **The strip counts every channel the way `sectionFullyPosted` does**, including a hand channel with no post. It reads as plain `Posted` exactly when that function is true.
10. **The copy guard reads literals in code.** All new visible text says "section", never the banned word. `lib/outreachHandCopy.ts` is scanned because its name starts with `outreach`.

```ts
// What a hand-posted row copies (#0626): the post with its ShortLink, or the
// post with no links at all, reading cleanly. Pure, so it is unit-testable.
import { LINK_TOKEN } from './outreach';
import { isHashtagParagraph } from './outreachMessage';
import type { OutreachChannel, OutreachPost } from './types';

/** Instagram's call to action. Pinned by internal/outreach/outreach_test.go. */
const BIO_CTA = 'Sign up at the link in our bio.';
const MARK = String.fromCharCode(0);
const BRACKETED = new RegExp(`\\s*\\([^()]*${MARK}[^()]*\\)`, 'g');
const ANY_URL = /(?:https?:\/\/|www\.)[^\s<>"]+/gi;
const URL_TAIL = /[.,;:!?)\]}'"…]+$/;
const NOT_A_SENTENCE_END = /(?:^|[\s("'])(?:mr|mrs|ms|dr|st|vs|jr|sr|approx)$|[^\s]\.[^\s]*$/i;
const DANGLING = /(?::|→|->|⇒|👇|⬇️?|-|–|—)$|\b(?:sign[ -]?up|register|rsvp|tickets?|details|more info|learn more|links?)(?: (?:here|below|now))?[.!]?$/iu;

function markLinks(line: string, shortUrl: string | null): string {
  let s = line.split(LINK_TOKEN).join(MARK);
  s = s.replace(ANY_URL, (m) => MARK + (m.match(URL_TAIL)?.[0] ?? ''));
  const bare = (shortUrl ?? '').replace(/^https?:\/\//i, '');
  return bare ? s.split(bare).join(MARK) : s;
}

function sentences(line: string): string[] {
  const out: string[] = [];
  let start = 0;
  for (let i = 0; i < line.length; i++) {
    if (!'.!?…'.includes(line[i])) continue;
    if (i + 1 < line.length && !/\s/.test(line[i + 1])) continue;
    if (line[i] === '.' && NOT_A_SENTENCE_END.test(line.slice(start, i))) continue;
    out.push(line.slice(start, i + 1).trim());
    start = i + 1;
  }
  const tail = line.slice(start).trim();
  if (tail) out.push(tail);
  return out;
}

function withoutLinks(line: string): string {
  const kept: string[] = [];
  for (const s of sentences(line.replace(BRACKETED, ''))) {
    if (!s.includes(MARK)) {
      kept.push(s);
      continue;
    }
    const after = s.slice(s.lastIndexOf(MARK) + 1).trim();
    if (isHashtagParagraph(after)) kept.push(after);
    else if (kept.length > 0 && DANGLING.test(kept[kept.length - 1])) kept.pop();
  }
  return kept.join(' ');
}

/** The post with every link taken out; '' when nothing else is left. A body with no link comes back as written. */
export function textOnly(body: string, shortUrl: string | null): string {
  const lines = body.replace(/\r\n?/g, '\n').split('\n');
  const marked = lines.map((l) => markLinks(l, shortUrl));
  if (!marked.some((l) => l.includes(MARK))) return lines.join('\n').trim();
  const out: string[] = [];
  for (const line of marked) {
    if (!line.includes(MARK)) {
      out.push(line);
      continue;
    }
    const left = withoutLinks(line);
    if (left !== '') {
      out.push(left);
      continue;
    }
    while (out.length > 0 && out[out.length - 1].trim() === '') out.pop();
    if (out.length > 0 && DANGLING.test(out[out.length - 1].trim())) {
      const prior = sentences(out[out.length - 1].trim());
      prior.pop();
      out[out.length - 1] = prior.join(' ');
    }
    out.push('');
  }
  return out.join('\n').replace(/\n{3,}/g, '\n\n').trim();
}

/** The post with its ShortLink in it, or null when it has none: never a raw token. */
export function withLink(body: string, shortUrl: string | null): string | null {
  if (!shortUrl) return null;
  const text = body.replace(/\r\n?/g, '\n').split(LINK_TOKEN).join(shortUrl).trim();
  if (text.includes(shortUrl)) return text;
  const line = `Sign up: ${shortUrl}`;
  if (text.includes(BIO_CTA)) return text.split(BIO_CTA).join(line);
  const paras = text.split('\n\n');
  if (paras.length > 1 && isHashtagParagraph(paras[paras.length - 1])) paras.splice(paras.length - 1, 0, line);
  else paras.push(line);
  return paras.join('\n\n');
}

export function handCopies(post: Pick<OutreachPost, 'body' | 'short_url'>): { withLink: string | null; textOnly: string } {
  return { withLink: withLink(post.body, post.short_url), textOnly: textOnly(post.body, post.short_url) };
}

/** The same video goes to these three, so they sit together in a section. */
export function isVideoChannel(channel: Pick<OutreachChannel, 'name'>): boolean {
  return channel.name === 'instagram' || channel.name === 'tiktok' || channel.name === 'youtube';
}

export function handChannelLabel(channel: Pick<OutreachChannel, 'name' | 'label'>): string {
  return channel.name === 'instagram' ? 'Instagram Reels' : channel.label;
}

export function handLinkLabel(channel: Pick<OutreachChannel, 'name' | 'automatic'>): string {
  if (channel.automatic) return 'Link to paste';
  return channel.name === 'instagram' ? 'Put this in your bio' : 'ShortLink';
}

/** False when the browser has no clipboard or refuses. Call it directly from the click: Safari needs that. */
export async function writeClipboard(text: string): Promise<boolean> {
  try {
    await navigator.clipboard.writeText(text);
    return true;
  } catch {
    return false;
  }
}
```

### Edge cases and where each is handled

| Case | What happens |
