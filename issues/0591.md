## Resolution

1. **Terminology sweep.** Visible copy now says "Short link" (was Tracked
   link), "Create link" (was Prepare link), "On hold" (was Held), "Post"
   (column header, was Wave), "Bluesky server" (was PDS URL), and plain
   phrases for the remaining "wave"/"campaign"/"tracked link" strings in
   `Outreach*.svelte` and `lib/outreach*.ts` (Composer, Links, Locations,
   Results, WaveRow, ScheduleAllDialog, FlyerEditor's print-tab title,
   outreach.ts, outreachCards.ts, outreachMessage.ts, outreachLinks.ts,
   outreachResults.ts, outreachConnections.ts). The `held` status kind became
   `on_hold`. Guard: `web/src/lib/outreachCopy.guard.test.ts` parses the
   Svelte files (svelte/compiler) and the lib helpers (TypeScript) and checks
   only text nodes, visible attribute text and string literals; the method is
   documented at the top of the file and the detector is itself tested for
   what it flags and what it leaves alone (identifiers, comments, CSS, keys,
   `===` operands, `utm_campaign`).
2. **Editor.** Verified already done: posting actions are on the card (#0581)
   and the duplicate title is gone (#0582). Added: the action row is Save and
   Cancel (plus Create link only when the link is missing), Delete at the far
   end in the danger style; Schedule / Unschedule moved beside the schedule
   picker; the redundant Copy content button was removed (the card has Copy
   caption).
3. `WorkshopEditor.svelte`: the button reads "Email the list".
4. A 404 for an unknown workshop shows "Workshop not found / This workshop no
   longer exists." with an "All outreach" link, no Retry and no Edit workshop
   link (`OutreachPanel` gained `onNotFound`); an unknown flyer shows "Flyer
   not found / This flyer no longer exists." with "All flyers". Other load
   failures still offer Retry.
