## Review notes

Opus review, 2026-10-18. Approved with small fixes in `6e4c0ca`.

- **Guard (item 1).** Mutation-tested against real files, each restored by
  sha256: a banned word in a template text node, a static `aria-label`, a
  template-literal attribute, a lib helper's returned string, a lib template
  literal, and a label map's *value* (`FIELD_LABELS` `label: 'PDS URL'`) were
  all caught. Object keys and `===` operands are skipped only as keys and
  operands; the value side of a map is still checked. **One hole found and
  closed:** the Svelte walker returned on every `TS*` node, so a script-level
  `const LABELS = { held: 'Held' } as const` (or `satisfies`, `!`) hid every
  string inside it. It now walks the wrapped expression; the detector test
  pins it.
- **`held` → `on_hold` (item 1).** Client-only. `StatusKind` is computed in
  `lib/outreachCards.ts` from the server's boolean `post.held`, which is
  unchanged; no Go or migration value is `'held'`, and no CSS rule keyed on
  `status-held` existed.
- **Copy content (item 2).** Manual channels keep Copy caption on the card in
  every state the composer offered Copy content except `queued`, which a
  manual channel never reaches. Automatic, configured channels lose their
  only copy button; the text is still selectable in the preview and editor,
  and C9 named the button redundant. `ComposerActions.canCopy` is now unused.
- **Not-found (item 4).** 404 alone gives the not-found state; a 500 still
  offers Retry (tested). The heading row with Edit workshop is not rendered.
  `OutreachPanel` now also says "This workshop no longer exists." itself when
  a future caller passes no `onNotFound`, rather than rendering nothing.
- **Wording (item 5).** Fixed: the Results "Every link" table printed the raw
  wave name (`last-call`); it now uses the existing `waveLabel`. The Schedule
  all hint named Reminder and Last call even when only one is offered and
  said "too" when nothing else was chosen; it reads "Tick a post above to
  schedule it." The "Post" column header was kept: its values are Announce /
  Reminder / Last call, matching the card titles.

Follow-ups for the orchestrator (not filed): remove the dead
`ComposerActions.canCopy`; the Results table still shows `post.status` raw
(lowercase API values); the guard cannot see dynamic server strings such as
`wave_label`, so jargon arriving from Go is outside its reach.

## Resolution

1. **Terminology sweep.** Visible copy now says "Short link" (was Tracked
   link), "Create link" (was Prepare link), "On hold" (was Held), "Post"
   (column header, was Wave), "Bluesky server" (was PDS URL), and plain
   phrases for the remaining "wave"/"campaign"/"tracked link" strings in
   `Outreach*.svelte` and `lib/outreach*.ts` (Composer, Links, Locations,
   Results, WaveRow, ScheduleAllDialog, FlyerEditor's print-tab title,
   outreach.ts, outreachCards.ts, outreachMessage.ts, outreachLinks.ts,
   outreachResults.ts, outreachConnections.ts). The `held` status kind became
   `on_hold`. Guard: `web/src/lib/outreachCopy.guard.test.ts` parses the
   Svelte files (svelte/compiler) and the lib helpers (TypeScript) and checks
   only text nodes, visible attribute text and string literals; the method is
   documented at the top of the file and the detector is itself tested for
   what it flags and what it leaves alone (identifiers, comments, CSS, keys,
   `===` operands, `utm_campaign`).
2. **Editor.** Verified already done: posting actions are on the card (#0581)
   and the duplicate title is gone (#0582). Added: the action row is Save and
   Cancel (plus Create link only when the link is missing), Delete at the far
   end in the danger style; Schedule / Unschedule moved beside the schedule
   picker; the redundant Copy content button was removed (the card has Copy
   caption).
3. `WorkshopEditor.svelte`: the button reads "Email the list".
4. A 404 for an unknown workshop shows "Workshop not found / This workshop no
   longer exists." with an "All outreach" link, no Retry and no Edit workshop
   link (`OutreachPanel` gained `onNotFound`); an unknown flyer shows "Flyer
   not found / This flyer no longer exists." with "All flyers". Other load
   failures still offer Retry.
