## Description

The public archive **API** returns 404 for an unknown or non-sent slug and 410 for a withheld one (`#0123`, `#0318`). The **HTML** route `/archive/{slug}` returns 200 for all of them, serving the SPA shell. Search engines therefore see a successful page where the content is gone, which invites soft-404 handling and keeps withdrawn URLs around longer.

## Acceptance criteria

1. `GET /archive/{slug}` returns **410** for a withheld campaign and **404** for an unknown, draft, or unsent slug, matching the API.
2. The response body is still the SPA shell, so the in-app not-found and withheld views keep working.
3. A published campaign still returns 200 with `#0519`'s server content.
4. Consider the same for `/workshops/{slug}`, and record the decision.
5. `ISSUE=NNNN scripts/check.sh go ./internal/handlers/... ./internal/seo/... ./cmd/opencircuit/...` passes.
