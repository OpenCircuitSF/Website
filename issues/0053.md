## Description

`/workshops` — upcoming sessions in chronological order, past sessions in reverse chronological order.

## Acceptance criteria

- [ ] Two sections, upcoming and past, each rendering workshop cards
- [ ] Cards show title, date, location name, summary, and interest tags
- [ ] Canceled workshops shown with a clear canceled badge
- [ ] Empty state when nothing is scheduled, with a subscribe prompt
- [ ] Home page's "next up" section (#0015) switched from placeholder to real data
- [ ] Responsive from 375 px up; dates formatted in the site's local timezone
- [ ] `npm run check` and `npm test` pass

## Notes

PRD §5.1. Past workshops are worth showing — they are the evidence that this is a real, recurring group, which is exactly what a first-time visitor arriving from a social link is trying to assess.
