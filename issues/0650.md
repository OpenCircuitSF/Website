## Description

These came out of `#0648`'s reviews, and none of them affects today's production data.

1. Some Luma events belong to workshops that are still drafts on the site. They show under **On Luma only** without saying so. The list could mark them, for example "draft on the site", or leave them out.
2. `streetPart` keeps the city when an address has no street-type word and no comma before the city, for example `3 Embarcadero Center San Francisco`. That would produce a false Location difference. No production address is written that way today.
3. `streetPart` drops a suite number that comes after the street type, on both sides. A difference only in the suite therefore isn't reported.
4. If someone wants it, add an admin-pinned Luma URL per workshop so a wrong match can be overridden. `#0648`'s plan deferred this because the matching rule paired every production workshop correctly.

## Acceptance criteria

- [ ] On Luma only marks, or leaves out, Luma events that match a site draft.
- [ ] An address with no street-type word is compared without its city. There is a test for this.
