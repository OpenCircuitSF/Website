## Description

Brennan, 2026-10-17, after the image upload refused with "MEDIA_DIR is
unset": "Every ENV var really should be something I set in Settings."

`#0564` did this for the seven outreach connection variables. Apply the same
pattern to every remaining variable that can safely live in the database.
Some cannot, and the plan must say which and why. A variable is needed before
the database is reachable, or it protects the admin login itself, or it
names the host the passkeys are bound to.

`internal/config` reads today: `ADMIN_EMAIL`, `AWS_REGION`, `BASE_URL`,
`DATABASE_URL`, `EMAIL_FROM`, `EMAIL_LIST_DOMAIN`, `EMAIL_REPLY_TO`,
`MEDIA_DIR`, `SES_CONFIGURATION_SET`, `SES_EVENTS_TOPIC_ARN`,
`SES_INBOUND_BUCKET`, `SES_INBOUND_TOPIC_ARN`, `SESSION_SECRET`, `STORAGE`,
`WEBAUTHN_RP_ID`, `WEBAUTHN_RP_ORIGIN`, plus the `#0564` set, plus anything
`cmd/opencircuit` reads directly (`PORT`, `MAILER_NOOP`,
`SEND_WORKER_ENABLED`, `SES_SANDBOX`, dev flags). The planner re-derives the
full list from the code.

## Acceptance criteria

- [ ] **Classify every variable** in the plan as one of:
  - **Settings**: moves to admin Settings, with DB then env then default
    precedence as in `#0564`.
  - **Bootstrap**: stays in `config.env`, with a one-line reason. Expected
    examples: `DATABASE_URL`, `SESSION_SECRET`, `WEBAUTHN_RP_ID`,
    `WEBAUTHN_RP_ORIGIN`, `PORT`, `STORAGE`.
  - **Dev-only**.

  Treat safety guards with care. `MAILER_NOOP`'s production refusal (AGENTS.md
  §10) must not become something a Settings click can bypass.
- [ ] Settings variables appear in the admin Settings section, grouped (for
      example Email, Amazon SES, Media), following `#0564`'s UI and
      write-only-secret patterns where a value is sensitive. Each field shows
      its source (saved, environment, default, unset).
- [ ] Each setting takes effect without a restart where practical. Where a
      restart is unavoidable (for example a worker that only starts at boot),
      the UI says so next to the field.
- [ ] **`MEDIA_DIR`** gets a production default of `/var/www/media`, or is
      set in Settings. The upload error points to Settings and states that
      the directory must also be writable by the service
      (`scripts/enable-media-upload.sh`).
- [ ] Values are validated as `#0564` does; changes are audited by field
      name only.
- [ ] `docs/configuration.md` gains a column saying where each variable is
      set, and `.env.example` stays in step (its guard stays green).
- [ ] Go handler and store tests, plus jsdom SPA tests. Verified with
      `ISSUE=0566 scripts/check.sh` plus the AGENTS.md §5 guard packages the
      change reaches. Zero skips.
