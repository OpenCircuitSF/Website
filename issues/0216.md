## Description

`#0120`'s phase-3 review passed the fix and found three comment inaccuracies in
the two new test files. No behavioural impact — but the first one overstates
what the tree proves, which is the defect class this repo has now hit four times
(`#0190`, `#0192`, `#0196`, `#0199`).

**1. It cites three tests that do not exist.**
`web/src/lib/modalKeydown.test.ts` names
`Admin.escapeWiring.structuralGuard.test.ts`,
`CampaignEditor.escapeWiring.structuralGuard.test.ts`, and
`Campaigns.escapeWiring.structuralGuard.test.ts` as proving the panel wiring.
None exists.

**Worse than a dangling pointer: the claim itself is false.** Nothing asserts
the *positive* wiring — that each panel's `onkeydown` is bound to the same node
its focus effect targets. `modalEscapeGuard.test.ts` asserts only the **absence
of the bad shape**. So a reader is told the wiring is pinned when it is not.

`#0196` built a guard against exactly this — a comment citing a `Test*`
identifier no function defines — but it scans **Go** comments only. These are
TypeScript.

**2. A stale reason for a real conclusion.** `modalEscapeGuard.test.ts`'s header
says `CampaignSendDialog`'s panel `onkeydown` "was deleted outright". That
describes the **abandoned first attempt**; what shipped binds `handleKeydown` to
the panel, deliberately, so `#0197`'s pinned expression stays byte-identical.
The conclusion holds, the stated reason does not.

**3. A miscount.** The same header says "nine sites across three files". The
review enumerated from the pre-fix blobs: **8 sites across 4 files**
(`Admin.svelte` ×5, `CampaignEditor` ×1, `CampaignSendDialog` ×1, `Campaigns`
×1). The `WorkshopEditor`/`Workshops` hits a naive grep returns are comment text
inside `#0052`'s own notes describing the shape it removed.

**`#0094`'s new test file has two more of the same defect**, found by its own
review: its header cites `web/HANDOFF` (no such file — `web/` has no `.md` at
all) and "see this repo's `CLAUDE.md` §… discussion" with a literal unfilled
ellipsis. Same class, same commit family, so they are folded in here.

**The stale claim has already propagated once.** `#0094`'s implementation
notes repeat it — describing `CampaignSendDialog`'s panel `onkeydown` as
"deleted outright" — because it read `modalEscapeGuard.test.ts`'s header and
believed it. That is what a false comment costs: not the original error, but
every reader downstream. Check `issues/0094.md` when fixing item 2.
