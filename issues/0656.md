## Plan

### Decisions recorded here

1. **One source of truth for guide metadata: `web/src/content/guides/guides.json`.** It holds slug, title, hook, tags (and minutes for topics) for every guide. The router, `topics.ts`, `GuidesIndex.svelte`, `pageTitle.ts` and the Go server all read it, so the Go and TS slug sets cannot diverge. This follows the `#0520` precedent (`about.json`/`privacy.json` are embedded through `web.StaticContent()` and read by both runtimes) instead of a second hand-typed Go list plus a regex parity guard over `router.ts`. The acceptance criterion's "guard keeps the sets equal" is met by having one copy rather than two. The tests below pin that both sides really read it. The file goes in a **subdirectory** on purpose: `internal/seo/staticpages.go`'s `mustLoadStaticPages` turns every top-level `web/src/content/*.json` into a static page and panics on one without an `h1`, and it skips directories.
2. **The list is still a compile-time constant.** `//go:embed src/content` bakes the JSON into the binary, so no store lookup runs and nothing about drafts is revealed.
3. **OG cards reuse the event card builder.** `(*cardRenderer).renderCard(title, meta)` through `Site.serveCard`, served at **`GET /guides/{slug}/og.png` for every catalog slug, including the workshop guide**. The guide stays at `/workshops/programming-leds`, but its card does **not** go at `/workshops/programming-leds/og.png`. That URL is already `WorkshopCardHandler`'s legacy route (`#0614`) and still renders the **production event** of the same slug, so posts that already carry it keep their image. The meta line is `Guide · N min` for a topic and `Workshop guide` for a workshop guide. Cache key: `"guide:"+slug`. An unknown slug returns 404.
4. **Event → guide matching uses the slug.** An event links to workshop guide `g` when `slug === g` or `slug` is `g` + `-` + digits only (`programming-leds`, `programming-leds-2`). Why: `internal/workshops/store.go`'s `slugify` derives slugs from the title, and repeats get a numeric suffix, so every "Programming LEDs" run matches with no migration, no admin field and no UI. `programming-leds-advanced` does not match. The known false positive is a differently themed event titled "Programming LEDs 2". An explicit field can replace this later. This is SPA-only. The Go server fallback for `/events/{slug}` is unchanged.
5. **Header nav order: Events, Guides, About, Subscribe.** The fallback nav follows the same order (Home, Events, Guides, About, Subscribe, Archive, Privacy policy).
