## Description

The Workshops-repo session (`~/Developer/OpenCircuitSF/Workshops`) built the client side of a set of static, Svelte-interactive guides with no backend. That work sits **uncommitted** in the worktree `.claude/worktrees/programming-leds-guide` on branch `guide/programming-leds`, off `3e03ce5e`. `web/node_modules` there is an untracked symlink to the main checkout's; never commit it. The copy's source of truth is `Workshops/workshops/programming-leds/` (`STUDENT_GUIDE.md`, `README.md`, `CLASS_PLAN.md`).

What exists on the client:

- **`/workshops/programming-leds`**: the Programming LEDs student guide, route `workshop-guide`, view `GuideProgrammingLeds.svelte`, static h1 "Programming LEDs". `router.ts` exports `WORKSHOP_GUIDE_SLUGS = new Set(['programming-leds'])`, a fixed list in code with no store lookup. `legacyRedirectTarget` skips those slugs, and every other `/workshops/{slug}` still maps to `/events/{slug}` (`#0614`).
- **`/guides`**: a `STATIC_ROUTES` entry, route `guides`, view `GuidesIndex.svelte`, h1 "Guides".
- **`/guides/{slug}`**: route `topic-guide`, view `TopicGuide.svelte`, only for slugs in `TOPIC_GUIDE_SLUGS` (`one-wire-many-leds`, `delay-vs-millis`, `baud-rate`, `charge-only-cables`, `led-power-budget`, `esp32-c3-supermini-pinout`). Any other slug is not-found. Content and metadata (slug, title, hook, minutes, tags, takeaway, post) live in `web/src/lib/topics/topics.ts`.
- Supporting code: `web/src/lib/guide/*` (`leds.ts` ports the firmware's colour math), `clock.svelte.ts`, and `progress.svelte.ts` (localStorage, try/catch). Eight `--guide-*` tokens in `app.css` across all three theme blocks. Images under `web/public/img/workshops/programming-leds/`.
- The peer reports: svelte-check 0 errors, web suite 123 files / 5175 tests passing. **No Go tests and no `check.sh` have been run.** Rendering was only checked by headless screenshot in dark mode, never in light theme, at mobile widths or with real clicks.

### Decisions (user, 2026-11-14)

- The student guide lives at **`/workshops/programming-leds`**. This was chosen knowing that production has a **published event with exactly that slug** (Sept 18, 2026), so old `/workshops/programming-leds` links for that event will now land on the guide. Do not "fix" this back.
- Add **"Guides" to the site header nav** and to the SEO fallback nav.
- Link the **"Student guide"** from Programming LEDs event pages.
- The board photos' usage rights are confirmed. Ship them.
- 8 LEDs is correct. Strips vary, and the firmware's `NUM_LEDS` is 8.
