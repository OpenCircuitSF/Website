# 0150 — `scripts/testdb.sh gc` destroyed a running agent's database, because sweeping was the default

## Description

`scripts/testdb.sh gc` dropped **every** `opencircuit_test_*` database unconditionally. An implementer finishing `#0147` ran it as a cleanup step and destroyed `opencircuit_test_0055b`, which belonged to a concurrently running `#0055` agent.

The database itself is cheap — a ~0.2s clone from the template — and nothing was lost. The defect is the shape of the command: the *destructive-to-everyone* action was the bare default, sitting one word away from the safe per-agent `drop`, in a project whose whole concurrency model (§5a) is "every agent gets its own database". `CLAUDE.md` even listed `gc` under cleanup, so running it was following instructions.

The agent that did it disclosed it unprompted, which is the only reason it was caught.

## What has been done

Fixed immediately by the orchestrator, because three agents were running at the time and the next reflexive `gc` would have done it again:

- `gc` now **refuses without `--all`**, listing the databases it would have dropped and pointing at `drop <ISSUE>` for the caller's own.
- With `--all`, it **skips any database with live connections** rather than racing whoever holds them.
- `CLAUDE.md` §5a's cleanup guidance now says plainly that `gc` is not a cleanup step, and the script's own usage header says the same.

## Acceptance criteria

- [x] A bare `gc` cannot destroy another agent's database — verified: it refuses and lists them
- [x] `gc --all` skips databases with active connections
- [x] `CLAUDE.md` §5a and the script header describe the new semantics
- [ ] A guard test covers the refusal, so the safe default cannot quietly regress the way `#0140`'s `pipefail` did
- [ ] Check the other scripts for the same shape — an unqualified destructive default that assumes the caller is alone. `db-reset.sh` is the obvious candidate to read

## Notes

This is the third instance today of a shared-resource assumption failing under concurrency, after the shared git index (`CLAUDE.md` §8a) and the tracked `web/dist/index.html` placeholder (`#0141`). The pattern is the same each time: a tool written for one agent working alone, used by three.

Worth noting what *didn't* fail: the disclosure norm. Every one of these was caught because the agent that did it said so.
