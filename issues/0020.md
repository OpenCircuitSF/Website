## Description

Generated `sitemap.xml` covering the static routes plus every published workshop, and a `robots.txt` that allows the public site while excluding the admin and API namespaces.

## Acceptance criteria

- [ ] `GET /sitemap.xml` returns valid XML with `<loc>` and `<lastmod>` for `/`, `/about`, `/workshops`, `/subscribe`, and each published workshop
- [ ] Draft, unpublished, and canceled workshops are excluded
- [ ] `GET /robots.txt` allows `/` and disallows `/admin`, `/account`, `/api`, `/auth`, `/confirm`, `/preferences`, `/unsubscribe`
- [ ] `robots.txt` references the sitemap URL
- [ ] Sitemap is generated from the database, not hand-maintained, and cached with invalidation on workshop mutation
- [ ] Both served with correct content types (`application/xml`, `text/plain`)

## Notes

PRD §7.4. Disallowing `/confirm`, `/preferences`, and `/unsubscribe` matters: those URLs carry tokens, and an indexed token URL is a token leak.

Until #0051 lands, the workshop portion of the sitemap can be empty — ship the static routes now.
