## Resolution

- **Mastodon account on reload:** `Manager.reloadLocked` starts a background `verify_credentials` (`lookupMastodonAccount`) whenever the Mastodon client is rebuilt, bounded by a 5s context, so neither startup nor a settings save waits on it. Success caches `@user@host` exactly as a manual Test does; failure keeps the bare host and logs only `group=mastodon`, never the token or upstream text. Hosts in the reserved `.test`/`.example`/`.invalid` TLDs are skipped (they cannot resolve). All inside `internal/outreachconn`; `cmd/opencircuit/main.go` is untouched.
- **`splitBody`:** resolved by documentation. A body carries no marker saying whether its final hashtag-only paragraph is template or typed, so it stays tail; Save message recomposes message + tail, so nothing is lost, only that paragraph is not editable from the Message field. A real fix needs the server to mark the appended paragraph. Documented on `splitBody` and pinned by a test (including the round trip).
- **Single alert:** in `ServerSettings.svelte` only the mount that owns the precedence note (`showNote`) renders `role="alert"` and Retry; the second mount shows the text quietly. A two-mount shared-store test asserts one alert and one Retry.
- **`thumbOK`:** named interface `thumbOKer` plus `var _ thumbOKer = (*outreach.Publisher)(nil)`.
