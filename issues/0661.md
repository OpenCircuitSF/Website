## Description

Two small cleanups from `#0656`'s review:

1. The plain-text regex in `web/src/lib/guides.test.ts` contains a literal U+00AD byte. It works, but the character is invisible in the source, which is the hazard AGENTS §8 warns about. Write it as the six-character ASCII escape instead: backslash, `u`, `00AD`. Then read the file's bytes back to prove the literal byte is gone (`python3 -c "print(open(P,'rb').read())"`).
2. `internal/seo/seo.go` and `internal/seo/fallback.go` put the `internal/guides` import in a group of its own. Merge it into the existing internal import group.
