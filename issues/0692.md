## Description

On 2026-11-16 the user asked for guides on common electrical components (resistors, capacitors, transistors, MOSFETs and LEDs), noting that "interactive diagrams are very helpful". The work is split across `#0690`, `#0691` and `#0692` so three agents can build at once, each in its own worktree, on the topic-guide framework from `#0656`, `#0666`, `#0667` and `#0670`–`#0672` (follow `#0670`'s layout: logic in a plain TS module, a thin Svelte demo, entries appended after an issue marker in `TOPIC_BODIES` and `demos.smoke.test.ts`).

Every new topic sets `"set": "components"`. That set does not exist on main yet, and an empty set fails `guideSets.test.ts` and `GuidesIndex.behavior.test.ts`, so **each of the three issues adds the same set entry** (appended last in `sets`, exactly as below) and updates those two tests' expected set lists. The orchestrator keeps one copy when merging.

```json
{
  "id": "components",
  "title": "Components",
  "blurb": "Resistors, capacitors, LEDs, transistors and MOSFETs: what each part does and how to pick the right one."
}
```

Audience: makers at an Open Circuit SF workshop, mostly beginners, building with an ESP32-C3 SuperMini (3.3 V logic, about 20–40 mA per pin at most and less is better) and a USB 5 V supply. Use those numbers in the examples.

Guides in this issue (slugs may be adjusted):

- `bjt-transistor-switch` — an NPN transistor (2N2222 / 2N3904) as a switch from a 3.3 V pin: base resistor, collector load, saturation. Demo: a circuit with a pin toggle and sliders for base resistor and load current; shows base current, required gain, whether it saturates, and Vce, with the transistor's pins labelled (E-B-C for TO-92).
- `mosfet-switch` — a logic-level N-channel MOSFET (e.g. AO3400, IRLZ44N) as a low-side switch: gate resistor, gate pull-down, why a non-logic-level part (IRFZ44N) barely turns on at 3.3 V. Demo: pick a part, toggle the gate, see Rds(on) at that Vgs, the heat in the MOSFET at a chosen load current, and the load on or off.
- `flyback-diodes` — switching a motor, relay or solenoid: why the coil kicks back and where the diode goes. Demo: a switch-off animation with the diode in, out, or reversed, plotting the voltage spike at the transistor (a teaching model, labelled as such).
- `bjt-vs-mosfet` — which to choose: a short comparison with a picker (load current, supply voltage, switching from 3.3 V) that recommends a part type and shows why.

## Acceptance criteria

1. Each guide has an entry in `guides.json` with `"set": "components"`, a body in `topics.ts`, and at least one **interactive diagram**: the reader changes something (drags, taps, picks a value) and an inline SVG circuit or part drawing plus the numbers update live.
2. The logic is in a plain TS module with unit tests (formulas, lookups, edge cases). Each demo has one jsdom behaviour test. Demos meet the keyboard and ARIA basics: real buttons or inputs, labels, visible focus using `--accent`.
3. Illustrations are inline SVG, or SVG rendered to PNG with `rsvg-convert`. Never launch a browser (AGENTS.md §8).
4. Facts are standard and checkable (E-series values, IEC 60062 colour code, datasheet-typical values for named parts). Mark anything from memory under `### Assumptions`.
5. `ISSUE=0692 scripts/check.sh` passes, and so do the scoped Go checks `internal/guides`, `internal/seo` and `cmd/opencircuit`.
