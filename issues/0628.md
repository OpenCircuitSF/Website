## Description

`shownChannels` in `internal/handlers/admin_outreach.go` returns only enabled channels, so a channel turned off in Settings simply vanishes from the Outreach screen.

## Acceptance criteria

- [ ] The board shows a disabled channel as off, with a link to the setting.
- [ ] A disabled channel gets no drafts or wave cards, and no ShortLinks are created for it.
- [ ] No schema change is made.

## Notes

Depends on `#0624`. With `#0623` every channel is on by default, so this appears only after an admin turns one off.
