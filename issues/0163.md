## Description

`#0158` replaced every `time.Now().UnixNano()`-derived test identifier with `testdb.Unique()`, across 28 files. It missed four helpers, in two packages that consequently have **zero** `testdb.Unique()` call sites — because they render the same clock as a formatted string instead:

```
internal/middleware/auth_test.go:39            zz-mw-<label>-<ts>@example.com
internal/middleware/auth_test.go:48            zz-mw-tok-<label>-<ts>
internal/middleware/clientip_signup_test.go:91 zz-clientip-<ts>@example.com
internal/audit/audit_test.go:36                zz-audit-<label>-<ts>@example.com
```

where `<ts>` is `time.Now().UTC().Format("20060102T150405.000000000")` — the same clock that repeats on **94.7%** of adjacent reads (`#0158`), just wearing a different coat. `#0158` searched for `UnixNano()` and `#0160` for `UnixNano|UnixMilli|UnixMicro`; `.Format(…)` matches neither.

**Three of the four are latent**: a distinct `label` argument discriminates every call site, so the clock is not load-bearing. **The fourth is a live defect**: `internal/middleware/clientip_signup_test.go:91`'s `uniqueSignupEmail` takes **no label**, so the clock is its only discriminator, and it is called from two tests separated by nothing but a database insert. That is exactly the "masked by intervening round trips" shape `#0158`'s review flagged for `uniqueAdminWorkshopTitle` — masked until it isn't.

## Acceptance criteria

- [x] All four helpers draw uniqueness from `testdb.Unique()`; `internal/middleware` and `internal/audit` stop being the two packages with no call sites
- [x] Keep the `label` arguments — they make failures readable, and the point is that the *clock* stops being the discriminator, not that labels are redundant
- [x] `uniqueSignupEmail` is fixed first and separately noted, since it is the one with a real collision window
- [x] A test proves back-to-back calls to each helper are distinct, in the shape `#0158` used
- [x] **Sweep on the axis that found this one**: enumerate every identifier-minting helper in the tree and check what discriminates it, rather than grepping for known-bad tokens. `#0158` searched for a function name, `#0160` for three, and this survived both — the search that worked was reading the helpers
- [x] `ISSUE=0163 scripts/check.sh go ./internal/...` passes, and `internal/middleware` and `internal/audit` pass under `-shuffle` on two fresh seeds

## Root cause

Four helpers built "unique" test identifiers by formatting `time.Now().UTC()`
to nanosecond-looking precision
(`time.Now().UTC().Format("20060102T150405.000000000")`) instead of calling
`time.Now().UnixNano()` directly. It is the identical repeating-clock defect
`#0158` fixed in 28 files — a 200,000-pair probe there measured that clock
repeating on 94.7% of adjacent reads — just spelled as a formatted string.
`#0158`'s sweep grepped for `UnixNano()` and `#0160`'s for
`UnixNano|UnixMilli|UnixMicro`; `.Format(…)` matched neither pattern, so
both sweeps walked past all four call sites without ever reading them.

Three of the four (`uniqueAuthEmail`, `uniqueSessionToken`, `seedUser`) take
a `label` argument that discriminates every call site in the tree today, so
the clock was decoration rather than load-bearing — latent, not live.
`uniqueSignupEmail` (`internal/middleware/clientip_signup_test.go:91`) takes
no `label`, so the clock was its *only* discriminator, and
`TestSignupSurvivesUnparseableXFF` / `TestSignupSurvivesPortOnRightmostEntry`
call it back-to-back separated by nothing but a database insert — exactly
the "masked by intervening round trips until it isn't" shape `#0158`'s
review flagged for `uniqueAdminWorkshopTitle`.

## Fix

Replaced each helper's `"..." + time.Now().UTC().Format("20060102T150405.000000000") + "..."`
construction with `fmt.Sprintf("...%d...", testdb.Unique())`, keeping every
existing `label` argument and prefix string unchanged so failure messages
read the same as before. `uniqueSignupEmail` was fixed first, as the issue
required, since it is the only one of the four with a real collision
window.

`internal/audit/audit_test.go`'s `"time"` import became unused once
`seedUser` stopped calling `time.Now()` and was removed; `fmt` and
`internal/testdb` were added to all three files' import blocks (already
imported by each package's separate `main_test.go`, but each `_test.go`
file needs its own import).

Added one back-to-back-collision regression test per helper, in the shape
`internal/subscribers/suppressions_test.go`'s
`TestUniqueSuppressionEmail_NeverCollidesAcrossManyBackToBackCalls`
(`#0108`/`#0160`) uses: call the helper 20,000 times in a tight loop with no
intervening work and fail on the first repeat.
`TestSeedUser_BackToBackCallsNeverCollide` (audit) is a two-call DB-backed
variant instead, since `seedUser` inserts a row per call and `users.email`
carries a real `UNIQUE` constraint (`migrations/000001`) — 20,000 inserts
per test run was unnecessary and would have meaningfully slowed the suite
for no extra coverage; two calls are enough to prove no collision, and a
collision there surfaces as the same `t.Fatalf` a real caller would hit.

**Enumeration of every identifier-minting helper in the tree** (the
criterion the issue calls out as the one that matters most): searched for
every function whose name matches `unique*`/`test*Email|Slug|Title|Token|ID`
(case-insensitive) and separately grepped every file containing a `"zz-"`
literal prefix, then read each helper's body rather than trusting the name.

## Gotchas

- **The `"time"` import removal was file-specific.** `internal/audit/audit_test.go`
  had no other `time.` usage once `seedUser` stopped calling `time.Now()`,
  so `gofmt`/`go vet` would have failed with "imported and not used" had it
  stayed; the other two files still use `time.Hour`/`time.Now()` elsewhere
  and kept the import.
- **`internal/audit`'s regression test needs a database**, unlike the other
  three, because `seedUser` inserts a row as part of building the
  identifier rather than returning a bare string. `TestSeedUser_BackToBackCallsNeverCollide`
  skips cleanly (via `auditTestPool`) when `TEST_DATABASE_URL` is unset,
  same as every other DB-backed test in the file, rather than needing a
  separate no-DB variant.

## Notes

Reported by `#0160`'s phase-3 review under `CLAUDE.md` §9, found by enumerating identifier-minting helpers rather than by searching for the token `#0158` had fixed.

The lesson is worth keeping: two sweeps for "the thing we just fixed" both missed a fourth spelling of the same idea. A search finds what you already know to look for; reading the helpers found what nobody had named.
