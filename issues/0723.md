**3. The GPIO header (`pi-gpio-pinout`)**

```ts
export const GPIO_LOGIC_V = 3.3;
export const GPIO_MAX_MA_PER_PIN = 16;   // raspberrypi.com/documentation, GPIO section
export const GPIO_MAX_MA_TOTAL = 50;
export type PinKind = 'power5' | 'power33' | 'ground' | 'gpio';
export type PinFunction = 'I2C' | 'SPI' | 'UART' | 'PWM' | 'I2S' | 'HAT ID';
export interface HeaderPin {
  physical: number;           // 1–40
  kind: PinKind;
  gpio: number | null;        // BCM number, null for power and ground
  functions: PinFunction[];
  roles: string[];            // shown as tags, e.g. 'I2C SDA', 'PWM0', 'UART TX'
  facts: string[];
  warning: string | null;     // only the two 5 V pins
}
export const PI_HEADER: HeaderPin[];   // 40 entries, physical order
export type PinScheme = 'physical' | 'gpio';
export function pinByPhysical(n: number): HeaderPin;   // throws outside 1–40
export function pinByGpio(g: number): HeaderPin;       // throws if not on the header
export function pinLabel(p: HeaderPin, scheme: PinScheme): string;
//  physical: String(p.physical) for every pin
//  gpio:     `GPIO${g}` for GPIO pins; '5V', '3V3', 'GND' otherwise
export function pinTitle(p: HeaderPin): string;
//  'Pin 11: GPIO 17', 'Pin 2: 5 V power', 'Pin 1: 3.3 V power', 'Pin 6: Ground'
export function pinsWith(f: PinFunction): number[];  // physical numbers, ascending
export function gpiozeroLine(p: HeaderPin): string | null;
//  'led = LED(17)  # GPIO 17 is physical pin 11'; null for power and ground
```

`facts` per kind (draft; keep the facts):

- `power5`: `Connected to the board’s 5 V supply: it can power small 5 V parts, or power the Pi itself.`, `How much it can give depends on your power supply, less what the Pi uses.` `warning`: `Never connect a 5 V pin to a GPIO pin. GPIO pins are 3.3 V and not 5 V tolerant: 5 V can permanently damage the Pi.`
- `power33`: `3.3 V from the Pi’s own regulator, for sensors and modules that run at 3.3 V.`, `Keep big loads like motors and LED strips off it.`
- `ground`: `All eight ground pins are connected together.`, `Join the ground of everything you connect, including a separate power supply, to one of these.`
- `gpio`: a role-specific line first when there is one, then always `` `GPIO ${g}: an input or an output at 3.3 V. ### `TOPIC_BODIES` entries (draft text; keep the facts, polish the prose)

`pi-find-on-network` — tryIt: `Pick the network the Pi is on and your laptop’s system. See which ways of finding it work, and why some networks hide it completely.` Ideas:
1. `Try the name first` — `Raspberry Pi OS answers to its hostname plus .local, using multicast DNS (the Avahi service). If you set the hostname mypi in Imager, run ping mypi.local and the reply shows its address. macOS, current Windows and most desktop Linux understand .local names. Give a new Pi a few minutes on its first boot before you look.`
2. `Then the router, or a scan` — `Your router’s web page lists the devices it has given addresses to; look for the hostname. A scan works too: nmap from the laptop, or a scanner app such as Fing on a phone on the same WiFi, which lists the maker as Raspberry Pi. arp -a only lists devices the laptop has talked to recently, so ping first.`
3. `Some networks hide it` — `Guest networks usually keep devices apart (client isolation), so the laptop can’t reach the Pi even with its address. Café WiFi with a sign-in page never lets the Pi online, because it can’t click Accept. Many office and campus networks block the multicast that .local names need. Put the laptop and the Pi on a phone hotspot instead, set to 2.4 GHz for a Zero 2W.`
Takeaway: `Try yourname.local first, then the router’s list. On guest, café or office WiFi, use a phone hotspot.`

`pi-models-compared` — tryIt: `Tick what your project needs. See which board fits, what you give up, and which boards it rules out.` Ideas:
1. `Zero 2W: small, frugal, 2.4 GHz` — `A quad-core 1 GHz board with 512 MB of memory, 65 by 30 mm, drawing well under a watt at idle. It has 2.4 GHz WiFi only, one mini-HDMI port, one micro-USB data port, and no Ethernet or headphone jack. Ideal for one job that runs all day, like the Volumio speaker at our space.`
2. `Pi 4: the all-rounder` — `Quad-core 1.8 GHz with 1 to 8 GB, both WiFi bands, Gigabit Ethernet, four full-size USB ports, two micro-HDMI ports and a headphone jack, on a 5.1 V 3 A USB-C supply. It is the usual board for RGB LED panels, which is why our two displays run on Pi 4s.`
3. `Pi 5: when you need speed` — `Quad-core 2.4 GHz and up to 16 GB, two to three times faster than a Pi 4, with the same ports except the headphone jack, plus a PCIe connector, a power button and a real-time clock. It wants a 5 A USB-C supply, and some older libraries and HATs don’t support it yet.`
Takeaway: `One small job on WiFi: Zero 2W. Ethernet, two screens or LED panels: Pi 4. Heavy computing: Pi 5.`

`pi-gpio-pinout` — tryIt: `Tap a pin to see what it does. Switch between physical pin numbers and GPIO numbers, and use the filters to find I2C, SPI, UART and PWM.` Ideas:
1. `Two ways to number a pin` — `Physical numbers count the header itself: pin 1 in one corner, odd pins down one row and even pins down the other. GPIO numbers, also called BCM numbers, are the chip’s names for the pins, and they are what code uses: in gpiozero, LED(17) means GPIO 17, which is physical pin 11. The layout is the same on the Zero 2W, Pi 4 and Pi 5.`
2. `3.3 V only, and not much current` — `GPIO pins work at 3.3 V and are not 5 V tolerant: 5 V on a GPIO pin can permanently damage the Pi. A pin can give up to 16 mA, and all of them together 50 mA, so light an LED through a resistor and switch anything bigger with a transistor. Two pins are 5 V, two are 3.3 V, and the eight ground pins are all connected.`
3. `Pins with a second job` — `GPIO 2 and 3 are I2C, with built-in pull-up resistors. GPIO 7 to 11 are SPI, 14 and 15 are the serial port (UART), and 12, 13, 18 and 19 can do hardware PWM. GPIO 0 and 1 are kept for HAT ID chips. Turn on I2C, SPI or the serial port in sudo raspi-config, under Interface Options.`
Takeaway: `Code uses GPIO numbers, not pin numbers. Everything is 3.3 V: never put 5 V on a GPIO pin.`
