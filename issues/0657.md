## Description

The user wants to schedule posts to Bluesky and Mastodon outside the existing event-focused Outreach feature. The first use is the short topic guides under `/guides/<slug>` (`#0656`). Each topic in `web/src/lib/topics/topics.ts` already carries a `post` field with ready-made post copy.

Reuse the existing Bluesky and Mastodon posting code and stored credentials where that makes sense. Nothing has been designed yet.

**This issue starts with a planning pass.** The plan must lay out the design options and list the product questions only the user can answer, including:

- Approval flow: whether a scheduled post publishes automatically or waits for confirmation.
- Recurring posts, or one-off only.
- Image attachments, for example the guide's OG card, with alt text.
- Which accounts post.
- Where the post copy lives: `topics.ts`, the database, or editable in the admin.
