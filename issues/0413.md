## Description

`internal/db`'s doc-parity guard finds a documented migration range with
`docRangePattern`, which requires the word `numbered` or `contiguous`
immediately before a backticked range. **The alternation has no leading word
boundary**, so a word merely *ending* in one of those — `renumbered` — also
matches.

`PRD.md` carries `renumbered` followed by a range (`000001`–`000007`), which the
pattern matches. **Nothing fails today** because `PRD.md` is not among the files
the guard checks. But adding it — or moving that prose into a file that is
checked — would silently pin the guard to the **wrong range**, and the guard
would then pass while measuring something nobody intended.

This is `#0218`'s family: a pattern that quietly matches more than its author
described. Latent rather than live, exactly like `#0395`'s nested-fence case.

**Reported by `#0407`'s review**, which found it while confirming the pattern
matched exactly once in `CLAUDE.md`.

**Unverified by the orchestrator** — the `renumbered` match is the reviewer's
measurement. Reproduce it before building on it.

## The suggested fix

A `\b` before the alternation. One character, and it makes the pattern mean what
its name and its doc comment already claim.

## Acceptance criteria

1. The pattern no longer matches a word merely ending in `numbered` or
   `contiguous`.
2. **Prove it discriminates**: confirm the `renumbered` occurrence matches
   before the fix and does not after, and confirm every legitimate match still
   matches. Score by running the pattern, not by reading it.
3. **The guard's current behaviour must not change** — it matches exactly once
   in `CLAUDE.md` today, at the Repository-layout row, and must still match
   exactly that. A fix that alters which row is found is worse than the latent
   hazard.
4. **Consider whether the guarded file set should widen** to include `PRD.md`,
   now that doing so would be safe. Say what you conclude — per
   `#0330`/`#0347`/`#0356`/`#0381`, recording a limit is legitimate, but leaving
   the question unmentioned is not.
5. **No new mechanism** beyond the boundary and whatever criterion 4 concludes.
   §8's `#0258` is six passes of adding checks to defend checks.
6. Run `./internal/db/...` and `./internal/handlers/...` (`#0381`). Per §5 name
   the specific tests that ran. `gofmt` stability. No Go-file-plus-line-number
   citation (`#0352`), scanned with `python3` bytes rather than BSD `grep -P`.
