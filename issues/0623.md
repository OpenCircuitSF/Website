## Description

`outreach_channels` defaults to `bluesky,mastodon,instagram`, and production has no saved value, so TikTok and YouTube never appear. The site cannot post to Instagram, TikTok or YouTube, but the user posts there by hand and needs a ShortLink for each.

## Acceptance criteria

- [ ] TikTok and YouTube are in the default `outreach_channels`, and a saved value is still respected.
- [ ] YouTube is labelled **YouTube Shorts** on admin screens.
- [ ] Existing workshops, including `hack-night` and `hack-night-2`, gain drafts for the newly enabled channels without disturbing existing drafts, schedules or posted rows.
- [ ] Each of Instagram, TikTok and YouTube Shorts has its own ShortLink for each wave, available without posting, with its own UTM attribution.
- [ ] Nothing attempts to post automatically to those three channels.
- [ ] Automatic-channel behaviour and Results are unchanged, except that the new links are counted.

## Notes

The planner establishes when manual-channel ShortLinks are created today (`internal/outreach/links.go`) and whether `Prepare` already covers them. A ShortLinks outage must not break the screen.
