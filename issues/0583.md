## Resolution

- Go: `outreachWorkshopView` carries `summary` and `cover_image`;
  `outreachPanelView.bluesky_card` is `"short"` or `"canonical"`, via
  `SetCardURL` (wired to `serverSettings.BlueskyCardURL` in `main.go`). It
  reports `"short"` whenever the publisher would fall back (`baseURL == ""`).
- `web/src/lib/outreachPreview.ts`: `segments`, `hostOf`, `blueskyCard` (picture
  only for a `/media/` cover), `mastodonLinkCard` (cover, else
  `/workshops/{slug}/og.png`; null without a URL), `identicalAutomaticBodies`,
  `copyablePostLink`.
- `OutreachBlueskyPreview`, `OutreachMastodonPreview` and a thin
  `OutreachPostPreview` that picks one (other channels keep plain text and
  count). The Mastodon image block shows only when the workshop exposes
  `cover_alt` (#0572 has not landed): an ALT badge, or "No image: alt text
  missing".
- Wired into `OutreachAnnouncement` (previews area only), `OutreachPostDialog`
  (new optional `view` prop) and `OutreachPostCard` (new `view` prop from the
  list). The identical-text warning (`.text-warn`) shows above the Announcement
  previews, following unsaved typing, and in the both-networks dialog. A posted
  card keeps its preview and adds **Copy link to post** (with the Copied flip)
  when `remote_url` is safe.
- Deviations: the cards list itself shows no identical-text warning (it appears
  where both are sent together); the previews own the character count, so the
  per-card count paragraph moved into them; `#0572`'s `cover_alt` is read as an
  optional field and nothing breaks without it.

## Review notes

Opus reviewer, 2026-10-18 — **approved** after three small fixes in `fa400f42`.

Checked against what is actually sent:

- **Bluesky card** (`internal/outreach/publisher.go` `postBluesky`): title is
  `job.Title`, description `deref(job.Summary)` untruncated (the client sends it
  as is, so no truncation to mirror; the preview's trim only drops whitespace),
  thumb only from a `/media/` path through `thumbnail`. `blueskyCard` matches.
  Host: `canonical` only when `bluesky_card_url` says so **and** `siteBase` is
  set; the handler's `blueskyCard()` uses the same two conditions on
  `h.baseURL`, and the Go test covers the empty-base fallback. The preview's
  canonical host is `location.host`, which equals `BASE_URL`'s host in
  production (one origin); see the follow-up.
- **Mastodon card** (`internal/seo/seo.go` `workshopRouteMeta`): og:title is
  the title, og:description the summary, og:image `absoluteURL(cover)` else
  `/workshops/{slug}/og.png` (the workshop is cardable whenever outreach is
  available). **Fixed:** an absolute `https://` cover was shown as og.png
  although og:image uses it verbatim; now kept. **Fixed:** the card's byline
  read the short link's host, but `web/index.html` always emits
  `og:site_name` "Open Circuit SF", and Mastodon shows the provider name in
  place of the host when one is present; it now reads `APP_NAME` (same text).
  **Fixed:** with the image attached (alt text present) the card was still
  drawn without its picture; Mastodon draws no link card for a status with
  media, so the card is now omitted, and with alt missing (nothing attached)
  the card comes back with its picture. Tests for all three.
- **Count**: the previews reuse the existing `countCharacters` (Intl.Segmenter
  graphemes for Bluesky, as `internal/bluesky` counts UAX #29 clusters); not
  changed here.

  links are `<span>`s with no `href`; card images go through
  `isSafeLinkHref`; Copy link to post requires `copyablePostLink` (safe
  scheme), tested with `javascript:`.
- **Identical-text warning**: the Announcement compares `shownBody` of the
  automatic posts for the same wave (follows unsaved typing); the dialog
  compares the items it will send. Correct bodies.
