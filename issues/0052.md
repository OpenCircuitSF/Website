## Description

The admin screen for creating and editing workshops, with Markdown body editing and interest tagging.

## Acceptance criteria

- [ ] List view with status, date, and title; sortable by date
- [ ] Create and edit form covering every field, with Markdown editing and preview for the body
- [ ] Interest tagging drives both the public page's pre-checked subscribe form and campaign targeting
- [ ] Slug auto-generated from the title, editable before first publish and locked after
- [ ] Publish, unpublish, and cancel actions with confirmation
- [ ] Cover image upload or path entry
- [ ] `npm run check` and `npm test` pass

## Notes

PRD §5.2. Locking the slug after first publish protects shared links — an edited slug breaks every social post and email that already pointed at the old URL. If a slug genuinely must change later, that is a deliberate action with a redirect, not a casual edit.
