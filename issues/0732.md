## Acceptance criteria

- [ ] `GET /events.ics` returns `text/calendar; charset=utf-8`. It holds one `VEVENT` per published upcoming event, from the same store read the public listing uses. Each `VEVENT` has a stable `UID`, `DTSTART`/`DTEND` with `TZID=America/Los_Angeles` and a `VTIMEZONE`, `SUMMARY`, `LOCATION`, `URL` (the canonical `www` event URL), `DESCRIPTION` as plain text, and `STATUS:CANCELLED` for cancelled events that are still listed publicly.
- [ ] Line folding at 75 octets and RFC 5545 escaping (`,` `;` `\` newline), pinned by tests, including a multi-byte character at a fold boundary.
- [ ] Drafts and unpublished events never appear (test).
- [ ] Linked with `<link rel="alternate" type="text/calendar">` from the events listing, and mentioned on `/agents` if `#0731` has landed.
- [ ] The response is compressible by `#0716`'s middleware (`text/calendar` is already in its type list) and carries a short `Cache-Control`.

### Design in one paragraph

The feed is a new method on the existing `handlers.PublicWorkshopsHandler`, so it reads `workshops.Store.ListVisible` through the **same** `publicWorkshopStore` interface field that `GET /api/workshops` (`List`) already uses. No new SQL and no new store method. The handler uses the **upcoming** slice only and drops entries whose `StartsAt` is nil, since a VEVENT without a start can't be placed on a calendar. The RFC 5545 text work (escaping, 75-octet folding, VTIMEZONE, CRLF) lives in a new pure package `internal/ical`, so the byte-level tests run with no database. In `cmd/opencircuit/main.go` the change is **one route line** inside the existing `if publicWorkshopsH != nil {` block, using `cfg.BaseURL`, which is already in scope in `mountAndServe`. So: no new constructor argument, no `mountAndServe` signature change, and no edit in `servePostgres`/`serveDevMode`. Discovery is a `<link rel="alternate" type="text/calendar">` in the shared SPA head, right beside the existing Atom feed link, following that precedent.

### Approach

**1. `internal/ical/ical.go`** (package `ical`; blank-import `_ "time/tzdata"`, the same as `internal/seo/fallback.go`)

- `const TZID = "America/Los_Angeles"`.
- `func EscapeText(s string) string`: RFC 5545 §3.3.11 TEXT escaping. First normalise `"\r\n"` and lone `"\r"` to `"\n"`. Then, **in this order**, replace backslash with two backslashes, `;` with `\;`, `,` with `\,`, and newline with a backslash followed by the letter `n`. The backslash has to go first, or the escapes added afterwards would be escaped again. Use `strings.NewReplacer` with the backslash pair listed first. Per AGENTS.md §8, build expected test strings so no NBSP-style or escape-landing surprises occur. Read the test file back as bytes if a literal looks wrong.
- `func FoldLine(line string) string`: returns `line` split into physical lines joined by CRLF + one space, **without** a trailing CRLF. Rule: no physical line exceeds **75 octets** (excluding the CRLF). The leading space of a continuation line counts toward its 75, so continuation content is at most 74 octets. **Never split a UTF-8 sequence.** When the cut point `i` lands on a byte where `!utf8.RuneStart(line[i])`, step `i` back until it is a rune start. Work on bytes, not runes.
- `type Event struct { UID string; Start time.Time; End *time.Time; Stamp time.Time; Summary, Location, Description, URL string; Cancelled bool }`.
- `func Calendar(name string, events []Event) []byte`: the whole document, every line ending in `\r\n`, each line passed through `FoldLine`:
  ```
  BEGIN:VCALENDAR
  VERSION:2.0
  PRODID:-//Open Circuit SF//Events//EN
  CALSCALE:GREGORIAN
  METHOD:PUBLISH
  X-WR-CALNAME:<EscapeText(name)>
  X-WR-TIMEZONE:America/Los_Angeles
  <VTIMEZONE block>
  BEGIN:VEVENT ... END:VEVENT   (per event)
  END:VCALENDAR
  ```
  The VTIMEZONE block is hardcoded, using the US rules in force since 2007:
  ```
  BEGIN:VTIMEZONE
  TZID:America/Los_Angeles
  BEGIN:DAYLIGHT
  TZOFFSETFROM:-0800
  TZOFFSETTO:-0700
  TZNAME:PDT
  DTSTART:19700308T020000
  RRULE:FREQ=YEARLY;BYMONTH=3;BYDAY=2SU
  END:DAYLIGHT
  BEGIN:STANDARD
  TZOFFSETFROM:-0700
  TZOFFSETTO:-0800
  TZNAME:PST
  DTSTART:19701101T020000
  RRULE:FREQ=YEARLY;BYMONTH=11;BYDAY=1SU
  END:STANDARD
  END:VTIMEZONE
  ```
  Each VEVENT, in this order:
  - `UID:<uid>`
  - `DTSTAMP:<Stamp.UTC() as 20060102T150405Z>`
  - `DTSTART;TZID=America/Los_Angeles:<Start.In(la) as 20060102T150405>`
  - `DTEND;TZID=America/Los_Angeles:<...>`, **only when End != nil**. RFC 5545 §3.6.1 allows omitting it; `ends_at` is optional in the admin form, and we do not make one up.
  - `SUMMARY:<EscapeText>`
  - `LOCATION:<EscapeText>`, only when non-empty
  - `DESCRIPTION:<EscapeText>`, only when non-empty
  - `URL:<url>`, a URI value, **not** text-escaped
  - `STATUS:CANCELLED` when `Cancelled`, otherwise `STATUS:CONFIRMED`

  Load `la` once with `time.LoadLocation(TZID)` in a package-level `var` and panic on error. tzdata is embedded, so the error cannot happen.

**2. `internal/handlers/public_events_ics.go`**

```go
func (h *PublicWorkshopsHandler) CalendarHandler(baseURL string) http.HandlerFunc
```
- `upcoming, _, err := h.store.ListVisible(r.Context(), h.now())`. On error, `http.Error(w, "internal server error", 500)`.
- For each `wk` in `upcoming`: skip when `workshopPageStatus(wk) != http.StatusOK` (defence in depth, the same predicate `GetBySlug` uses, so drafts and never-published rows are excluded even if the SQL ever widens). Also skip when `wk.StartsAt == nil`.
- Map each remaining `wk` to an `ical.Event`:
  - `UID`: `fmt.Sprintf("event-%d@%s", wk.ID, host)`, where `host` is `url.Parse(baseURL)`'s `Hostname()`. Compute it once, outside the closure.
  - `Start: *wk.StartsAt`, `End: wk.EndsAt`, `Stamp: wk.UpdatedAt`, `Summary: wk.Title`.
  - `Location`: `LocationName` and `LocationAddress`, both dereferenced, empties dropped, joined with `", "`.
  - `URL`: `strings.TrimRight(baseURL, "/") + "/events/" + wk.Slug`.
  - `Description`: `*wk.Summary` if set and non-blank, then `"\n\n"`, then the event URL. With no summary, just the URL. `BodyMD` is Markdown and is deliberately left out, because the criterion asks for plain text.
  - `Cancelled: wk.Status == workshops.StatusCanceled`.
- Headers: `Content-Type: text/calendar; charset=utf-8`, `Cache-Control: public, max-age=300`. Write `ical.Calendar("Open Circuit SF", events)`.
- The doc comment names `GET /events.ics`, `#0732`, and the fact that it shares `List`'s `ListVisible` read.
