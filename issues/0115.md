## Description

[#0101](0101.md) added the Luma calendar link to the SPA — `Footer.svelte`,
`About.svelte`, and the privacy sentence — and that work is correct. But the SPA
is not deployed. `CLAUDE.md` §7 records that what `www.opencircuitsf.com`
actually serves today is `placeholder/index.html`, and that page's only call to
action is still the Discord invite:

```html
<div class="cta">
  <a class="btn btn-primary" href="https://discord.gg/Fq9ug6QXV3" rel="noopener">Join the Discord</a>
</div>
```

The user added the calendar on 2026-08-20 specifically to promote upcoming
events. Until the Go service ships, nobody who visits the site sees it. The
placeholder also says "In the meantime, the Discord is where everything
happens" (line ~344), which was true when written and is now the same half-truth
`#0101` corrected in `About.svelte`.

## Review notes

Approved. Independent re-verification, phase 3.

**There is no automated test suite for this file, and that is stated rather than
skipped silently.** `placeholder/index.html` is a standalone static page: it is
not embedded by `//go:embed`, not part of the Vite build, and not imported by
any Go or Svelte source, so `go test ./...`, `npm run check`, and `npm test`
have literally nothing to assert about it — running them would produce a green
result that proves nothing, the exact failure mode `CLAUDE.md` §5 warns about.
`git show --name-only 8840774` is two files, both under `placeholder/`, with no
`.go`, no `web/`, and nothing under `web/dist/`. In place of a suite the review
rendered the page in headless Chromium against a local HTTP server and asserted
against the live DOM, computed styles, network log, and screenshots.

What was checked, and how:

- **Server provenance (§8b).** `python3 -m http.server 39117 --bind 127.0.0.1`;
  `lsof -nP -iTCP:39117 -sTCP:LISTEN` returned PID 87828, the same PID the
  spawn reported, and the server log was empty (no `address already in use`).
  The response body was then `diff`ed against `git show
  8840774:placeholder/index.html` and was byte-identical. Killed afterwards;
  the port is released and no `http.server` process remains.
- **Both CTAs.** `.cta a` resolves to exactly two anchors — `btn btn-primary`
  → `https://discord.gg/Fq9ug6QXV3` and `btn btn-ghost` →
  `https://luma.com/opencircuitsf`, both `rel="noopener"`. Neither carries
  `target="_blank"`, which differs from the SPA but matches the Discord button
  already on this page, so the file stays internally consistent.
- **Link resolution.** `luma.com/opencircuitsf` → 200, `num_redirects=0`;
  `lu.ma/opencircuitsf` → 301 `location: https://luma.com/opencircuitsf`,
  matching the note in `web/src/lib/links.ts`. Discord → 200. The Luma page's
  `og:title` is `Open Circuit SF · Events Calendar`, confirming it is this
  group's calendar and not a coincidental slug.
- **Contrast, measured not assumed.** The calculator reproduces §8's published
  numbers (`#68FF23` on the dark ground 14.80:1, on white 1.32:1) before being
  trusted. Ghost label: 18.60:1 light, 15.61:1 dark. Ghost hover
  (`--accent`): 5.17:1 light, 13.76:1 dark. Focus ring vs page: 4.76:1 light,
  14.80:1 dark — both clear of 3:1. Recorded for completeness: the ghost
  *border* is `--border-strong`, which measures 3.11:1 / 2.86:1 (light) and
  2.86:1 / 3.08:1 (dark) — the sub-3:1 weakness §8 documents. Not raised as a
  defect: §8's prohibition is scoped to focus rings, this ring correctly uses
  `--accent`, the rule predates the commit, and the control is identified by an
  18.6:1 label in a 44 px-minimum hit area rather than by its border, so
  WCAG 1.4.11 is not resting on it.
- **Copy.** The old "the Discord is where everything happens" string is gone
  from the served body. The replacement — "upcoming sessions are listed on the
  Luma calendar, where you can RSVP directly, and the Discord is where people
  organize between sessions" — matches `About.svelte` lines 76–78 in substance
  and shares the clause "where you can RSVP directly" verbatim. The two
  surfaces do not contradict each other, and neither overclaims: it says
  sessions are *listed* and that you can RSVP, both true of the live page.
- **README.** "Before it goes live" is now a two-item list covering both CTAs,
  each with its own reason to re-check (invite expiry for Discord; the
  hand-copied-URL relationship to `links.ts` for Luma). Criterion met.

timing caveat applies and none was needed for a static-file check.
