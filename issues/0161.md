## Description

`gofmt -l` currently flags four files, none of them touched by the change that noticed:

```
cmd/opencircuit/seo_wiring_test.go
internal/db/prd_index_parity_test.go
internal/handlers/static_test.go
internal/sesnotify/verify_test.go
```

They have presumably been unformatted for some time. **`scripts/check.sh` runs `go build` and `go vet` but never `gofmt`**, so nothing in the canonical verification path reports it, and `go vet` does not care about formatting.

This surfaced during `#0156`'s review, which ran `gofmt -l` of its own accord and then had to establish that the flagged files were pre-existing rather than its own doing — a small diagnostic tax it paid on behalf of a defect that belongs to nobody.

## Acceptance criteria

- [ ] The four files are gofmt-clean, and the reformatting commit is separate from any behavioral change so the diff is reviewable as pure formatting
- [ ] Decide whether `scripts/check.sh` should run `gofmt -l` and fail on output. The argument for: it is nearly free, and formatting drift is exactly the kind of thing that accumulates silently. The argument against: it is one more way for a run to fail on something unrelated to the change under review — which this project has felt acutely today. Record the decision
- [ ] If added: prove it fails against an unformatted file, then passes
- [ ] `ISSUE=0161 scripts/check.sh go ./...` passes with whatever you decide

## Notes

Reported by `#0156`'s phase-3 review under `CLAUDE.md` §9's rule that subagents report issues rather than filing them.

Worth noting `#0140`'s lesson while deciding the second criterion: `check.sh` spent an unknown period reporting `VERIFICATION PASSED` over failing tests, and the fix was to make it *more* able to fail. A check that cannot fail is worthless; a check that fails for reasons unrelated to the change is a tax on every reviewer. `gofmt` is cheap enough and deterministic enough to be worth the former without much of the latter — but it is a judgment call, and this issue should make it deliberately rather than by reflex.
