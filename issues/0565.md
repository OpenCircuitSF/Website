## Description

From `#0564`'s review. None blocks release.

1. **Stale short-URL host.** A `Me` call already in flight against the old
   ShortLinks client can finish after `ResetShortLinks` and write the old
   host back into the outreach handler's cache. It stays wrong until the next
   reset or a restart.
2. **Wiring-test gap.** `cmd/opencircuit`'s
   `TestMountAndServe_AdminRoutesRequireSessionAndAdmin` fixture never calls
   `SetConnections`, so its sweep skips the five
   `/admin/outreach-connections` routes. They are protected today by the
   route loop and by the handler test's own auth checks.
3. **Account switch.** When the Bluesky handle or the Mastodon account
   changes, the tracker keeps the old account's mention cursors and its
   `attempted` map.

## Acceptance criteria

- [ ] A generation counter (or equivalent) discards a `Me` result that
      started before the latest `ResetShortLinks`; a test drives the race
      with a blocking fake.
- [ ] The wiring fixture calls `SetConnections`, and the sweep covers all
      five routes (401 without a session, 403 for a non-admin).
- [ ] When a channel's account identity changes, the tracker drops that
      channel's stored cursor and in-memory `attempted` state, and a test
      proves the new account starts from a fresh cursor.
- [ ] Verified with `ISSUE=0565 scripts/check.sh go ./internal/outreach/... ./internal/outreachconn/... ./internal/handlers/... ./cmd/opencircuit/... ./internal/db/...`. Zero skips.
