## Description

The route the router falls through to, styled as a terminal error rather than a browser default.

## Acceptance criteria

- [ ] `NotFound.svelte` rendered for any unmatched route
- [ ] Terminal-styled — e.g. a `CommandLine` showing the attempted path and a `command not found` style message
- [ ] Links back to Home and Workshops
- [ ] The Go SPA handler returns HTTP 404 for paths the route table does not recognize, while still serving the SPA shell
- [ ] Default metadata applied by #0019, and the page is not listed in the sitemap

## Notes

PRD §5.1. Returning 200 for every unknown path — the naive SPA catch-all — makes every typo an indexable soft-404. The handler needs the same route table #0019 uses so it can distinguish a real route from a miss.

Hashed asset paths must still 404 as assets, not fall through to the SPA shell, or a missing bundle silently returns HTML and produces a confusing MIME error in the console.
