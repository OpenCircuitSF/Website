## Description

The only schema.org structured data on the site is the workshop `Event` block (`#0055`), validated with Google's Rich Results Test in `#0149`. Measured on production, 2026-09-12: the home page and `/archive/09-2026` carry **no JSON-LD**.

That leaves two gaps:

- **Newsletters.** An archive page is an article: a headline, a publication date, a publisher. Structured data lets search engines present it as one.
- **The organisation.** Nothing states, in machine-readable form, that `opencircuitsf.com` is Open Circuit SF, what its logo is, or which profiles belong to it (Bluesky, Discord, the Luma calendar). That is what feeds a knowledge panel and ties the profiles to the site.

## Acceptance criteria

1. `/archive/{slug}` for a published campaign emits an `Article` (or `BlogPosting`; record the choice) with `headline`, `datePublished` from `archived_at`, `publisher` as the organisation, `url`, `description` (`#0528`'s text), and `image` (`#0532`'s card once it exists, the default card until then).
2. `/` emits an `Organization` (name, url, logo, and `sameAs` for the organisation's real public profiles) and a `WebSite` node.
3. Built the same way as `internal/seo/jsonld.go`'s `Event` block, reusing its escaping, and passing the same hostile-payload tests `#0055` applied: content from the database must not break out of the `<script>` element.
4. Nothing is emitted for withheld, draft, or unknown archive slugs.
5. The CSP is unaffected: JSON-LD is a data block, not executable script. Confirm the bootstrap script's hash is unchanged using an HTML parser, not a regex (`CLAUDE.md` §8).
6. **Post-deploy, verified by the user:** Google's Rich Results Test on `/` and `/archive/09-2026` reports no errors, per the post-deploy step `docs/seo.md` now records (`#0149`).
7. `ISSUE=NNNN scripts/check.sh go ./internal/seo/... ./cmd/opencircuit/...` passes with no skips.

## Fix

Same builder discipline as `internal/seo/jsonld.go`'s Event block: fixed structs, `encoding/json.Marshal`'s own HTML escaping, `""` when the data doesn't qualify. `articleJSONLD` (type choice recorded: **Article**, not BlogPosting — a newsletter issue is an article; the general type makes no claim the data can't back) on published archive pages, gated on `Published` re-checked plus a `archived_at` present gate — no fabricated date, mirroring `buildEvent`'s missing-startDate posture. `homeJSONLD` on `/` emits one `@graph` with the Organization (logo = `/mark-green-512.png`, the webmanifest's own opaque brand mark; `sameAs` = Bluesky (`https://bsky.app/profile/opencircuitsf.com`, whose handle is the domain per the kept `/.well-known/atproto-did`), Discord, and the Luma calendar — mirrored from `web/src/lib/links.ts`) and a WebSite node. Two pre-existing pins updated for the new legitimate state: `TestRender_JSONLD_StaticRoutesHaveNoBlock` no longer lists `/`, and `TestRender_FallbackAddsNoScriptElement` expects 1 for `/` and for a dated archive entry.

## Verification

`ISSUE=0530 scripts/check.sh go ./internal/seo/... ./internal/handlers/... ./cmd/opencircuit/...` — all three `ok`, no skips. New tests: `TestRender_JSONLD_ArchiveEntryEmitsArticle` (every required field, parsed as JSON via the existing `extractJSONLD` harness), `TestRender_JSONLD_ArchiveNothingForNonPublishedOrNeverArchived` (withheld/unsent/unknown/no-date → no block), `TestRender_JSONLD_ArchiveHostileSubjectStaysValidJSON` (#0055's hostile payload — quotes, backslash, embedded `</script>` — round-trips without reaching the page raw), `TestRender_JSONLD_HomePageEmitsOrganizationAndWebSite`, `TestRender_JSONLD_NothingOnOtherRoutesForArchive`. Criterion 5's CSP check is recorded with #0531's verification — the only `web/` edit in this chain, after which the bootstrap script's hash was re-parsed and matched. Criterion 6 (Rich Results Test) is post-deploy work for the user.
