## Description

`#0617`'s plan keeps `location_name`, `location_address` and `location_note` on
`workshops`, unread and unwritten, so that draft text its migration consolidates
without anyone having read it stays recoverable. Once venues have been deployed and
the result checked, drop the three columns in a new migration.

      repopulated from each listing's venue.
