## Description

This is a child of `#0673`. It exposes the API to MCP clients such as Claude Code, Claude Desktop and others, so a session can say "schedule next week's guide posts" and do it.

## Requirements

1. **Transport.**
   - MCP Streamable HTTP at `POST/GET /mcp`, served by the existing binary.
   - Use the official Go SDK (`github.com/modelcontextprotocol/go-sdk`) unless the plan finds a blocking problem.
   - Apache already proxies everything except `/.well-known/`. Verify that `/mcp` gets through, and that streaming responses aren't buffered.
2. **Auth.**
   - `Authorization: Bearer ocsf_…`, resolved by the same `RequireAPIToken` path.
   - Every tool call checks the scope its operation needs.
   - A missing or invalid key gets an HTTP 401, so a client prompts for one.
3. **Tools.** Each tool is a thin adapter over the **same service functions as the v1 handlers**, not an HTTP call back to itself. Tool names and JSON schemas are generated from, or tested against, the v1 registry.
   - `whoami`
   - `list_guides`, `get_guide`
   - `list_guide_posts`, `create_guide_posts`, `update_guide_post`, `schedule_guide_post`, `unschedule_guide_post`, `send_guide_post`, `post_guide_again`, `delete_guide_post`, `guide_posts_overview`, `list_channels`
   - `list_events`, `get_event`, `create_event`, `update_event`, `publish_event`, `unpublish_event`, `cancel_event`, `duplicate_event`
   - `list_venues`, `list_event_types`, `list_interests`
   - `event_coverage`, `list_cadence_rules`, `set_cadence_rule`
4. **Descriptions.**
   - Each tool's description says what it does, which scope it needs, and any side effect. For example, `send_guide_post` posts publicly and right away.
   - Destructive or public tools say so first, so clients that ask before acting can ask.
5. **Tools follow the key.** The server registers only the tools the calling key's scopes allow, so a read-only key never sees write tools.
6. **Limits.** Tool calls count against the token's rate limit (`#0674`) and are audited as API-key actions.

## Acceptance criteria

- Go tests drive the MCP handler with the SDK's client over an in-memory or `httptest` transport. They cover:
  - `tools/list` filtered by scope;
  - a successful `create_guide_posts` and `list_events`;
  - a scope denial;
  - an invalid key getting a 401.
- A parity test asserts every v1 write operation has a tool, or is listed as deliberately excluded.
- A local smoke test with `claude mcp add --transport http ocsf http://localhost:8080/mcp --header "Authorization: Bearer <key>"` is recorded in the issue, with the key redacted.
