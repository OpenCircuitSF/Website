## Description

Ship both families as subsetted woff2 files served from our own origin. No Google Fonts, no CDN — the site must make zero external requests.

## Acceptance criteria

- [ ] Archivo (variable, weights 400–900) and JetBrains Mono (400, 700) placed in `web/public/fonts/`
- [ ] Latin-subsetted woff2 only; total font payload ≤ 120 KB
- [ ] `@font-face` rules in `app.css` with `font-display: swap` and correct `unicode-range`
- [ ] Fallback stacks declared: `ui-sans-serif, system-ui, sans-serif` and `ui-monospace, SFMono-Regular, Menlo, monospace`
- [ ] Font licenses (both are SIL OFL) included in `web/public/fonts/LICENSE`
- [ ] No request to `fonts.googleapis.com` or `fonts.gstatic.com` anywhere in the built output
- [ ] Verified in DevTools that fonts load from the site's own origin and the page has zero third-party requests

## Notes

PRD §4.3. Self-hosting is a privacy and reliability decision, not a performance micro-optimization: a site that promises no third-party tracking cannot load fonts from Google.

Subset with `pyftsubset` (fonttools) or `glyphhanger`. The variable Archivo file covers the whole weight range in one request, which is why it beats shipping discrete weights.

`font-display: swap` matters here — the display headline is the LCP element and must not be blocked on a font download.
