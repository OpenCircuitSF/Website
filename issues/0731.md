## Description

From the handoff's Discovery section. A docs page, a machine-readable server card and a footer link make the public MCP server (`#0729`) findable.

**Two repo facts shape this.**

1. **`/mcp` is the MCP endpoint itself.** Content negotiation there would mix SPA and MCP handling on one route, so the human docs go at **`/agents`**. A browser GET to `/mcp` (`Accept: text/html`, not an MCP request) may redirect to `/agents`. That is decided at plan time, without breaking MCP clients.
2. **`/.well-known/` is not served by the Go service.** Apache serves it from disk (`ProxyPass /.well-known/ !`, AGENTS.md §7) because it holds the domain's Bluesky `atproto-did`. So `/.well-known/mcp.json` needs one of:
   - a static file deployed into `/var/www/vhosts/www.opencircuitsf.com/.well-known/`, or
   - a single `ProxyPass /.well-known/mcp.json` exception ahead of the `!` rule.

   Either way, the `atproto-did` hash check (`4198e742…5948d`) must still pass after the change.

### Spec, pinned

Read on 2026-11-19:
- **SEP-2127, "MCP Server Cards"**: status Final, Extensions Track, <https://modelcontextprotocol.io/seps/2127-mcp-server-cards>.
- Its normative wire format, from `modelcontextprotocol/experimental-ext-server-card` at `main` `28db12c9`: `schema.ts` and `docs/discovery.md`.

What the spec says:
- **Schema URL** (required `$schema`): `https://static.modelcontextprotocol.io/schemas/v1/server-card.schema.json`. It is versioned by `vN` and still pre-release.
- **Fields used here:**
  - `name`: reverse-DNS with exactly one `/`, matching `^[a-zA-Z0-9.-]+/[a-zA-Z0-9._-]+$`, 3–200 characters
  - `version`: semver
  - `description`: 1–100 characters
  - `title`: up to 100 characters
  - `websiteUrl`
  - `icons[{src, mimeType, sizes}]`
  - `remotes[{type: "streamable-http", url, supportedProtocolVersions}]`

  There are **no** `tools`, no capabilities, and no auth field. "No auth" is expressed by having no required `headers`.
- **Card location:** `GET <streamable-http-url>/server-card` is reserved. Media type `application/mcp-server-card+json`. CORS `Access-Control-Allow-Origin: *`, `Access-Control-Allow-Methods: GET`, `Access-Control-Allow-Headers: Content-Type, If-None-Match`. `Cache-Control: public, max-age=3600`, plus an `ETag` that honours `If-None-Match`.
- **Domain discovery:** `/.well-known/ai-catalog.json`, media type `application/ai-catalog+json`:

      {"specVersion":"1.0","entries":[{"identifier":"urn:air:opencircuitsf.com:mcp:opencircuitsf","type":"application/mcp-server-card+json","url":"<base>/mcp/server-card"}]}

- **Consistency:** the card's name, version and title SHOULD NOT contradict the live server's values.

### Design, decided

- **Go generates everything, and Apache only proxies.** The card is about 600 bytes built from constants, `reg.Version()` and `mcp.SupportedProtocolVersions()`, which the server already uses, so a deployed static file could only drift. Two `ProxyPass` exact-path lines go **above** `ProxyPass /.well-known/ !`. Apache checks `ProxyPass` rules in order and the first match wins, so `atproto-did` and everything else under `/.well-known/` still come from disk.
- **Paths:**

  | Path | Serves | Why |
  |---|---|---|
  | `/mcp/server-card` | the card | the spec's reserved location; reached through Apache's existing `ProxyPass /`, so it needs no Apache change |
  | `/.well-known/ai-catalog.json` | the catalog | spec domain discovery |
  | `/.well-known/mcp.json` | the same card bytes and headers | the alias this issue asked for, which the IETF `draft-soden-wellknown-mcp-commerce` also names; documented as non-standard |

- **Card values:**

  | Field | Value |
  |---|---|
  | `name` | `com.opencircuitsf/opencircuitsf` |
  | `title` | `Open Circuit SF` |
  | `description` | `Read-only Open Circuit SF events and newsletter issues. No account or key needed.` (82 characters) |
  | `version` | `reg.Version()` |
  | `websiteUrl` | `base + "/docs/mcp"` |
  | `icons` | `[{src: base+"/mark-green-256.png", mimeType: "image/png", sizes: ["256x256"]}]` (the file is in `web/public/`) |
  | `remotes` | `[{type: "streamable-http", url: base + Path, supportedProtocolVersions: mcp.SupportedProtocolVersions()}]` |

  No `repository`, because the GitHub rename (AGENTS.md §10 item 1) is pending.
- **`GET /mcp` from a browser:** 302 to `/docs/mcp` only when `Accept` contains `text/html` **and not** `text/event-stream`. Every other GET, which is what MCP clients send, still gets the SDK's 405. This uses a temporary redirect because it is content-negotiated.
