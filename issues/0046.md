## Description

Render a campaign without sending it, and deliver a real test message to an admin address before the campaign can go out.

## Acceptance criteria

- [ ] `POST /admin/campaigns/{id}/preview` returns the rendered HTML and text without sending
- [ ] `POST /admin/campaigns/{id}/test` sends one real message to a specified admin address
- [ ] The test message uses a real manage token so the unsubscribe links can be clicked and verified
- [ ] Test sends are recorded but do not create `email_sends` rows for the campaign
- [ ] A campaign cannot leave `draft` until a test send has succeeded
- [ ] Handler tests cover preview rendering and the test-send gate

## Notes

PRD §6.6. Using a real, working token in the test send is the point — the operator should be able to click the unsubscribe link in the test message and see it work. A test that exercises everything except the compliance-critical links is not a test.

Whichever admin address receives the test must not end up suppressed by clicking it; use a token tied to a dedicated test subscriber row, not to a real list member.
