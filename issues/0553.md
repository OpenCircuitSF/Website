## Acceptance criteria

- [ ] The admin dashboard's outbound-queue counts and its "queue abandoned" warning exclude `outreach_post` rows (or report them separately, labelled as social posts), so a bad Bluesky password never reads as a mail failure. Test it.
- [ ] Mastodon retries cannot double-post after the instance forgets the `Idempotency-Key` (~1 hour): before re-posting a post whose earlier attempt may have succeeded (any attempt after a timeout or 5xx), look for a recent status by our account carrying that post's short URL and adopt it instead of posting again. Test with a fake that forgets the key.
- [ ] The local Mastodon character count trims trailing punctuation from URLs the same way the Bluesky facet code does, matching what the instance counts. Test it.
- [ ] The Bluesky thumbnail reader checks the file size (stat) before reading it.
- [ ] A credential env var set to whitespace only is reported at boot (warning log) rather than silently treated as unset.
- [ ] Verified with `ISSUE=0553 scripts/check.sh` (full).
