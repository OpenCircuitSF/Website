## Description

Admin endpoints to manage workshops and public endpoints to read the published ones.

## Acceptance criteria

- [ ] `GET/POST/PATCH/DELETE /admin/workshops[/{id}]`, admin-gated
- [ ] `GET /api/workshops` returns published workshops, split into upcoming and past
- [ ] `GET /api/workshops/{slug}` returns one published workshop; drafts 404 for the public
- [ ] Publish and unpublish transitions stamp `published_at`
- [ ] Cancel sets status `canceled` and the public page shows it as canceled rather than hiding it
- [ ] Workshop mutations invalidate the SEO and sitemap caches (#0019, #0020)
- [ ] Audit rows for every mutation
- [ ] Handler tests cover public visibility rules for each status

## Notes

PRD §8. A canceled workshop stays visible with a clear cancellation notice — people who saw the announcement will come looking, and a 404 tells them nothing.

Cache invalidation on mutation is easy to miss and produces a confusing bug where a published workshop does not appear in previews or the sitemap until the cache expires.
