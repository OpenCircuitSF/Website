## Description

## Acceptance criteria

- [ ] `decodeError` redacts the configured token from the server's `error` string before it reaches `APIError.Message` / `err.Error()`. The leak test gains a JSON-body case (`{"error":"…<token>…"}`) alongside the existing plain-text 500 case.
- [ ] `EnsureCampaign` can no longer create duplicate campaigns because of a name/slug mismatch: drop the separate `name` parameter (the campaign is named with the slug; the display name goes in `Description`), or reject a name whose slugification differs from the slug before any request. Tests cover the chosen behavior.
- [ ] `CreateLink`'s doc comment states the de-duplication only applies without a custom `Key`; with a custom key a retry answers 409 `ErrConflict`. Add a helper or documented pattern (fetch with `GetLink` on 409 and accept it when its destination matches) and test it.
- [ ] Verified with `ISSUE=0550 scripts/check.sh go ./internal/shortlinks/... ./internal/handlers/...`.
