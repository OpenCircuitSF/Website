## Description

`internal/seo/invalidator_satisfier_guard_test.go`'s doc comment says:

> `*Sitemap` already had a method of that shape under its old, longer name, and
> shortening it made a previously-impossible assignment compile silently

That has a **correct** parse — "shape" meaning zero-parameter, zero-result, and
"its" referring to the *seam's* method — and an **incorrect** one, in which
`*Sitemap`'s own method was the thing shortened.

The incorrect parse is exactly the inversion `#0346` exists to correct, and
that inversion has already cost a full bounce once: it originated in `#0346`'s
filed description, was copied faithfully into `CLAUDE.md` §8, survived that
pass's own verification, and was caught only by a three-tree `go/types`
measurement.

The truth, measured repeatedly: `(*seo.Sitemap).Invalidate` has carried that
short name since `18960b4` (`#0020`) and was never renamed until `#0337`
unexported it. `#0325` renamed `(*Site)`'s and `(*Renderer)`'s methods **and
both seam interfaces**. `*Sitemap` was recruited without being touched.

`internal/seo/sitemap.go`'s companion comment states this unambiguously. This
one should match it.

## Acceptance criteria

1. The doc comment has only one available parse, and it is the correct one:
   `*Sitemap`'s method was never renamed; the seams' required method was, and
   that is what recruited `*Sitemap`.
2. It is consistent with `internal/seo/sitemap.go`'s companion comment — read
   both and make them agree in substance and in framing.
3. Comment-only. Prove it structurally: parse both revisions with comments
   excluded, compare bytes, with the tool proved falsifiable first and failing
   closed on empty input (§8 records a fail-open that arose exactly that way,
   and three agents found bugs in their own instruments this session).
4. `gofmt` stability: file sha256 equals sha256 of `gofmt` stdout — this is a
   declaration doc comment, exactly what §8's smart-quote gotcha rewrites.
5. Any historical claim is re-verified against `git show`, not copied from this
   issue.
