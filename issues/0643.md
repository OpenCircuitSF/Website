# 0643 — Pre-fill a new newsletter with the month's upcoming events and their newsletter ShortLinks

## Description

The user's request, 2026-11-05: "We need to update how the newsletter is created. The body should be pre-filled with the upcoming events for the month with short links which have UTM values for the newsletter which go with the campaign already created for the event."

So when an admin creates a newsletter (an email campaign), its body should start out listing the upcoming events for the month. Each event's link should be a ShortLink whose destination carries newsletter UTM values (for example `utm_source=newsletter`, `utm_medium=email`) and which belongs to the ShortLinks campaign already created for that event by Outreach.

## Acceptance criteria

- [ ] Creating a newsletter pre-fills the body with the upcoming events for the month, each with a title, date/time, venue and link.
- [ ] Each event link is a ShortLink in that event's existing ShortLinks campaign, pointing at the event page with newsletter UTM values. Reuse an existing newsletter link for the event rather than creating duplicates.
- [ ] The admin can still edit the body freely before sending; the pre-fill never overwrites text the admin has typed.
- [ ] If ShortLinks is unavailable or an event has no campaign, the body still pre-fills, with a clear fallback (plain event URL with UTM values, or a note), and the admin is told.
- [ ] Past events and unpublished events are left out.
