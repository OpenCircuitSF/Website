## Description

Three residues of `#0182`, found by its pass-2 review. The first is the one that matters.

**1. The terminal-row call site has no end-to-end test.** `MarkFailedRow`'s `adminSendErrorMessage(sendErr)` argument can be replaced with `""` and **the whole suite still passes.**

`#0182`'s committed end-to-end test uses `errors.New(sesText)`, which matches no modeled SES type and therefore takes the **retryable** path — not the terminal-row path that pass 1's reviewer originally exercised with a real `&types.MessageRejected{}`. So the property holds (the reviewer re-proved the terminal route by hand), but the committed test does not cover the route it appears to.

That is the same shape as `#0171`: a test that looks like it guards a path and guards its neighbour.

**2. SDK transport and credential failures reach admins raw.** `#0182` established that everything on the raw-text branch is AWS-SDK-authored — which is true, but "AWS-authored" is not "what the recipient's mail system said". A credential refresh failure or a DNS/dial error arrives through the same site as:

> `operation error SES v2: SendEmail, … failed to refresh cached credentials …`

Same class as `#0182`, one layer narrower: an admin looking at a failed row learns nothing actionable from it, and it is an infrastructure fault rather than a delivery outcome.

**3. The unprefixed fallback is a catch-all, not an enumeration.** `!hasPrefix → adminSendBuildFailureMessage` means any *future* unprefixed return would be silently mislabelled "could not be built". `#0182` bounced once for exactly this — assuming a class rather than enumerating it — so the shape is worth closing while it is fresh.

## Acceptance criteria

- [ ] An end-to-end test drives the **terminal-row** path with a modeled SES type (`&types.MessageRejected{}` or similar) through `drainCampaign` and reads back via `CampaignStatsStore.FailedSends` — and **fails** if `MarkFailedRow`'s message argument is replaced with `""`
- [ ] Decide how to present SDK transport/credential failures: mapped to fixed admin text like our own errors, or passed through with a marker distinguishing "this send was rejected" from "we could not reach SES". Record the reasoning — an admin debugging a bad campaign and an admin debugging a broken deployment want different things
- [ ] The unprefixed branch either enumerates the returns it expects (failing loudly on an unrecognised one) or documents why a catch-all is right there
- [ ] `#0181`'s citation guard still passes against any new strings
- [ ] `ISSUE=0185 scripts/check.sh go ./internal/...` passes with zero skips
