## Description

Generate the twelve unfurl images for the second batch of Raspberry Pi guides (`#0723`–`#0726`), exactly as `#0722` did for the first batch: read `#0722` in full (its Fix, Verification and Work log record the Codex command, the post-processing and the three re-rolls), then follow `assets/og/guides/PROMPTS.md`'s "How to use this file".

Slugs: `pi-find-on-network`, `pi-models-compared`, `pi-gpio-pinout`, `pi-zero-usb-ports`, `pi4-micro-hdmi`, `pi4-heat-throttling`, `pi-wifi-dropouts`, `pi-run-on-boot`, `pi-backup-sd-card`, `pi-zero-audio-out`, `pi-rgb-matrix-basics`, `pi-rgb-matrix-power`.

Also add one line to `PROMPTS.md`'s "How to use this file" about `#0710`'s 40,000 B cap on each image's 640×336 thumbnail (`TestGuideThumb_EmbeddedSetWeight`): dense, multicoloured images can pass the 1,000,000 B PNG limit and still fail it.

## Acceptance criteria

1. Twelve 1200×630 PNGs at `internal/seo/cardassets/guides/<slug>.png`, each under 1,000,000 B and each thumbnail under the 40,000 B cap.
2. Each looked at directly (Read tool; never a browser, AGENTS.md §8): no lettering, logos or brand marks; subject inside the crop; on-style with the set.
3. Work log: Codex command and model, re-rolls and why.
4. `ISSUE=0727 scripts/check.sh go ./internal/seo/... ./cmd/opencircuit/... ./internal/db/...` passes.
5. The user approves the images (as for `#0722`).
