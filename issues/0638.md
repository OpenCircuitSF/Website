## Description

Since `#0627`/`#0628`, opening a workshop in Outreach automatically creates ShortLinks and hand-posted drafts for TikTok, Instagram Reels and YouTube Shorts (`POST /admin/workshops/{id}/outreach/hand-links`). That also happens for a workshop that has already started or ended, so **Post by hand** and Results count posts that will never be made.

**User's decision, 2026-11-05:** "yes to … 3" — past workshops skip the automatic ShortLinks.

## Acceptance criteria

- [ ] Opening a workshop whose start time has passed does not call or perform the automatic hand-links creation; nothing new is written for it.
- [ ] Hand links and drafts that already exist for a past workshop are untouched.
- [ ] The server refuses (or no-ops) the automatic path for a started workshop too, so the rule doesn't live only in the SPA.
- [ ] Upcoming workshops behave exactly as before.
- [ ] Tests cover past, starting-now and upcoming workshops.

## Relation

- Follows `#0627`, `#0628`. Touches `internal/handlers/admin_outreach_handlinks.go` and the SPA call site.
