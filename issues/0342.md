## Description

Two stale comments survived `#0297`'s two implementation passes and both of its
reviews. Neither affects behaviour, a bound, or a test.

**1. `internal/mailing/outbox_worker.go:572-576`** — the inline comment at
`pass`'s `trackClaimed` call site still reads *"so a `Stop` landing anywhere in
`sendOne` still sees it as outstanding — see `trackClaimed`'s doc comment"*.

That is the **identical falsehood** `#0297`'s bounce required be removed from
`trackClaimed`'s own doc comment, 150 lines away in the same file — and it now
cites the very doc comment that refutes it. `Stop` blocks on `doneCh`, which
cannot close mid-send, so it never observes a row there. The first review
enumerated four such sites; the implementer found and fixed a fifth on its own
initiative and missed this sixth.

**2. `internal/handlers/subscribe_intake_test.go:184-186`** — still says
"`#0294` has since raised `intakeOrphanStaleAfter` … 210s and `#0284` raised
`outboxOrphanStaleAfter` to 800s". Both are superseded by `#0297`: the windows
are now 30s and 70s. It labels its numbers historical, so it misleads less, but
the figures are wrong as stated.

Filed rather than bounced because a second bounce would have escalated
`#0297`'s next pass to Opus (§3) for a two-sentence comment edit — the wrong
trade under that section's own cost rule.
