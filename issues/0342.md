## Description

reviews. Neither affects behaviour, a bound, or a test.

**1. `internal/mailing/outbox_worker.go:572-576`** — the inline comment at
`pass`'s `trackClaimed` call site still reads *"so a `Stop` landing anywhere in
`sendOne` still sees it as outstanding — see `trackClaimed`'s doc comment"*.

initiative and missed this sixth.

"`#0294` has since raised `intakeOrphanStaleAfter` … 210s and `#0284` raised
`outboxOrphanStaleAfter` to 800s". Both are superseded by `#0297`: the windows
are now 30s and 70s. It labels its numbers historical, so it misleads less, but
the figures are wrong as stated.

`#0297`'s next pass to Opus (§3) for a two-sentence comment edit — the wrong
