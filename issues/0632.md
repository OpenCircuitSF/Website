# 0632 — Outreach can lose an unsaved edit without warning in two more ways

| | |
|---|---|
| **Status** | open |
| **Platform** | All |
| **Module** | outreach |
| **Phase** | 10 — Outreach |

## Description

Found in `#0625`'s review. Neither was caused by that issue.

1. **Confirmed by a jsdom test:** **Save message** replaces an unsaved Customize edit on a non-customized post in that section, with no warning, because the composer picks up the new server body.
2. **Read in the code, not run:** `web/src` has no `beforeunload` handler, so a reload or closed tab loses unsaved work with no warning. In-app links were not checked for a guard.

The open and closed triangles on the board and strips are also very small. The hit areas are fine, so this is cosmetic.

## Acceptance criteria

- [ ] **Save message** cannot silently discard an unsaved Customize edit.
- [ ] Leaving the page with unsaved Outreach work warns first, for a reload, a closed tab and an in-app link.
- [ ] The triangles are easy to see at normal zoom.
