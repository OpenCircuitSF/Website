## Description

Brennan found `#0559`'s `full-photo` layout messy: everything was in one box
across the top. A Fable design pass produced three proposals, and he chose
**B, "caption"**:

> This version looks best. It has the title and subtitle near the top and then
> the longer description is near the bottom. That design and layout works best.

**The approved design is the spec.** Match it:

- Mockup: `/private/tmp/claude-501/-Users-brennan-Developer-OpenCircuitSF-Website/e9fedb52-7ddf-4f3c-a103-780353b40d22/scratchpad/flyer-layout-fable/b-caption.html`, generated by `gen.py` in the same folder.
- Renders: `out/b-caption-full.png` and `out/b-caption-half.png` in the same folder.
- Design notes: `NOTES.md` in the same folder. It covers the type scale, contrast numbers, focal rule and the data the app needs.

The scratchpad is not durable. The planner copies the facts the implementation needs (sizes, colours, alpha, insets, rules) into `## Plan`.

Layout B, in brief:

- **Photo:** full bleed, cropped around the focal point.
- **Title box:** placed just below the photo's subject.
  - Semi-transparent dark fill, `rgba(11,16,10,.72)`, with a green accent bar on the left edge.
  - Holds the big title, which is uppercase in the mockup, and the tagline.
- **Footer box:** semi-transparent, at the bottom left.
  - Holds the date and time (green mono), the venue (mono), and the workshop description.
  - Under a thin rule: `> open_circuit_sf` (green mono) at the bottom left and `OpenCircuitSF.com` at the bottom right.
- **QR box:** opaque white, at the bottom right, with the location label under the code.
- **Half-size double:** the same composition, scaled. A shorter description is used, with a line clamp as a backstop.

## Acceptance criteria

- [ ] **Layout.** `full-photo` renders layout B in both print formats (full Letter, and half-size double inside `#0549`'s rotation and cut line), with the mockup's proportions, type scale, colours, insets and 0.72 alpha. `photo-top` and `split` are unchanged.
- [ ] **Contrast.** The `flyers.ts` contrast test is updated for 0.72 alpha. Every text colour stays at least 4.5:1 against the fill composited over white. The mockup's measured worst case is the tagline at 5.6:1. The QR quiet zone stays opaque white.
- [ ] **Title placement.** The title box's vertical position comes from the focal point: below the subject when `focal.y` is in the top half, above it otherwise, per NOTES.md. A per-flyer override (auto / top / middle, or whatever the plan settles on) is stored and editable in the flyer editor. Title and footer never overlap in either format; prove this with a unit test of the placement function over focal-y extremes.
- [ ] **Title fit.** A long title never breaks mid-word. The font size steps down (NOTES.md: 54 → 48 → 42pt full, scaled for half). The step is a pure TS function with unit tests.
- [ ] **Description.** The footer shows the workshop's description by default. The flyer editor can override it per flyer, with an optional shorter text for the half-size format; without one, the half format shortens at a word or sentence boundary, never mid-word. Any new column goes in a **new migration `000036`**: `000031`–`000035` have not reached production either, but new work goes in a new file per CLAUDE.md §1. Update `docs/database.md` to match.
- [ ] **Wordmark and URL.** `> open_circuit_sf` sits at the bottom left in the footer box and `OpenCircuitSF.com` at the bottom right. No short link is printed on `full-photo`.
- [ ] **Fonts.** The print view uses the self-hosted Archivo and JetBrains Mono, as in the mockup.
- [ ] **Tests.** jsdom `FlyerFace` tests cover the new structure. Go tests cover the new fields: store round-trip, handler validation and length limits. Existing flyers keep working with defaults.
- [ ] **No browser on the host.** Never launch Chrome, Chromium, Playwright, Puppeteer or host Safari. A rendered check, if done, runs in a disposable Tart VM clone per `~/Developer/Homelab/cameron/tart-ui-test-vm.md`, using Safari plus WebDriver in the guest, with `tart-lease`, and with stop and delete in an EXIT trap. The reviewer should do one rendered comparison against `b-caption-full.png` this way, rebuilding the preview harness in `/private/tmp/claude-501/-Users-brennan-Developer-OpenCircuitSF-Website/e9fedb52-7ddf-4f3c-a103-780353b40d22/scratchpad/flyer-preview-0559/` against the real component.
- [ ] Verified with `ISSUE=0561 scripts/check.sh`, plus `internal/handlers` and `internal/db` as CLAUDE.md §5 requires for the files touched, and `scripts/testdb.sh template` after the migration.
