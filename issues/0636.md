# 0636 — Some Outreach controls still act as if a switched-off channel were on

|---|---|

## Description

Found in `#0628`'s review.

1. With every channel off, `Write it` and `Write the announcement` still show, but they draft nothing and give no message.
2. After Unschedule on an off channel, the cell reads `Mastodon (off)` Draft until the next reload, because `onChange` does not refetch the view. The server hides that draft on reload, and until then its Schedule returns 409.
3. A section's `Post to Bluesky and Mastodon` button still names an off channel whose post is scheduled. `#0588` allows acting on such a post, but a bulk button posting to a channel that is off may deserve a decision.

## Acceptance criteria

- [ ] With every channel off, the Write controls explain why nothing can be drafted.
- [ ] After Unschedule on an off channel, the board matches what the server will show.
- [ ] The user decides whether a bulk post may include an off channel, and the button says what it will do.
