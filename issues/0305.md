# 0305 — The growth dashboard now understates import-driven growth

| | |
|---|---|
| **Status** | open |

| **Module** | web / admin dashboard |
| **Phase** | 8 — Archive, imports, and delivery health |
| **First seen** | 2026-08-27 |

## Description

`#0292` stopped stamping `confirmed_at` on imported subscribers, which fixed a
real overstatement: an import of 500 addresses read as 500 confirmations on the
growth dashboard, and the admin detail view claimed a local confirmation that
never happened.

**`web/src/lib/dashboard.ts`'s `formatGrowthDetail` still renders `confirmed_30d`
as "N joined, M left".** That wording was accurate when the count meant "became
active". It now means "locally confirmed", so:

- an import of 500 addresses reads as **0 joined**;
- `net_30d` can go **negative** in a month with a large import plus normal churn,
  while the list is in fact growing.

So the number has stopped overstating and started understating, in the opposite
direction from the bug `#0292` fixed. `#0292`'s criterion 3 explicitly permitted
the exclusion and scoped its wording fix to the Go doc comment, so this was
correctly out of its scope — but it is now the one remaining place where the
dashboard says something untrue.

## Acceptance criteria

1. The label stops claiming "joined" for a count that means "locally confirmed".
   Either relabel it accurately, or show an imported-in-30-days figure alongside
   so import-driven growth is visible rather than invisible.
2. `net_30d` does not read as negative in a month where the list grew. If the
   figure keeps its current definition, it must be labelled so that is obvious;
   if it changes definition, say what it now counts and update
   `Growth30Days`'s doc comment to match.
3. **Whatever the dashboard displays and whatever `Growth30Days` documents must
   agree.** The mismatch between them is the whole of this defect and of
   `#0292`'s.
4. If a new count is added, it comes from the existing query rather than a
   second round trip — `#0292`'s reviewer confirmed `Growth30Days` needed no
   query change, so the data is likely already there.
5. A test asserts the rendered figures against seeded data including an import,
   and fails if the label and the underlying count disagree again.
6. `ISSUE=NNNN scripts/check.sh web` passes, and `scripts/check.sh go ./internal/handlers/...`
   if the Go side changes.
