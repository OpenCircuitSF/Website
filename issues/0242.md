## Description

`#0063` settled a console-wide question: a live region must be a **persistent
DOM node whose text mutates**, never a node created and destroyed by an `{#if}`.
A recreated node is not announced — the assistive technology has nothing to
observe changing.

That decision is recorded only in prose and in comments. Nothing enforces it,
and the failure mode is already demonstrated twice over:

- `#0063`'s own sweep left six identical instances unconverted while its
  comments described the decision as applied console-wide.
- `SubscribeForm.svelte`'s error region **looked correct by inspection** —
  an `{#if}/{:else}` with matching `id`s — and was only proved broken by driving
  a real browser and watching a `__marker` property fail to survive the
  transition.

That second point is the argument for a guard rather than review discipline:
**this defect is invisible to reading.** The markup looks right. Only the
compiled template, or the live DOM, shows the node being replaced.

The project already has the technique. `#0181`, `#0197` and `#0120` are AST
guards over Svelte source, and `#0222`'s focus-wiring guard walks templates for
exactly this kind of structural property. `#0095`, built in the same session,
exists to argue that comments cannot hold invariants — while this invariant is
held by comments.

## Acceptance criteria

- [ ] An AST guard fails when a `role="status"` / `aria-live` element is created by an `{#if}` or `{#each}` rather than persisting with mutating text
- [ ] It distinguishes the legitimate alternative — a whole-panel swap that moves focus instead, as `Unsubscribe.svelte` does — rather than flagging it
- [ ] Mutation-proved in both directions: reverting a converted site fails the guard; every currently-correct site passes
- [ ] It runs over the whole `web/src` tree, not a hand-maintained file list — `#0063` was bounced precisely for sweeping the files it happened to be editing
- [ ] Any site it cannot classify is reported loudly rather than skipped, per the silent-row-masking class (`#0083`, `#0092`, `#0224`)
- [ ] `scripts/check.sh web` passes

## Notes

Reported by `#0063`'s phase-3 review under `CLAUDE.md` §9.

Worth writing the guard against the **compiled** template rather than the source
where practical: the `SubscribeForm` case proves source markup can look correct
while the compiler still emits two branches. The reviewer distinguished the two
builds precisely that way — pre-fix served two `$.if` templates, post-fix one
inline `<p>` via `$.sibling`.

`CLAUDE.md` §1 is explicit that these AST guards are not redundant with the
component harness: they catch drift between what a test claims and what a
component says, which mounting cannot.
