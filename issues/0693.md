# 0693 — RC charging demo floods screen readers during its animation

| | |
|---|---|
| **Status** | open |
| **Platform** | All |
| **Module** | web |
| **Phase** | 10 — Outreach |
| **First seen** | 2026-11-16 |

## Description

Reported by `#0691`'s review. In `web/src/lib/topics/RcChargeDemo.svelte` the readout inside the `aria-live` region updates about every 30 ms while the charge or discharge animation runs, so a screen reader may queue dozens of announcements.

## Acceptance criteria

1. The live region announces only the settled state (for example, once the animation ends or the reader stops dragging), while the visible readout still updates every frame.
2. A jsdom test proves the live-region text does not change mid-animation.
