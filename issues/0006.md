Given the explicit instruction not to rewrite `CLAUDE.md`, I did not add those headings; flagging this gap for the reviewer's judgment rather than silently deciding it's fine.

**`README.md`** — rewrote from a bare `# Open Circuit SF` heading to a full README: a features list (grounded in `PRD.md` §5/§6, explicit about what's built vs. planned), a stack table, a quick-start pointing at `./scripts/dev.sh`, the production build sequence, and links to `docs/README.md`/`CLAUDE.md`/`issues/Issues.md`.

**`docs/README.md`** — a per-topic index (Overview & setup / Data & backend / Mailing list / Frontend & brand / Project conventions), linking every doc below plus `CLAUDE.md`, `issues/Issues.md`, and `PRD.md`.

**Twelve subsystem docs** (`docs/dev.md` already existed from #0005 and needed no changes here):

- **Substantive, not stubs** — `architecture.md` (system diagram + component table + "where to look," per the issue's Notes), `auth.md`, `passkeys.md`, `frontend.md`, `database.md`, `configuration.md`, `design.md`.
