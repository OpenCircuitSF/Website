## Description

`#0352` removed the two `<file>.go:<int>` citations from
`internal/outbox/claim_kinds_call_site_guard_test.go`, replacing them with
stable identifiers. **The class is repo-wide.**

A census of Go comments by `#0352`'s reviewer found **30 such citations across
7 files**:

| File | count |
|---|---|
| `internal/handlers/audit_email_metadata_guard_test.go` | 11 |
| `internal/handlers/citation_target_guard_test.go` | 11 |
| `internal/outbox/outbox_kind_detection_test.go` | 3 |
| `internal/…/logging_test.go` | 2 |
| `internal/handlers/citation_guard_test.go` | 1 |
| `internal/mailing/templates_test.go` | 1 |
| `internal/seo/sitemap_test.go` | 1 |

**Two spot-checked at random were both already stale:**

- `internal/seo/sitemap_test.go:80` says "`sitemap.go:86` checks only
  `w.Status`" — that line is `workshops, err := s.source.Workshops()`.
- `internal/mailing/templates_test.go:404` cites `mailer.go:105`, which is a
  **blank line**.

A line number is invalidated by edits to *unrelated* parts of the cited file,
which is what makes the drift silent; an identifier is invalidated only by an
edit to the cited thing itself. §11's PRD index was deliberately rebuilt
heading-anchored for exactly this reason.

## Why this needs a planning pass first

`#0352`'s reviewer endorsed a **Phase 1 (Opus) planning pass** under §3's
"real design latitude" test, and named four decisions where two implementers
would build different things:

1. **Scan scope** — comments only, or all text? (A comment-scoped scan excludes
   runtime `%s:%d` format strings for free, since those live in string
   literals.)
2. **Citation versus fixture.** `outbox_kind_detection_test.go` cites *itself*
   inside an indented block that is a rendered `go test` failure transcript.
   `citation_target_guard_test.go`'s 11 are the citation guard's own prose
   *about* citations. Neither is a stale citation; both match any naive
   pattern.
3. **Fix all 30, or grandfather behind an allowlist?** An allowlist here is
   precisely §8's "a copy of the answer stored next to the question" hazard —
   and `#0337`'s `embeddingReviewed` allowlist, keyed on a name, was proved not
   to stay true.
4. **Where the oracle belongs**, per §8's direction-of-comparison rule: in Go,
   or in an external `scripts/check.sh guards` harness.

The existing `internal/handlers` citation-guard family — which already catches
comments citing unresolvable paths and undefined test functions — is **2,173
lines across three files** and took five issues of design iteration. That is the
scale being extended, and the reason this is not a mechanical pass.

## Acceptance criteria

*To be written by the planning pass.* At minimum it must settle the four
decisions above, with reasons, and say which of the 30 citations are real
defects versus legitimate fixtures.
