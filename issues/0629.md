## Resolution notes

> 🟢 Resolved 2026-11-05 — The unused `GET`/`POST .../outreach/links` routes, handlers and SPA helpers are removed with nothing left referring to them, and the link report now points to **Create link** on a post or **Print** on a flyer, both of which exist.

## Description

`linkReportMessage` in `web/src/lib/outreachLinks.ts` tells the user to "use Create missing links", but that button is gone. `createWorkshopOutreachLinks` and `getWorkshopOutreachLinks` have no SPA callers, so `POST` and `GET .../outreach/links` are unused by the UI. Found while planning `#0623`.

## Root cause

`GET`/`POST /admin/workshops/{id}/outreach/links` and their SPA helpers outlived the links table UI; only tests used them, and `linkReportMessage` still named a "Create missing links" control that no longer exists.

## Fix

Per `#0638`'s plan (shared commit): routes, handlers, view types, SPA API calls, types and dead wording helpers removed; tests moved onto hand-links or Start; `linkReportMessage` now points at **Create link** on a post or **Print** on a flyer.

## Plan

Planned 2026-11-05 together with `#0638` and `#0630`. **The full plan, the tests, the verification and `## Obstacles` are in `issues/0638.md`.** In short:

- **Remove** `GET` and `POST /admin/workshops/{id}/outreach/links`. That covers `Links`, `CreateLinks`, `linksView`, their view types and the two `main.go` routes. Nothing in the SPA calls them, and no doc, PRD section or route guard names them.
- **Remove** the SPA's `getWorkshopOutreachLinks`, `createWorkshopOutreachLinks`, `OutreachLinksView` and `OutreachLinkRow`, plus the dead `linksEmptyState`, `linkRowLabel`, `linkClicksLabel` and `draftAllMessage`. The last two also named controls that no longer exist.
- **Rewrite** the Go tests that used the route as a tool onto hand-links or Start. Delete `TestAdminOutreachLinks_View`.
- **Change** `linkReportMessage`, which is still used for Start's report, to point to **Create link** on a post or **Print** on a flyer.
