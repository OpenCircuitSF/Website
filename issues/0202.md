## Description

`#0201` made the walk-coverage test's ground truth exclude vendored trees by
anchored path prefix. Its phase-3 review verified the behaviour exhaustively and
passed it — then found the doc comment explaining *why* the invariant holds is
wrong.

The comment says `onDisk` "is a superset of that same walk **(it additionally
counts the two vendored prefixes `onDisk` would otherwise miss)**".

The ground truth does **not** count those prefixes — excluding them is the
entire change `#0201` made. That clause describes the pre-`#0201` unrestricted
walk, and survived the edit.

What `onDisk` actually counts in addition is **name-matched directories outside
the anchored prefixes**: `internal/dist`, `internal/node_modules`,
`web/src/node_modules`. That is precisely the set the two mechanisms disagree
about, and precisely why the test can still catch the shipped walk narrowing.

The conclusion the comment draws — `collected ⊆ onDisk` — is correct, and the
review confirmed it by execution. Only the justification is backwards.

**This is worth fixing despite being one clause**, because this test's value
lives almost entirely in that comment. The test is a set comparison; what makes
it meaningful rather than circular is the argument for why the two enumerations
differ where they do. A reader who trusts the current clause would conclude the
ground truth still walks `node_modules` — the exact thing `#0201` removed — and
could "simplify" the anchoring away on that basis.

## Acceptance criteria

- [ ] The doc comment states what `onDisk` actually counts in addition: name-matched directories outside the anchored vendored prefixes
- [ ] It names the concrete cases (`internal/dist`, `internal/node_modules`, `web/src/node_modules`) so the disagreement set is legible
- [ ] The `collected ⊆ onDisk` conclusion is retained — it is correct
- [ ] No behaviour change: `#0201`'s four plants still produce the same results, including the adversarial `internal/node_modules/` case
- [ ] `ISSUE=0202 scripts/check.sh go ./internal/...` passes with zero skips

## Notes

Reported by `#0201`'s phase-3 review under `CLAUDE.md` §9.

This is a comment-only change. Do not touch the anchoring logic — the review
mutation-tested it: reducing `path == prefix || HasPrefix(path, prefix+sep)` to
a bare `HasPrefix(path, prefix)` makes a planted `web/node_modules_extra/`
sibling fail, so the separator guard is load-bearing and not incidental.

`#0201`'s `## Review notes` carries the full plant table, including two
adversarial cases worth keeping in mind while rewording: `internal/node_modules/`
and the nested npm-workspaces shape `web/src/node_modules/`, both correctly
caught.
