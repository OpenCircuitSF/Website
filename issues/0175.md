## Description

`#0172` removed tracker citations from admin-facing copy. Its reviewer swept on a different axis — reading every rendered string rather than grepping for citation patterns — and found the same family of problem with no citation to grep for.

**1. "The send worker" is an implementation detail, rendered to admins in five places:**

- `Admin.svelte`'s physical-address hint
- `campaigns.ts`'s returned-to-draft text
- `campaigns.ts`'s two cancel confirmations
- `Campaigns.svelte`'s "Returned to draft — worker refused it" badge
- `CampaignEditor.svelte`'s stall hint

An admin has no model of a "worker". The facts behind these strings are real and worth telling them — a send was refused, a campaign went back to draft, something stalled — but the *reason* should be phrased in terms of the product ("sending stopped because no physical address is set") rather than the process that enforced it.

**2. User-visible copy mixes `--` and em dashes.** Two strings in `WorkshopEditor.svelte` and two messages in `workshopAdmin.ts` use a double hyphen where the rest of the console uses `—`.

## Acceptance criteria

- [ ] The five "worker" strings describe what happened and why in the admin's terms, without naming the worker. Keep the diagnostic value — an admin must still learn *why* a campaign returned to draft
- [ ] The physical-address hint in particular should say what to do about it, since that one is actionable (`#0045` refuses to send without it — CAN-SPAM §7704)
- [ ] Dashes are consistent across user-visible copy; pick the convention the console already uses and apply it
- [ ] **Sweep the way this was found**: read the rendered strings, do not grep for a word. `#0172`'s reviewer stripped `<script>`/`<style>`/comments from the admin views and read the text nodes plus `placeholder`/`title`/`aria-label`/`alt` — that method is what turned this up, and it is worth repeating rather than searching for "worker"
- [ ] Judged fine by that same review and **not** to be changed: the audit log's own displayed values (`${entry.target_type} #${entry.target_id}`, the `e.g. email_campaign` placeholder, `#0114`), `api.ts`'s `HTTP ${status}` fallback, and product vocabulary an admin genuinely meets ("slug", "double opt-in", "draft", "Markdown")
- [ ] `scripts/check.sh web` passes
