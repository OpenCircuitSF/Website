# 0214 — `docs/dev.md` still names the old hardcoded defaults, next to the example that breaks them

## Description

`#0213` made `BASE_URL` and `WEBAUTHN_RP_ORIGIN` derive from `$PORT` instead of
a hardcoded `8080`. Its phase-3 review found the documentation did not follow.

**`docs/dev.md:51,53` still list both defaults as the literal
`http://localhost:8080`.** They are now `http://localhost:${PORT}`. The table's
own example, six lines further down, is `PORT=9090 ./scripts/dev.sh` — which is
precisely the case where the stale literal misleads: a reader sets `PORT=9090`,
reads that `BASE_URL` defaults to `:8080`, and concludes the override is the
half-broken thing `#0213` just fixed.

**A second, cosmetic finding from the same review.** `web/vite.config.ts` sets
no `server.port` or `strictPort`, so `5173` is *inherited* from Vite's default
rather than declared. A bare `npm run dev` with `5173` occupied slides silently
to `5174` while `README.md`, `docs/dev.md`, `CLAUDE.md`, and `dev.sh`'s messages
all still say `5173`. Unreachable through `dev.sh` — `#0117`'s preflight refuses
before Vite starts — so this is about the bare-`npm` path only.

## Acceptance criteria

- [ ] `docs/dev.md`'s `BASE_URL` and `WEBAUTHN_RP_ORIGIN` rows describe values derived from `$PORT`, and stay correct when read alongside the `PORT=9090` example immediately below them
- [ ] No other doc states a default that `#0213` changed — check `README.md`, `docs/`, and `CLAUDE.md`
- [ ] `web/vite.config.ts` declares `server.port` (and decide on `strictPort`), so `5173` is stated rather than inherited — **or** the inheritance is recorded as deliberate where a reader would see it
- [ ] If `strictPort` is set, confirm `#0117`'s preflight and `dev_guard_test.sh` still behave — the guard binds `:5173` in several parts
- [ ] `scripts/dev_guard_test.sh` passes 8/8 with its byte-identity check intact
- [ ] `scripts/check.sh web` passes

## Notes

Reported by `#0213`'s phase-3 review under `CLAUDE.md` §9.

The first item is small and worth doing promptly: a stale default sitting six
lines above a worked example of overriding it is the most misleading possible
placement.

For the second, note the review's own correction: **`web/vite.config.ts` does
not spell `5173` at all** — both `#0213`'s Description and its implementation
note said it did, and neither was right. `5173` is fixed and env-free in
`README.md:61`, `docs/dev.md:12,24`, `CLAUDE.md:209`, and seven places in
`dev.sh`. Declaring it in the Vite config would make five files agree with the
code rather than four agreeing with each other.
