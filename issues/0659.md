## Description

The `/admin/guide-posts` handlers (list, create, patch, schedule, unschedule, send, delete), their routes, and an audit action for every change.

The design, file list, test names and verification commands are in `#0657`'s `## Plan`. The user's answers are in its `## Decisions (user)`. Follow both; do not re-plan. A short phase-1 pass may still narrow the plan to this slice.

### Added by the user on 2026-11-14

- **Campaign per draft.** Creating a draft takes a campaign name. Prefill it with something like `guides-YYYY-MM` and let the user change it. `#0658` makes the campaign slug a per-post input. The user reposts guides now and then under new campaigns.
- **Recently-shared overview.** Add an endpoint that returns one row per catalog guide: last posted date, channel(s), campaign, and total clicks. Guides never posted are included, so the admin can see what hasn't been shared. Clicks come from ShortLinks stats across every campaign that has guide posts.
- **"Schedule again"** copies a posted post into a new draft. The new draft can go under a new campaign and gets a new short link.

### `internal/guideposts` changes (small, all pure or store)

1. **`Linker.Ensure` returns whether this call stored the link**: `Ensure(ctx, id) (Post, bool, error)`. `minted` is `SetLink`'s `changed`; `false` on the early return (already linked) and on every error. The handler writes `guide_post.link_created` only when it is `true`, so a racing second caller or an already-linked post writes nothing (Outreach's rule for `outreach_link.created`). Update the 10 `Ensure(` call sites in `links_test.go`.
2. **Review follow-up 1: `UpdateBody` refuses an edit that removes the short URL.** Chosen: **refuse**, not re-append (see Assumptions). New `ErrLinkRemoved = errors.New("guideposts: the post must keep its short link")`. In `UpdateBody`, after `lockedStatus` and before validation: `if cur.ShortURL != nil && !containsURL(body, *cur.ShortURL) { return Post{}, ErrLinkRemoved }`. New unexported `containsURL(text, u string) bool`: true when some occurrence of `u` is followed by end of text or by a byte that is not `[A-Za-z0-9_-]` (the same boundary rule as `mastodon.containsLinkToken`, which is unexported, so copy it; a longer key that starts with this one must not count). Unlinked drafts are unchanged: `SetLink` already appends the URL when the token was removed.
3. **Validation errors become a typed error** so the handler can tell 422 from 500 without string matching. New `type BodyError struct{ Err error }` with `Error() string { return e.Err.Error() }` and `Unwrap() error`. `Create` and `UpdateBody` wrap the error from `ValidateDraft`/`outreach.ValidateForSend` as `&BodyError{Err: err}`. The message text is unchanged (it already names the count and the limit), so existing store tests keep passing.
4. **"Schedule again"**: `func (s *Store) CopyAsDraft(ctx context.Context, id int64, base, campaign string) (Post, error)`. `src := Get(id)`; `src.Status != "posted"` → `ErrWrongStatus`; `body := src.Body`, and when `src.ShortURL != nil`, `body = strings.ReplaceAll(body, *src.ShortURL, outreach.LinkToken)` so the copy gets its own new link in the same place; then `return s.Create(ctx, src.GuideSlug, src.Channel, body, base, campaign)`. `Create` re-validates the slug (a guide removed since → `ErrUnknownGuide`), the channel, the campaign (blank → `CampaignSlug`, the same rule as Create) and the body. The new row has a new id, so a new destination (`utm_content=gp{newid}`) and therefore a new short link.
5. **Pure helpers in `guideposts.go`**:
   - `SuggestedCampaign(now time.Time) string` = `"guides-" + outreach.PacificDate(now)[:7]` (for example `guides-2026-11`). The server sends it; the UI prefills it.
   - `ClickWindow(since, now time.Time) (from, to time.Time)`: `from` = UTC midnight of `since`, `to` = UTC midnight of `now` plus one day, and when the span exceeds `maxClickDays = 366` days, `from = to - 366 days`. Not `outreach.ResultsWindow`: that clamps to 120 days and to a workshop date, and a guide campaign has neither.
   - `PostRef(id int64) string` = `"gp" + id`, the `utm_content` value. `DestinationURL` uses it instead of its inline `"gp" + …`, so `#0662`'s signup rows can be matched to posts by the same function.
6. **Overview (pure)**, new file `internal/guideposts/overview.go`:
   ```go
   // GuideShare is one catalog guide's sharing history, for the admin's
   // recently-shared overview.
   type GuideShare struct {
       Slug            string     `json:"slug"`
       Title           string     `json:"title"`
       URL             string     `json:"url"`               // base + "/guides/" + slug
       LastPostedAt    *time.Time `json:"last_posted_at"`    // newest posted_at; nil = never posted
       LastCampaign    string     `json:"last_campaign"`     // campaign of that newest posted post; "" when never posted
       Channels        []string   `json:"channels"`          // distinct channels ever posted, sorted; [] when none
       Campaigns       []string   `json:"campaigns"`         // distinct campaigns ever posted, sorted; [] when none
       PostedCount     int        `json:"posted_count"`
       NextScheduledAt *time.Time `json:"next_scheduled_at"` // earliest scheduled post, if any
       Clicks          *int64     `json:"clicks"`            // sum over every linked post of this guide; nil when unknown
   }
   func Overview(topics []guides.Guide, posts []Post, base string, clicks map[string]int64, clicksKnown bool) []GuideShare
   ```
   One row per entry of `topics`, in catalog order, including guides with no posts. `Clicks`: `nil` when `!clicksKnown` or when any linked post of the guide is missing from `clicks`; otherwise the sum (`0` for a guide with no linked posts). Posts whose slug is not in `topics` are ignored. No new SQL: the post count is small and `Store.List` already returns every row.

| Method and path | Handler | Request | Response | Errors |
|---|---|---|---|---|
| `GET /admin/guide-posts` | `List` | — | `200 {topics, posts, channels, post_hour, suggested_campaign, clicks_error, signups_error}` | 500 |
| `POST /admin/guide-posts` | `Create` | `{slug, channel, campaign?, body?}` | `201 {post, link_error}` | 400 unknown slug or channel, 422 bad campaign or body |
| `PATCH /admin/guide-posts/{id}` | `Patch` | `{body}` | `200 post` | 400 bad id or JSON, 404, 409 locked or in flight, 422 body invalid or link removed |
| `POST /admin/guide-posts/{id}/schedule` | `Schedule` | `{scheduled_at}` (RFC 3339) | `200 post` | 404, 409, 422 time refused, 429/502/503 ShortLinks |
| `POST /admin/guide-posts/{id}/unschedule` | `Unschedule` | — | `200 post` | 404, 409 |
| `POST /admin/guide-posts/{id}/send` | `Send` | — | `202 post` (also Retry from `failed`) | 404, 409, 429/502/503 ShortLinks |
| `POST /admin/guide-posts/{id}/again` | `Again` | `{campaign?}` | `201 {post, link_error}` | 404, 409 not posted, 400 guide gone, 422 bad campaign or body |
| `DELETE /admin/guide-posts/{id}` | `Delete` | — | `204` | 404, 409 queued or posted |
| `GET /admin/guide-posts-overview` | `Overview` | — | `200 {guides: [GuideShare + signups], clicks_error, signups_error}` | 500 |

`/admin/guide-posts-overview` is hyphenated like `/admin/outreach-results`, so it never shares a prefix segment with `/admin/guide-posts/{id}`.

Behaviour per route:

- **`List`**: `topics` = every `guides.Topics()` entry with `Kind == guides.Topic` as `{slug, title, hook, post, url, default_body}` (`url` = `baseURL + "/guides/" + slug`, `default_body` = `guideposts.DefaultBody(g)`). `posts` = `store.List` as `guidePostView{guideposts.Post; Clicks *int64 `json:"clicks"`; Signups *guidePostSignups `json:"signups"`}`. `channels` = `bluesky` and `mastodon` from `outreach.ChannelByName`, as `{name, label, char_limit, configured}`. `post_hour` = `hourFn()` or `outreach.DefaultPostHour`. `suggested_campaign` = `guideposts.SuggestedCampaign(h.now())`.
- **Clicks** (shared by `List` and `Overview`), `func (h) clicks(ctx) (map[string]int64, string)`: `store.ClickKeys`; for each campaign, `from, to := guideposts.ClickWindow(c.Since, h.now())`, `rollup, _, err := h.statsCache().Get(ctx, c.CampaignSlug, from, to)`; on success merge `outreach.ClicksByKey(c.Keys, rollup)`; on error log it once (`slog`, the slug, never upstream text in the response) and remember `linkFailureReason(err)` as the page's `clicks_error` (first one wins). A failed campaign's keys are simply absent, so those posts show `clicks: null`; other campaigns still count. No linked posts → no ShortLinks call, `clicks_error` null. A `ClickKeys` database error is a 500. ShortLinks failing **never** fails the request.
- **`Create`**: decode; `store.Create(ctx, slug, channel, body, h.baseURL, campaign)`; audit `guide_post.created` `{slug, channel, campaign}`; then `post, minted, err := linker.Ensure(ctx, id)`. On `minted`, audit `guide_post.link_created` `{slug, channel, campaign, short_link_key}`. On error, log it and return `201 {post: <the unlinked draft>, link_error: linkFailureReason(err)}`; the draft is kept. `link_error` is `null` on success.
- **`Patch`**: `store.UpdateBody`; audit `guide_post.updated` `{slug, channel}` (never the body).
- **`Schedule`**: `parseScheduleAt(req.ScheduledAt, h.now())` → 422 `"scheduled_at " + reason`; load the post (404); channel not configured → 409 `"<Label> is not connected"`; `ensureLink` (below); `store.Schedule`; audit `guide_post.scheduled` `{slug, channel, scheduled_at}`.
- **`Send`**: load; channel not configured → 409; `ensureLink`; `store.QueueNow`; audit `guide_post.queued` `{slug, channel, retry: prev == "failed"}`; `202`.
- **`ensureLink(w, r, actorID, p) (Post, bool)`**: when `p.ShortURL == nil` and `p.Status == "draft"`, call `linker.Ensure`; on error `writeShortLinksError(w, "guide_post_link", err)` and stop (so a still-failing ShortLinks is a 503/429/502 with fixed text); on `minted`, audit `guide_post.link_created`. A non-draft row always has a link (`guide_posts_link_check`), so nothing is called for it.
- **`Unschedule`**: `store.Unschedule`; audit `guide_post.unscheduled` `{slug, channel}`.
- **`Again`**: `store.CopyAsDraft(ctx, id, h.baseURL, req.Campaign)`; audit `guide_post.created` `{slug, channel, campaign, copied_from: <source id>}`; then the same `Ensure` + `link_created` + `link_error` handling as `Create`.
- **`Delete`**: `Get` first (for audit metadata and the 404), then `store.Delete`; audit `guide_post.deleted` `{slug, channel}`; `204`. The ShortLinks link is left in ShortLinks (see Assumptions).
- **`Overview`**: `store.List`, `clicks`, then `guideposts.Overview(topics, posts, h.baseURL, clicks, clicksKnown)` where `clicksKnown` means at least one campaign answered or there were none; add `signups` per row (below).
- **Error mapping**, one helper `writeGuidePostError(w, err)`: `ErrNotFound` 404 "post not found"; `ErrPostLocked` 409 "post is already posted"; `ErrPostInFlight` 409 "post is being sent"; `ErrWrongStatus` 409 "post is not in a state that allows this"; `ErrNoLink` 409 "the post has no short link yet"; `ErrUnknownGuide` 400 "not a topic guide"; `ErrChannelUnknown` 400 "unknown channel"; `ErrBadCampaignSlug` 422 "campaign may use only lowercase letters, digits and single hyphens"; `ErrLinkRemoved` 422 "the post must keep its short link"; `errors.As(*guideposts.BodyError)` 422 with its message; anything else is logged and 500 "internal server error".
- Path ids through `outreachPathID` (same package). Bodies through the same JSON decode helper Outreach's handlers use.

### Assumptions (user may override)

1. **Removing the short link from a linked post's text is refused (422), not silently re-appended.** What you see in the editor is exactly what posts, and the character count stays honest. Re-appending would change the text after you saved it.
2. **"Schedule again" works only on a posted post.** The copy is a new draft with the same text, the old link swapped for a new one, in the campaign you choose (prefilled with this month's `guides-YYYY-MM`). A blank campaign means the default `guide-posts`, the same as a new draft.
3. **Clicks cover up to the last 366 days per campaign.** Each campaign is read from its first post's day to tomorrow (UTC). Outreach's 120-day limit is tied to workshop dates and does not fit guides. A campaign older than a year counts only its last year of clicks.
4. **When ShortLinks fails, the page still loads.** Affected posts show no click count and a page-level `clicks_error` explains why. One failing campaign does not hide the others.
5. **The overview lists guides in catalog order.** Sorting (by last posted, never-posted first, and so on) is the UI's job in `#0660`. The row carries everything needed to sort.
6. **A guide's `channels` and `campaigns` cover every post ever made for it.** `last_campaign` is the campaign of the most recent post.
7. **Deleting a draft does not delete its ShortLinks link.** The link stays in ShortLinks with no clicks. Deleting it would need a ShortLinks API call that nothing uses today.
8. **Signups per guide count every signup from that guide's page**, from a post link or a direct visit. Signups per post count only visits that arrived through that post's link (`utm_content=gp{id}`).
9. **Scheduling or sending needs the channel connected in Settings → Outreach** (409 otherwise). A draft can be created and edited while it is not connected.
10. **The suggested campaign uses the Pacific month**, matching every other date the admin shows.
