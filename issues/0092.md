# 0092 — The docs guard still accepts two illegal fence closers

## Description

`#0089` replaced a `HasPrefix` fence check with a `leadingRunLength` one and closed
the two drift forms it was filed for. Its review then probed ten further fence shapes
and found **two more residuals**. Neither is a regression — the old `HasPrefix` code
behaved identically — but both are the same drift mode `#0089` targeted: a line that
CommonMark does *not* treat as a fence closer is treated as one here, so the parser
resynchronises early and a table row after it slips past the guard unnoticed.

## The two forms

1. **A closer indented four or more spaces still closes the fence.** The check runs
   on `trimmed`, which has already had all leading whitespace stripped. CommonMark
   caps a closing fence at three spaces of indentation; at four it is indented code
   inside the block. Probe yields 1 row, want 0.
2. **A closer with trailing text still closes the fence.** ` ``` nope ` has a leading
   run of three backticks and so satisfies `leadingRunLength(trimmed, fenceChar) >= fenceLen`.
   CommonMark permits only whitespace after a closing fence. Probe yields 1 row, want 0.

## Acceptance criteria

- [ ] A closing fence indented 4+ spaces is not treated as a closer
- [ ] A closing fence followed by non-whitespace text is not treated as a closer
- [ ] Both forms added as table-driven cases to the existing `cases` slice, each
      failing before the fix and passing after — quote the failing output
- [ ] The eight shapes the review confirmed correct stay correct (5-fence closed by 4
      and by 5, longer-than-opener closer, trailing whitespace after closer, closer
      indented ≤3 spaces, both tilde forms) — they are regression cover, not optional
- [ ] Indentation measurement is untouched: `col += 4 - (col % 4)` is CommonMark's
      next-multiple-of-4 tab rule and was verified correct across eight probes

## Notes

Successor to `#0089`. Its review verified the tab-stop arithmetic separately and found
no mismatch, so this issue is only about the fence-closer predicate.

This guard has now had residuals found in **four consecutive rounds**. That pattern is
the argument for the `#0089` follow-up that commits the twelve probe forms into the
suite rather than re-deriving them by hand each time.
