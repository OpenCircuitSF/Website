## Description

`ClaimDue` and `OrphanSweep` take `kinds ...Kind`, implemented as
`cardinality($n) = 0 OR kind = ANY(...)`. **An empty slice means every kind**, so
the variadic makes the dangerous case the default and the safe case the one you
have to remember.

Forgetting it is not hypothetical. It is `#0254`'s defect: the intake sweep ran
unscoped, released live mail claims, and produced duplicate confirmation
emails. `#0281` then built a guard that flags any unscoped call outside
`internal/outbox` — and **building that guard found four more violations**
(`admin_dashboard_test.go` ×2, `admin_pending_test.go`, `outbox_worker_test.go`)
that `#0254`'s reviewer had missed by enumerating only production call sites.

So the omission has now been made five times.

**The guard is the right immediate fix and it is in place.** This issue is the
structural one: make the safe case the default, so sweeping across kinds has to
be asked for by name.

`#0281`'s implementer considered this and deliberately deferred it — it touches
the exported `Store` signature and roughly 35 call sites across production and
tests, which is a change of a different size than the guard it was building.

## Acceptance criteria

1. `kinds` becomes a required parameter. Sweeping every kind is expressed as an
   explicit `AllKinds` sentinel (or equivalent) that reads as a deliberate act at
   the call site.
2. Every call site is updated — production and tests, ~35 of them. The
   package's own tests that legitimately exercise the unscoped default use the
   sentinel, so they still document that behaviour.
3. `#0281`'s guard is updated to match the new signature, and **kept**. A type
   change and a guard are complementary: the signature stops the omission, the
   guard stops a future overload or wrapper reintroducing it. Do not delete it
   as now-redundant.
4. The SQL keeps working for both cases, and a DB-backed test covers the
   sentinel path explicitly — an `AllKinds` that silently matched nothing would
   be worse than the variadic.
5. Prove the change catches the original defect: a call site that means to scope
   but does not must now fail to compile, not merely fail a guard.
6. `ISSUE=NNNN scripts/check.sh go ./internal/... ./cmd/...` passes with no skips.
