# 0119 — The blocked Send button's `aria-describedby` points at an id that does not exist, so a screen reader announces no reason

| | |
|---|---|
| **Status** | open |
| **Module** | web / design |
| **Platform** | All |
| **Phase** | 5 — Campaigns |
| **First seen** | 2026-08-21 |

## Description

`CampaignEditor.svelte`'s Send button carries
`aria-describedby="preflight-panel-hint"`, but **no element in the SPA has that
id** — `grep -rn "preflight-panel-hint" web/src` returns exactly one hit, the
reference itself. The attribute is silently ignored, so a blocked Send button
announces as "Send, unavailable" (`aria-disabled="true"`) with no reason
attached. That is precisely the failure `#0047`'s own Notes exist to prevent:
"an operator staring at a greyed-out send button with no reason given will work
around it or give up."

`#0047`'s plan §7 committed to this explicitly — "`aria-describedby` also points
the button at the pre-send panel." It ships pointing at nothing.

Partially mitigated today: the "Pre-send checks" panel is rendered
unconditionally and is visible, and activating the blocked button moves focus to
the panel's heading (`onOpenSend`'s `preflightHeadingEl?.focus()`), which does
work. So the information is reachable — it just is not announced with the
control.

## Acceptance criteria

- [ ] The Send button's `aria-describedby` resolves to a real element — give the
      pre-send panel's `role="status"` container `id="preflight-panel-hint"`, or
      point the attribute at whichever element actually carries the explanation.
- [ ] A blocked Send button's accessible description names the pre-send checks.
- [ ] The `<h3>Pre-send checks</h3>` inside `<Panel title="Pre-send checks">`
      no longer duplicates the panel header visually. The `<h3 tabindex="-1">`
      exists only as a focus target for `onOpenSend`; either drop the `Panel`
      title or make the focus target the panel header itself.

## Notes

Found by `#0047`'s phase-3 review. `#0063` audits this view for accessibility
and would catch it there, but it is a one-line defect against a commitment the
plan named, so it is worth fixing before that broader pass.
