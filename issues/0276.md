## Description

`internal/mailing/worker_test_helpers_test.go:86` has

```go
// newTestWorker constructs a Worker …
const (
	testWorkerBaseURL = …
	…
)
```

so `func newTestWorker` is undocumented and the sentence describing it is
attributed to a block of constants. This is structurally the same defect
`#0267` fixed at `internal/handlers/subscribe_test.go:1605` — a doc comment
naming one declaration attached to its neighbour.

**`#0267`'s guard does not catch it, by design.** The guard excludes the
group-level doc of a `GenDecl` with two or more specs, because six such
instances exist on this tree and five are the benign, pervasive idiom of
captioning a `const`/`var` group (`CampaignStatus*`, `PreflightCode*`,
`SuppressionReason*`, `Source*`, `Status*`). This one is the sixth, and it is
not benign.

`#0267`'s `## Implementation notes` states of those six that **"None is
`#0267`'s defect shape"**. That is wrong for this instance, and `#0267`'s review
corrected the record rather than bouncing the issue, since the stakes are a
test-only helper and the comment's second sentence genuinely does describe the
constants.

## Why no structural rule fixes this

The review checked the obvious narrowing before endorsing the exclusion:
*"check a group doc when its first word names a function in the same file"*
would still flag `Preflight` (`internal/mailing/preflight.go:150`) and
`Unsubscribe` (`internal/db/store.go:824`), both of which are legitimate
captions that happen to share a name with a function. No cheap structural rule
separates the good from the bad here, which is why the exclusion stands and
this instance needs fixing by hand.

Also recorded, for whoever touches the guard next: a **single-member**
parenthesised `const (…)` / `var (…)` block carrying a category-noun doc *is*
checked and would false-positive. None exists on the tree today; the
`nonTestIdentifierAllowlist`-style allowlist is the escape hatch if one appears.

## Acceptance criteria

1. The `newTestWorker` sentence moves onto `func newTestWorker`. The remaining
   sentence, which describes the constants, stays on the `const` block — this
   is a split, not a move of the whole comment.
2. `go doc` on the helper is not the check (it is an unexported test symbol);
   instead assert by reading that the comment above `func newTestWorker` opens
   with `newTestWorker`.
3. `#0267`'s `## Implementation notes` claim that none of the six group-level
   hits is its defect shape is corrected in `issues/0267.md`, with a pointer to
   this issue. Do not silently edit the sentence away — record that the
   exclusion is knowingly hiding one real instance.
4. A comment at `#0267`'s group-size exclusion records the same, so the next
   agent to widen the guard knows what the exclusion currently costs.
5. `ISSUE=NNNN scripts/check.sh go ./internal/...` passes with no skips, and
   `gofmt -l` is clean — note CLAUDE.md §8 on gofmt rewriting doc comments.
