## Description

`#0519`'s first slice serves only the intro and selected sections of `/about` and `/privacy` in the server HTML, copied from the Svelte views and checked by a guard. The full text still exists only after JavaScript runs.

## Acceptance criteria

1. The complete About and Privacy text appears in raw server HTML.
2. The text has **one** source used by both the server and the SPA, rather than two copies kept in step by a guard.
3. No duplicated content after mount, and exactly one `<h1>` (`#0519` criterion 4).
4. `ISSUE=NNNN scripts/check.sh` and `scripts/check.sh web` pass.
