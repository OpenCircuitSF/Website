## Description

One action on a workshop that creates a draft campaign pre-filled from it — subject, body, and interest targeting.

## Acceptance criteria

- [ ] `POST /admin/workshops/{id}/announce` creates a `draft` campaign linked via `workshop_id`
- [ ] Subject and body pre-filled from the workshop title, summary, date, and location
- [ ] Campaign targeting pre-set to the workshop's interests in `any_of` mode
- [ ] The draft is fully editable before sending — nothing is sent by this action
- [ ] The workshop screen links to the created draft
- [ ] Repeated announce calls create a new draft rather than overwriting an existing one
- [ ] Handler tests cover pre-fill content and the campaign/workshop link

## Notes

PRD §8. This action must never send. It is a compose shortcut; the send still goes through #0047's full guard sequence including the test send and typed count confirmation.

Creating a second draft on a repeat call is intentional — a follow-up reminder is a normal thing to send, and silently overwriting a partly-edited draft would lose work.
