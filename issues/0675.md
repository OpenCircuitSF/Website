## Description

This is a child of `#0673`. Today `AddV1Route` registers only GET routes. This issue builds the shared plumbing that every v1 resource uses.

## Requirements

1. **Routing.** Registration takes the method, path, required scope and handler. Every `/api/v1/` route requires a token, and session cookies are not accepted there, so no CSRF surface is added. Unknown paths under `/api/v1/` get a JSON 404.
2. **Errors.**
   - Every error is a JSON `{"error": {"code": "...", "message": "...", "fields": {...}}}`, with stable codes: `unauthorized`, `forbidden`, `not_found`, `validation`, `conflict`, `rate_limited`.
   - Validation errors name the fields.
   - Responses never include the raw underlying error text, such as SQL errors.
3. **Requests.**
   - Write requests take `application/json` only. The body is capped at 64 KB, and unknown fields are rejected with a validation error, so typos don't silently do nothing.
   - Times are RFC 3339 with an offset. The docs say the site's zone is America/Los_Angeles.
4. **Pagination.** List endpoints use `?limit=` (default 50, max 200) and `?cursor=`, an opaque cursor, and return `{"items": [...], "next_cursor": ...}`.
5. **Idempotency.**
   - Create endpoints accept an optional `Idempotency-Key` header. A retry with the same key and the same body returns the original result.
   - The keys are stored for 24 hours in migration `000054`, or in the same migration as `#0674` if they ship together.
6. **OpenAPI.**
   - `GET /api/v1/openapi.json` is public and needs no token. It is generated from the route registry, so it can't drift from it.
   - It covers each route's method, path, scope, request and response schemas, and errors.
   - A test asserts every registered v1 route appears in it.
7. **Version.** `GET /api/v1/me` returns the calling key's name, scopes, expiry, and the server version. It is the connection check used by the MCP server and the docs.

## Acceptance criteria

- The existing `GET /api/v1/engagement` moves onto the new registry, with its behaviour unchanged.
- Handler tests cover each error code, the body cap, unknown fields, pagination and idempotent replay.
- The `admin_routes_ast_test` and wiring guards are updated to cover the v1 registry.

### The registry design (new package `internal/api`)

`internal/api` is generic: it knows about tokens, scopes, JSON, schemas and idempotency, and nothing about guides or events. Domain operations live in `internal/handlers`, beside the admin handlers whose stores and validation they reuse. `internal/api` must not import `internal/handlers`.

```go
// operation.go
type Operation struct {
    Name        string // snake_case, ^[a-z][a-z0-9_]{0,63}$; the operationId AND the MCP tool name
    Method      string // http.MethodGet / Post / Patch / Delete
    Path        string // Go 1.22 pattern path under /api/v1/, e.g. "/api/v1/guide-posts/{id}"
    Scope       string // an apitokens scope; "" only with AnyToken
    AnyToken    bool   // any valid key may call it (whoami); makes "no scope" explicit
    Summary     string // one line; first line of the OpenAPI description and the MCP description
    Description string // optional detail
    Destructive bool   // deletes or irreversibly changes data
    PublicEffect string // "" or a short phrase, e.g. "posts publicly to Bluesky or Mastodon right away"
    Idempotency bool   // accepts an Idempotency-Key header (create endpoints)
    Status      int    // success status; 0 means 200. Creates use 201
    MCPExcluded string // "" = exposed as an MCP tool; otherwise the reason it is not
    // unexported, set by Define:
    in, out reflect.Type
    inSchema, outSchema *jsonschema.Schema
    call func(ctx context.Context, in any) (any, error)
}

func Define[In, Out any](op Operation, fn func(ctx context.Context, in In) (Out, error)) Operation
func (op Operation) InputSchema() *jsonschema.Schema  // whole In, as MCP sees it
func (op Operation) OutputSchema() *jsonschema.Schema
func (op Operation) Describe() string // prefix + Summary + Description + "Requires the <scope> scope."
func (op Operation) Decode(raw []byte) (any, error)  // the MCP path: whole-object args, same rules as a body
func (op Operation) Call(ctx context.Context, in any) (any, error)
```

- `Describe()` puts any warning first, so clients that ask before acting can ask: `"DESTRUCTIVE: "` when `Destructive`, then `"PUBLIC: <PublicEffect>. "` when that is set. Both OpenAPI and MCP use this one string.
- `Define` panics, because each of these is a wiring bug:
  - `Out` is not a struct (MCP requires an object output schema);
  - `In` is not a struct;
  - a GET or DELETE has a body field, meaning a field with neither a `path` nor a `query` tag;
  - a `path:"x"` tag does not appear as `{x}` in `Path`, or the other way round;
  - schema inference fails.
- Schemas come from `github.com/google/jsonschema-go` v0.4.3, through `jsonschema.ForType(t, &jsonschema.ForOptions{TypeSchemas: map[reflect.Type]*jsonschema.Schema{reflect.TypeFor[time.Time](): {Type: "string", Format: "date-time"}}})`. This is the same library and version the MCP SDK uses internally (`#0679`), so the two cannot disagree. It already gives structs `additionalProperties: false`, marks non-`omitempty` fields `required`, uses the `jsonschema:"..."` tag as the property description, and flattens embedded structs (`reflect.VisibleFields`). No other schema or OpenAPI library is added.

**Input binding tags.** One `In` struct carries path, query and body fields. Every field has a `json` tag, because MCP sends the whole `In` as one JSON object.

- `path:"id"` marks a field bound from `r.PathValue("id")`. It is required in the schema, so its json tag has no omitempty.
- `query:"limit"` marks a field bound from `r.URL.Query()`. It is always optional: use a pointer, or `omitempty`.
- A field with neither tag is a body field.
- Supported path and query kinds: `string`, `int`, `int64`, `bool`, `time.Time` (RFC 3339 only), and a pointer to any of these. A failed conversion is a validation error naming the field, for example `"limit": "must be a whole number"`.

```go
// page.go
type Page struct {   // embed in a list operation's In
    Limit  *int   `json:"limit,omitempty"  query:"limit"  jsonschema:"1 to 200, default 50"`
    Cursor string `json:"cursor,omitempty" query:"cursor" jsonschema:"opaque; pass next_cursor from the previous page"`
}
func (p Page) Resolve() (limit int, err error) // default 50; <1 or >200 → Validation{"limit": "must be 1 to 200"}
type List[T any] struct {
    Items      []T     `json:"items"`
    NextCursor *string `json:"next_cursor"`
}
func NewList[T any](items []T, next *string) List[T] // a nil items becomes []
func EncodeCursor(v any) string                       // base64url(JSON(v)), unpadded
func DecodeCursor(s string, v any) error              // a failure → Validation{"cursor": "is not a cursor this API issued"}
```

The cursor is keyset, not offset: a list op encodes its last row's sort key, such as `{"t": "...", "id": 41}`. `#0675` ships only the helpers. The first real list ops arrive in `#0676`.

```go
// errors.go
const (CodeUnauthorized = "unauthorized"; CodeForbidden = "forbidden"; CodeNotFound = "not_found"
       CodeMethodNotAllowed = "method_not_allowed"; CodeValidation = "validation"; CodeConflict = "conflict"
       CodeRateLimited = "rate_limited"; CodeInternal = "internal")
type Error struct { Status int; Code, Message string; Fields map[string]string }
func (e *Error) Error() string { return e.Code + ": " + e.Message }
func Validation(fields map[string]string) *Error // 400, message "the request has invalid fields"
func NotFound(what string) *Error                // 404, "<what> not found"
func Conflict(msg string) *Error                 // 409
func Forbidden(scope string) *Error              // 403, "this API key lacks the <scope> scope"
type ErrorBody struct { Error ErrorDetail `json:"error"` }
type ErrorDetail struct { Code string `json:"code"`; Message string `json:"message"`; Fields map[string]string `json:"fields,omitempty"` }
func AsError(op string, err error) *Error
```

`AsError` returns the `*Error` if `errors.As` finds one. For anything else it logs `slog.Error("api: operation failed", "op", op, "err", err)` and returns a 500 with code `internal` and message `"internal error"`. That is the **only** place an underlying error's text goes, and it goes to the journal, never to a response. Each op maps its own store sentinels, such as `guideposts.ErrNotFound`, to `api.NotFound(...)` inside its `fn`.

Additional statuses that keep code `validation`, with `fields` naming what was wrong:

| Status | Fields |
|---|---|
| 413 | `{"body": "must be at most 64 KB"}` |
| 415 | `{"Content-Type": "must be application/json"}` |

```go
// registry.go
type Config struct { Version string; Idempotency IdempotencyStore; Now func() time.Time }
type Registry struct { /* ops in Add order; frozen flag; openapi bytes cached at Freeze */ }
func NewRegistry(cfg Config) *Registry
func (r *Registry) Add(ops ...Operation)
func (r *Registry) Freeze()
func (r *Registry) Operations() []Operation
func (r *Registry) Version() string
```

`Add` panics on any of these:

- a path outside `/api/v1/`;
- `Scope == ""` without `AnyToken`, or `AnyToken` together with a scope;
- `!apitokens.IsKnownScope(Scope)`;
- a duplicate `Name`, or a duplicate `Method+" "+Path`;
- the reserved path `/api/v1/openapi.json`;
- a bad `Name`;
- a call after `Freeze`.

`Freeze` builds the OpenAPI bytes once.

```go
// http.go: the HTTP adapter
type RouterDeps struct { Resolver middleware.APITokenResolver; Limiter *middleware.RateLimiter; BaseURL string }
func NewHTTPRouter(reg *Registry, deps RouterDeps) http.Handler // freezes reg
func Serve(op Operation) http.Handler // adapter only (decode → call → encode/map errors), no auth: unit tests use it
```

`NewHTTPRouter` builds a private `http.ServeMux` holding:

1. `"GET /api/v1/openapi.json"`. Public, needs no token, and serves the cached bytes with `Content-Type: application/json` and `Cache-Control: public, max-age=300`.
2. For each operation, `op.Method+" "+op.Path` → `RequireAPIToken(deps.Resolver, "")` → `APITokenRateLimit(deps.Limiter)` → a scope check → `Serve(op)`.
   - The scope check is `apitokens.ScopeSatisfies(tok.Scopes, op.Scope)`; on failure it writes `Forbidden(op.Scope)`.
   - Authentication sits per route, not around the whole router, so `openapi.json` and the 404 stay public.
3. `"/api/v1/"` catch-all. It probes each of GET, POST, PUT, PATCH and DELETE with `inner.Handler(clone with that method)`: a returned pattern other than `"/api/v1/"` means the path exists for that method. If any method matches, it answers 405 `method_not_allowed` with `Allow`. Otherwise it answers 404 `not_found` ("no such API endpoint").
   - This keeps `admin_wiring_test`'s existing "POST /api/v1/token is 405" assertion true.
   - A plain catch-all would turn that 405 into a 404.

`Serve(op)` does the following, in order:

1. **Body.** For POST, PUT and PATCH: wrap the body with `http.MaxBytesReader(w, r.Body, 64<<10)` and read it all. A `*http.MaxBytesError` becomes a 413.
   - An empty body is treated as `{}`.
   - A non-empty body needs `mime.ParseMediaType(Content-Type) == "application/json"`, or the request gets a 415.
2. **Decode.** Decode with `json.NewDecoder(...).DisallowUnknownFields()`, then require EOF afterwards (trailing data is a validation error).
   - An unknown field gives `Validation{"<name>": "unknown field"}`; parse the name from the decoder error's `json: unknown field "x"` text.
   - A `*json.UnmarshalTypeError` gives `Validation{e.Field: "must be a <e.Type kind>"}`.
   - A syntax error gives `Validation{"body": "is not valid JSON"}`.
3. **Path and query fields.** If a path or query field is non-zero after the body decode, return `Validation{"<json name>": "belongs in the URL, not the body"}`. Then bind path and query fields from the URL.
4. **Call.** Run `out, err := op.call(ctx, in)`. On error, `e := AsError(op.Name, err)` and write `ErrorBody` with `e.Status`.
5. **Write.** Write `out` with `op.Status`, defaulting to 200.
6. **Idempotency.** Wraps steps 4 and 5 when `op.Idempotency` is set and the request has an `Idempotency-Key` header; see below.

The binding code is one function, `bind(op, body []byte, pathValue func(string) string, query url.Values) (any, *Error)`. `op.Decode(raw)` is the same decoder without the URL step, which is what the MCP adapter calls. Both paths share one set of rules for unknown fields and types.

Every response, error or not, carries `Cache-Control: no-store`. `RequireAPIToken` already sets it; `Serve` sets it too, so a unit test of `Serve` sees it.

**Idempotency** (`idempotency.go`; migration `000054_create_api_idempotency_keys`):

```sql
CREATE TABLE api_idempotency_keys (
    token_id      BIGINT NOT NULL REFERENCES api_tokens(id) ON DELETE CASCADE,
    idem_key      TEXT   NOT NULL,
    operation     TEXT   NOT NULL,
    request_hash  BYTEA  NOT NULL,
    status_code   INTEGER,          -- NULL while the first request is still running
    response_body JSONB,
    created_at    TIMESTAMPTZ NOT NULL DEFAULT now(),
    PRIMARY KEY (token_id, idem_key),
    CONSTRAINT api_idempotency_keys_key_check  CHECK (char_length(idem_key) BETWEEN 1 AND 255),
    CONSTRAINT api_idempotency_keys_hash_check CHECK (octet_length(request_hash) = 32)
);
CREATE INDEX api_idempotency_keys_created_at_idx ON api_idempotency_keys (created_at);
```

The down migration is `DROP TABLE api_idempotency_keys;`.

```go
type IdempotencyStore interface {
    Begin(ctx context.Context, tokenID int64, key, op string, hash []byte, now time.Time) (*StoredResponse, error)
    Complete(ctx context.Context, tokenID int64, key string, status int, body []byte) error
    Abandon(ctx context.Context, tokenID int64, key string) error
}
type StoredResponse struct { Status int; Body []byte }
var ErrIdempotencyMismatch = errors.New(...) // same key, different request → 409 "Idempotency-Key was used with a different request"
var ErrIdempotencyInFlight = errors.New(...) // first request still running → 409 "a request with this Idempotency-Key is still in progress"
func NewIdempotencyStore(pool *pgxpool.Pool) IdempotencyStore
```

`Begin` runs in this order:

1. `DELETE FROM api_idempotency_keys WHERE created_at < $now - interval '24 hours'`. This sweeps lazily, so no new worker is needed.
2. `INSERT ... ON CONFLICT DO NOTHING RETURNING`. If the row was inserted, return `(nil, nil)` and the caller runs the op.
3. Otherwise `SELECT` the row:
   - a different `operation` or `request_hash` returns `ErrIdempotencyMismatch`;
   - `status_code IS NULL` returns `ErrIdempotencyInFlight`;
   - otherwise return the stored response.

In `Serve`:

- **The key.** It must be 1–255 printable ASCII characters, or the request gets `Validation{"Idempotency-Key": "..."}`.
- **The hash** is `sha256(op.Name + "\n" + r.URL.Path + "\n" + body)`.
- **A replay** writes the stored status and body, plus `Idempotent-Replayed: true`.
- **On a 2xx**, call `Complete` with the marshalled `out`.
- **On any error**, call `Abandon`, which deletes the row, so a retry runs the op again. Only successes are replayed.

The key is scoped per token, so two keys can never collide. A key sent to a non-idempotent op is ignored. MCP calls do not use idempotency in v1 (see Assumptions).

**OpenAPI** (`openapi.go`): `func buildOpenAPI(reg *Registry, baseURL string) ([]byte, error)`. It builds a `map[string]any` and marshals it with `json.MarshalIndent`, so the output is deterministic.

- `openapi: "3.1.0"`. OpenAPI 3.1 schemas are JSON Schema 2020-12, which is what jsonschema-go emits, so the schemas go in unchanged.
- `info`:
  - `title`: "Open Circuit SF API".
  - `version`: `reg.Version()`.
  - `description`: says that times are RFC 3339 with an offset and that the site's zone is America/Los_Angeles; that auth is `Authorization: Bearer ocsf_…`; that lists use `limit` (default 50, maximum 200) and `cursor`; and the error envelope.
- `servers: [{url: baseURL}]`.
- `components.securitySchemes.bearer = {type: http, scheme: bearer}`.
- `components.schemas.Error` is inferred from `ErrorBody`.
- Each operation, under `paths[openAPIPath(op.Path)][lower(op.Method)]`:
  - `operationId`: `op.Name`.
  - `summary`: `op.Summary`.
  - `description`: `op.Describe()`.
  - `x-required-scope`: `op.Scope`, or `"any"`.
  - `security: [{bearer: []}]`.
  - `parameters`: path params (`required: true`) and query params, each with its property schema taken from `op.inSchema.Properties`. Idempotent ops also get the `Idempotency-Key` header parameter.
  - `requestBody`, only when the op has body fields. It is required, `application/json`, and holds a clone of `inSchema` with the path and query properties deleted and `Required` filtered to match.
  - `responses`:
    - `{op.Status or 200}` → `outSchema`;
    - `400`, `401`, `403`, `429` and `500` → `$ref Error`;
    - `404` when the path has a parameter;
    - `409` when `Idempotency` is set;
    - `413` and `415` when the op has body fields.
- The document itself appears under `GET /api/v1/openapi.json` with `security: []`.

Go's `{id}` path syntax is already OpenAPI's, so `openAPIPath` only strips a trailing `{x...}` wildcard. No current op uses one.

## Assumptions (user may override)

- **v1 errors use the new envelope everywhere**, including `/api/v1/engagement` and the 401, 403 and 429 from the token middleware. The engagement *success* body is unchanged. Home Assistant reads only the success body, so its sensor is unaffected. The error table in `docs/home-assistant.md` is updated.
- **`/api/v1/token` stays**, as a deprecated alias of `/api/v1/me` returning the same superset body, so nothing configured against `#0652`'s probe breaks.
- **Unknown `/api/v1/` paths get a JSON 404 with no token required.** A wrong method on a known path gets 405 with `Allow`.
- **`validation` is HTTP 400.** A body over 64 KB is 413, and a wrong Content-Type is 415. Both keep code `validation` and name the field.
- **Idempotency** keys are per API key and kept 24 hours, and only successful responses are replayed. A failed request can be retried with the same key.
- **Engagement output times stay UTC** (`Z`), as they are today. New resources choose their own output offset in `#0676` and `#0677`. Inputs accept any RFC 3339 offset.
- **The OpenAPI document is 3.1.0**, served with `Cache-Control: public, max-age=300`.

## Fix

Commit `3863a4db` (worktree branch `worktree-agent-a850a851061abb0c5`, on top of `#0674`'s resolve and the `#0676`–`#0678` plans).

New package `internal/api`, as planned, with these deviations and additions:

- **Mounting.** A bare `"/api/v1/"` pattern panics at startup: Go's ServeMux says it conflicts with the SPA's `"GET /"`. So `api.Mount(mux, h)` registers `"<METHOD> /api/v1/"` for each of `api.Methods` (GET, POST, PUT, PATCH, DELETE), and `main.go` calls `api.Mount(mux, api.NewHTTPRouter(...))` once. `TestAPIV1MountedOnlyViaRegistry` checks for that shape: exactly one `api.Mount(mux, api.NewHTTPRouter(...))`, and no literal `/api/v1` pattern on `mux`.
- **The OpenAPI document is built in `NewHTTPRouter`**, not in `Freeze`, because the `servers` URL comes from `RouterDeps.BaseURL`. `Freeze` only stops further `Add`s and is safe to call twice. `#0679` calls it too.
- **`response_body` is `BYTEA`, not `JSONB`.** JSONB reorders keys and rewrites whitespace, so a replay would not be byte-identical to the first response.
- **The scope rules are stricter (`#0674`'s review, from the orchestrator).** `Registry.Add` panics on `AnyToken` for any operation other than `whoami` and `token_probe`, and on `AnyToken` with a non-GET method. It also panics on any non-GET whose scope does not end in `:write`. `Add` also requires a `Summary` and a 2xx `Status`.
- **Additions requested for `#0676`–`#0678`:**
  - `api.Unavailable(msg)`, a 503 with code `unavailable`. `Operation.MayBeUnavailable` lists the 503 in OpenAPI.
  - A body field whose own `UnmarshalJSON` fails (a bad `time.Time`, for example) now names the field, via `badField`. Nested values name the top-level field.
  - `internal/api/apitest`: `NewResolver()`, `(*Resolver).Key(t, name, scopes...)`, `MemoryIdempotency`, `Router(t, res, ops...)` (which adds the core ops), `Do(t, h, method, path, secret, body, hdr...)`, and `ErrorOf(t, body)`.
  - `api.WithClientIP` and `api.ClientIPFromContext`. `serve` sets the IP from `middleware.ClientIP` for every REST call.
- **`Decode` (the MCP path) requires path fields.** A missing or zero `path:` field is `Validation{"id": "is required"}`.
- **`Operation.RequiredScope()`** returns the scope, or `"any"`. OpenAPI's `x-required-scope` uses it.
- **The 403 message names the scope.** The middleware's own 403 is `"this API key lacks the <scope> scope"`, the same as `api.Forbidden`.
- **The floor constants were raised.** `citationGuardMinPlausibleFileCount` and `auditEmailMetadataMinPlausibleFileCount` went from 115 to 165, the remedy `scripts/go_file_visit_floor_guard_test.sh` printed after the new files pushed the population to about 233.

The golden test's expected bytes were captured from the pre-change `ServeHTTP` before the refactor: the mixed fixture with the default window, and an empty window with `?hours=3`.
