## Description

From `#0643`'s review. The `ssh -R` tunnel to a Tart guest described in `docs/dev.md` (and printed by `scripts/dev-outreach-demo.sh`) closed the connection right after the key was accepted, with both the agent key and a throwaway key. A pair of small TCP forwarders that accept only the guest's IP worked instead; the working script was kept in the session scratchpad as `0643-vm/run.sh`.
