# 0281 — Nothing enforces that a ClaimDue or OrphanSweep caller passes its kinds

## Description

`outbox.Store.ClaimDue` and `outbox.Store.OrphanSweep` both take a variadic
`kinds ...Kind` and both implement it as `cardinality($n) = 0 OR kind = ANY(...)`.
**An empty slice therefore means "every kind"** — the variadic makes the
dangerous case the default one.

This is exactly the omission `#0254` bounced on. `#0254` added the filter to
`ClaimDue` and not to `OrphanSweep`, gave `OrphanSweep` a second caller, and the
intake poller's 20s sweep began releasing live mail claims held legitimately for
up to 35s — releasing a claim mid-send so the row reverted to `'queued'` and was
sent again. A duplicate confirmation link.

The fix scoped both live call sites. `#0254`'s reviewer then enumerated every
call site and confirmed **no live instance of the dangerous default remains**:

| Call site | Passes |
|---|---|
| `internal/mailing/outbox_worker.go:364` | `mailKinds...` |
| `internal/handlers/subscribe_intake.go:174` | `KindSubscribeIntake` |
| `internal/outbox/store_test.go:412` | nothing — deliberately exercising the documented default |

So nothing is broken. What is missing is any mechanism stopping the *next* call
site from forgetting, which is the whole of how `#0254` happened.

## Acceptance criteria

1. A guard fails when a `ClaimDue` or `OrphanSweep` call **outside**
   `internal/outbox` passes no kinds. The package's own tests must still be able
   to exercise the unscoped default — scope the rule by caller package, not by
   forbidding the signature.
2. The guard names the offending file and line, and states that an empty
   variadic means every kind, so the failure explains itself.
3. Prove it fires: a fixture call site with no kinds must fail the guard. Per
   CLAUDE.md §8 the oracle must not be the same bytes as the subject.
4. The guard fails closed if its scan finds zero call sites — see
   [#0275](0275.md). A guard that silently measures nothing is worse than none.
5. Consider whether the variadic should become a required parameter with an
   explicit `AllKinds` sentinel, so the safe case is the default and the
   sweeping case has to be asked for by name. If rejected, record why.
6. `ISSUE=NNNN scripts/check.sh go ./internal/... ./cmd/...` passes with no skips.
