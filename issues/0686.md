## Description

These are minor items from the `#0676`/`#0684` review.

1. **Bound the startup sweep.** Wrap the startup `api.SweepIdempotencyKeys` call in `cmd/opencircuit/main.go` in a `context.WithTimeout` of about 10 seconds, so a slow database can't hold up startup.
2. **Report every bad channel.** When `create_guide_posts` gets several bad `channels` entries, it reports only the last one. Report each one under its own field key.
3. **Close the delete race.** `delete_guide_post` checks that the post is a draft, then deletes it, and a post scheduled in between could still be deleted. Use a conditional `DELETE … WHERE status = 'draft'` and return a 409 when no row matches.
