## Description

`#0052`'s acceptance criteria require the admin UI to let a slug be edited before a workshop is first published. `#0051`'s API makes that impossible: neither the create nor the patch request struct carries a `slug` field, and the store generates it server-side from the title with a collision suffix. `#0052`'s reviewer verified both — no `slug` on either struct, no route that accepts one — and ruled the criterion unbuildable in the UI, leaving it unticked.

So one of the two is wrong, and this issue decides which.

## Acceptance criteria

- [ ] Decide deliberately, and record the reasoning:
      - **(a) The API is right.** Slugs stay server-generated and immutable. `#0052`'s criterion is struck with a note, and the UI keeps showing the slug read-only
      - **(b) The criterion is right.** `PATCH /admin/workshops/{id}` accepts a `slug` while `status = 'draft'`, rejects it afterward, and the UI exposes it before first publish
- [ ] If (b): the slug remains UNIQUE-enforced at the database, a supplied slug is validated (shape, length, reserved words) rather than trusted, and an admin-supplied collision is a 409 rather than a silent suffix
- [ ] If (b): changing a slug before publish leaves no dangling public URL — confirm nothing has linked it yet, since drafts 404 for the public
- [ ] Whichever wins, `#0052`'s criterion ends up either ticked or struck with a note. It must not stay floating
- [ ] The relevant tests cover the decided behavior

## Notes

`#0052`'s own `## Notes` argue for the API's position — a stable, server-generated slug is one less thing an admin can get wrong, and the collision suffix already guarantees uniqueness. That makes **(a)** the likely answer, but it is a product decision, not a technical one, so it is recorded here rather than settled by whoever next opens the file.

One consideration for (a): a title typo caught after publish leaves a permanently wrong slug, since editing the title does not regenerate it. That is the cost of immutability and it is probably acceptable — but it should be an accepted cost, not a surprise.
