# 0615 — Announcements, outreach and admin copy call every listing a workshop

| | |
|---|---|
| **Status** | open |
| **Platform** | All |
| **Module** | mailing / web / admin |
| **Phase** | 6 — Workshops |
| **First seen** | 2026-11-04 |

## Description

After `#0613` and `#0614`, a Hack Night can still be announced in text that calls
it a workshop. Audit every user-visible string that says "workshop" and make it
either generic ("event") or derived from the listing's type name. Identifiers,
table names, comments and URL-independent internals are out of scope.

## Acceptance criteria

- [ ] The issue records an audit of user-visible "workshop" strings across email
      templates and the announce shortcut, outreach text and flyer generation,
      social cards, admin screens, subscribe and preference copy, and the CRT
      command output, with the outcome for each: generic, type-derived, or left
      deliberately with the reason.
- [ ] An announcement email or outreach draft created from a Hack Night has no
      text calling it a workshop, and the same flow for a Workshop still reads
      naturally. Tests cover both.
- [ ] Admin screens that apply to every type read generically (for example,
      "Events" in the admin navigation and list heading).
- [ ] The homepage headline **"Hands-on electronics workshops"** and the marketing
      paragraphs are not changed here. They are brand copy, and the user decides
      them; the implementer lists any that now read wrongly in `## Notes`.
- [ ] Mail rendering changes name the specific tests that ran in `## Verification`
      (`AGENTS.md` §5).

## Notes

- Do not change existing rows in a way that rewrites sent or archived campaigns;
  their rendered content is history.
- The seeded CRT commands live in the database (migration `000028`), so changing
  a seeded command's copy needs a new migration, not an edit.

## Relation

- Depends on `#0613` and `#0614`.
