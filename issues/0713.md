## Description

User request, 2026-11-17: "We should support seeing temp as F or C and default to F for all guides. This one just shows C. Most viewers won't know how that converts to F." (about `/guides/soldering-iron-temperature`).

Temperatures appear only in °C today. Found by grep on 2026-11-17:
- `web/src/lib/topics/IronTempDemo.svelte` — the iron dial ("Iron set to N °C").
- `web/src/lib/topics/SolderWireDemo.svelte` — melting range and iron range per alloy.
- `web/src/lib/topics/soldering.ts` — alloy prose (183 °C, 183–190 °C) and the iron-temperature verdict text (`tipC`, `melt0`).
- `web/src/lib/topics/topics.ts` — guide "ideas" prose (183 °C, 217–220 °C, "Start at 330–350 °C", 350–380 °C).
- `web/src/lib/topics/transistors.ts` and `MosfetSwitchDemo.svelte` — junction temperature (`tj`) in the transistor/MOSFET guides.

Unit-of-rate values (°C/W thermal resistance) and code comments are not reader-facing temperatures; the plan decides whether any reader-facing °C/W text exists and how to treat it.

Wanted: every reader-facing temperature in the guides shows in **°F by default**, with an easy way to switch to °C, applied consistently across all guides (a single site-wide preference, remembered for the visitor). Conversions must be rounded sensibly (e.g. 183 °C → 361 °F; ranges convert both ends; a demo dial should step in friendly °F values or show both).

## Acceptance criteria

- [ ] Every reader-facing temperature in the guides (demos and prose) renders in °F by default.
- [ ] A visible °F/°C control switches all of them, on every guide, and the choice persists across pages and visits (browser storage, failing safe to °F).
- [ ] Prose temperatures are produced from numeric values by one formatting helper, not hand-written in two units; a guard test fails if a hard-coded `°C` or `°F` literal appears in reader-facing guide content outside that helper.
- [ ] The static no-JS fallback and the server-rendered meta (descriptions, `post` copy) say nothing wrong: either they carry no temperatures, or they follow the default (°F) — the plan states which.
- [ ] Unit tests cover the conversion and rounding (including ranges), and the toggle; `scripts/check.sh web` passes, plus `internal/seo` if any fallback/meta copy changes.
