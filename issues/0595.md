## Description

Carved out of `#0588` item 3 (review finding F3) and moved out of `#0593`.
The Instagram card links to this workshop's flyer, but Instagram needs an
image, and the flyer face is HTML and CSS drawn in the browser. Offering it as
a downloadable PNG needs a rasteriser (for example drawing the face onto a
`<canvas>` at a fixed square or 4:5 size), and jsdom cannot verify the
result.

## Acceptance criteria

- [ ] The Instagram card (and the flyer editor) offer **Download image**,
      producing a PNG of the flyer face at an Instagram-friendly size
      (1080×1350 or 1080×1080 — state which), with the cover photo, title,
      date, short link and QR code legible.
- [ ] No third-party CDN (AGENTS.md §9); any library is bundled and its size
      stated. Prefer drawing directly to a canvas from the same data the face
      uses over serialising DOM.
- [ ] The photo is same-origin (`/media/`) so the canvas is not tainted; a
      cross-origin or missing photo falls back to the plain tint, as print
      does.
- [ ] Verified rendering in the Tart VM with Safari per AGENTS.md §8 (never a
      host browser), with the PNG copied out and checked; plus unit tests for
      the layout maths.
