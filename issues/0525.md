## Description

`#0518` added `internal/seo.NoIndexAPIMiddleware`, which sets
`X-Robots-Tag: noindex` on responses under `/api/`, and wrapped the whole mux
with it in `cmd/opencircuit/main.go`'s `mountAndServe`.

The middleware itself is well tested: breaking its prefix check fails
`TestNoIndexAPIMiddleware_SetsHeaderOnAPIRoutesOnly`. **The wiring is not.**
`#0518`'s reviewer removed the wrap from `mountAndServe` in a throwaway worktree
and both `internal/seo` and `cmd/opencircuit` stayed green. The header works on
`HEAD` today — the reviewer proved it over the real wiring on a live socket — but
a future edit to `mountAndServe` could drop it silently.

This is the same unpinned-wiring shape as `#0326`, `#0490`, and `#0492`.

> 🟢 Resolved 2026-09-13 — the wiring test drives the real `mountAndServe`
> over a real socket and pins the header both directions; review reproduced
> the mutation proof itself in a throwaway worktree (wrap removed → test
> fails on exactly the three `/api/` assertions; wrap restored → green).
> All five criteria verified.

## Acceptance criteria

1. A `cmd/opencircuit` test runs the real `mountAndServe` and asserts
   `X-Robots-Tag: noindex` on a 401 from `GET /api/me`, a 405 from
   `POST /api/me`, and a 404 under `/api/`.
2. The same test asserts the header is **absent** on `/`, `/sitemap.xml`,
   `/robots.txt`, and a bare `/apiary`-style path that only shares the prefix
   textually.
3. **Prove it fails** with the wrap removed from `mountAndServe`, in a throwaway
   worktree, never the shared tree.
4. No fixed shared port (CLAUDE.md §8b).
5. `ISSUE=NNNN scripts/check.sh go ./cmd/opencircuit/... ./internal/seo/...`
   passes with no skips.

## Root cause

The middleware's own test proved composition over a hand-built mux; nothing pinned that mountAndServe wraps the real one, the same unpinned-wiring shape as #0326/#0490/#0492.

## Fix

cmd/opencircuit/noindex_wiring_test.go runs the real mountAndServe over a real socket (probed ephemeral port, no fixed shared port) and asserts `X-Robots-Tag: noindex` on a 401 from GET /api/me (cookieless RequireSession denial), a 405 from POST /api/me (mux-level), and a 404 under /api/ (SPA catch-all), and its absence on /, /sitemap.xml, /robots.txt, and /apiary (shares the prefix textually, not the "/api/" path prefix). Handler arguments are typed nils — registration only evaluates method values, legal on nil receivers — with a stub Pinger; the server is shut down with SIGTERM so no listener or signal registration leaks.

## Verification

`go test ./cmd/opencircuit/ -run TestMountAndServe_NoIndexHeaderWiredAroundWholeMux -v` — PASS. Criterion 3 mutation proof: in a throwaway worktree at HEAD, `seo.NoIndexAPIMiddleware(mux)` replaced with `mux` in cmd/opencircuit/main.go — the test FAILED on exactly the three /api/ assertions (`X-Robots-Tag = "", want "noindex"`) and passed again after the worktree was removed. Scoped suite: `ISSUE=0502 scripts/check.sh go ./internal/seo/... ./internal/handlers/... ./cmd/opencircuit/...` — ok, no skips.
