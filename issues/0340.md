# 0340 — A deferred `import_invite` outbox row can outlive the `confirm_token` it carries

## Description

`deferMissingPhysicalAddress` requeues an outbound row indefinitely while no
physical postal address is configured — correct behaviour, and `#0045`'s
refusal is a restricted rule that must not be made bypassable (§9).

But an `import_invite` row's payload holds a `confirm_token`, and that token can
be rotated underneath it by a resend or by an expiry sweep. Nothing ties the
queued row's lifetime to the validity of the token it carries. A row deferred
long enough can therefore be delivered with a token that no longer resolves,
producing an invitation whose link is dead on arrival — and the recipient has no
way to tell that from an expired one.

`#0313`'s planned `CancelQueuedTx` covers the single case that change
introduces. **The general hazard is pre-existing and unguarded**, and it widens
as soon as any further path rotates a token.

The exposure is real rather than theoretical right now: SES production access is
still pending (§10 item 2), and `#0045` refuses to start a campaign without a
physical address, which is item 3 and not started. Both make long defers the
expected state rather than an edge case.

## Acceptance criteria

1. A queued or deferred outbound row carrying a `confirm_token` cannot be
   delivered after that token has been rotated or invalidated — either the row
   is cancelled when the token changes, or the token is resolved at send time
   rather than captured at enqueue time.
2. The chosen mechanism is stated, with its trade-off: cancel-on-rotate versus
   resolve-at-send.
3. `deferMissingPhysicalAddress`'s indefinite requeue is preserved — `#0045`'s
   refusal is a restricted rule (§9) and must not become bypassable.
4. Covered for every token-bearing kind, not only `import_invite` — enumerate
   the kinds and say which carry tokens.
5. Proved by mutation: a test that rotates a token while a row is deferred and
   asserts the row cannot be delivered with the stale token. The mutation must
   fail against the un-fixed code.
6. Interacts with `#0313`'s `CancelQueuedTx` — if that lands first, this must
   generalise it rather than duplicate it. Say which.
