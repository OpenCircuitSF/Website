# 0557 — Mastodon mention fields that bypass `PlainText` could carry a NUL byte and stall the walk

| | |
|---|---|
| **Status** | open |
| **Platform** | All |

| **Phase** | 10 — Outreach |

## Description

From `#0555`'s review. `mastoMention` (`internal/outreach/tracker.go`) writes
`n.StatusURI` to `remote_id` and `n.Acct` to `author` straight from the JSON;
neither goes through `PlainText`, so an escaped NUL in either would fail the
insert and stall the Mastodon walk, as `#0555` fixed for Bluesky. Low risk
(our own instance validates both), one-line fix.

## Acceptance criteria

- [ ] `stripNUL` is applied to every payload string `mastoMention` stores (or once, to every string column, inside `InsertMention`); a test case with NUL in `acct` and the status URI proves it.
- [ ] Verified with `ISSUE=0557 scripts/check.sh go ./internal/outreach/... ./internal/db/...`.
