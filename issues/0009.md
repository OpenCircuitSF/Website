## Description

Bring across the admin console's user management, settings, and audit log screens, dropping the URL-filter tab that has no counterpart here.

## Acceptance criteria

- [ ] `Admin.svelte` renders three tabs: Settings, Users, Audit log — the URL filters tab is gone
- [ ] Settings tab toggles `registrations_enabled` and edits `physical_address`
- [ ] Users tab lists staff users with status and last login; deactivate and reactivate work with a reason and note
- [ ] Audit log is paginated and filterable by user id
- [ ] `/admin/url-filters*` handlers and their frontend calls are fully removed
- [ ] Admin routes are gated on `RequireSession` + `RequireAdmin`; a non-admin session gets 403 and the SPA hides the nav entry
- [ ] `npm run check` and `npm test` pass; `go test ./internal/handlers/...` passes

## Notes

PRD §5.2. `physical_address` is added to the settings screen here because #0045's send worker refuses to start a campaign without it — better to have the field in place from the start than to discover it missing on send day.

Admin tab styling is unstyled at this point; #0011 introduces the tokens and #0013 the motif components. Do not hand-roll colors here that the token pass will have to undo.
