## Description

`BuildRobotsTxt` (`internal/seo/robots.go`) emits `Allow: /` as its first rule,
a line from `#0020`. Google, Bing, and Python's `urllib.robotparser` resolve
rules by **longest match**, so for them it is harmless: every `Disallow` is more
specific. A crawler using **first-match** semantics, though, matches `Allow: /`
for every path — including `/admin`, `/confirm`, and `/api/me` — before it ever
reaches a `Disallow`.

`#0518`'s reviewer measured this. It is also why reordering `#0518`'s new
`Allow: /api/...` lines would have changed nothing for any crawler. Low priority:
the private routes are gated server-side regardless, and the major engines read
the file correctly.

`Allow: /` is redundant under longest-match too, since allowing everything is the
default.

> 🟢 Resolved 2026-09-13 — the line is removed (not moved), the choice recorded
> in robots.go's doc comment; review re-verified criterion 3 itself with
> Python's `urllib.robotparser` over the freshly generated file — all 15
> probe paths allowed/disallowed exactly as intended. All five criteria
> verified.

While here, `docs/seo.md` says every non-allowed `/api` route is "gated,
token-bearing, state-changing, or a webhook". `/api/list-stats` and
`/api/crt-session` are none of those: they are public, read-only, and disallowed
because they only feed Home's `aria-hidden` canvas. `robots.go`'s comment gets
this right; the doc does not.

## Acceptance criteria

4. `docs/seo.md`'s description of the disallowed `/api` routes is corrected to

## Root cause

`BuildRobotsTxt` led with `Allow: /` (#0020): redundant under longest-match (allowing everything is the default) and, under first-match semantics, a line that lets every path — including /admin, /confirm, /api/me — match an Allow before any Disallow.

## Fix

Recorded choice: `Allow: /` is REMOVED, not moved after the Disallow block — omission is the safe form under both resolution rules, while a moved line stays a first-match hazard. robots.go's doc comment records why; #0020's robots test now asserts the line stays absent while every private namespace stays disallowed. docs/seo.md's `/api` description corrected: /api/list-stats and /api/crt-session are public and read-only but disallowed because they only feed Home's aria-hidden canvas.
