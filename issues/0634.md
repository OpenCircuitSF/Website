# 0634 — The shared Message does not change hand-posted text and leaves unreachable card code

| | |
|---|---|
| **Status** | open |
| **Platform** | All |
| **Module** | outreach |
| **Phase** | 10 — Outreach |
| **First seen** | 2026-11-05 |

## Description

Found while planning `#0626`.

1. **Save message** never changes hand-posted text (`messageTargets`), so editing the shared Message leaves the TikTok, Reels and Shorts text as it was. The user may expect otherwise, especially because one video goes to all three.
2. After `#0626`, the both-networks code in `OutreachPostCards.svelte`, and the tests for it and for automatic cards, can no longer be reached in production.

## Acceptance criteria

- [ ] The user decides whether the shared Message should update uncustomized hand-posted text, and the screen makes the behaviour clear either way.
- [ ] The unreachable code and its tests are removed.
