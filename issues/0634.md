## Description

Found while planning `#0626`.

1. **Save message** never changes hand-posted text (`messageTargets`), so editing the shared Message leaves the TikTok, Reels and Shorts text as it was. The user may expect otherwise, especially because one video goes to all three.
2. After `#0626`, the both-networks code in `OutreachPostCards.svelte`, and the tests for it and for automatic cards, can no longer be reached in production. The same goes for `CardButtons.copy` outside tests and, after `#0627`, the card's Schedule… button and `openSchedule`.

## Acceptance criteria

- [x] The user decides whether the shared Message should update uncustomized hand-posted text. **Decided 2026-11-05: yes** ("yes to 1 and 3").
- [ ] **Save message** updates the TikTok, Reels and Shorts text for every wave whose hand-posted text the user has not customized; customized text is left alone, and the screen says which rows changed and which kept their own text.
- [ ] The unreachable code and its tests are removed.
