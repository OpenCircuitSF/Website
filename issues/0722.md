## Description

> Renumbered on 2026-11-18 from `#0695`–`#0698`: those numbers were filed against a stale local `main` and are already used on `origin/main` (Agent API issues). Plans written before the renumbering cite `main` at `1eccc4b6`; the guide framework they rely on is unchanged on `origin/main` (42 topics, five sets).

The user asked for the first batch of Raspberry Pi guides (`#0719`, `#0720`, `#0721`) to get images generated by Codex, "like we have done before". The earlier runs were in other projects: a prompts document in the repo, then Codex reading it and calling its built-in image generation (`codex exec`, feature `image_generation`, skill `~/.codex/skills/.system/imagegen/SKILL.md`). This repo's guide art so far is hand-built SVG rendered with `rsvg-convert` (`scripts/render-guide-art.sh`, `scripts/render-soldering-art.sh`); these are the first raster illustrations for guides.

Work, after the three guide issues are merged:

1. Write `docs/guide-image-prompts-pi.md`: one illustration per guide (seven), each with the output filename, the guide it belongs to, where it goes on the page, its alt text, and the prompt. A shared style block at the top keeps the set consistent with the site's look (`docs/design.md`, PRD §4: dark terminal-inspired, brand green accent) and works on both light and dark themes.
2. Run Codex non-interactively against that document to generate the images (`codex exec`, in the repo root, telling it to read the prompts document and save each image under its filename). Record the exact command in the issue's work log.
3. Optimise and place them under `web/public/img/guides/pi/` (1x and 2x, as the existing guide art is), wire each into its guide, and give each real alt text.

Rules for the images:

- **Illustrations, not diagrams.** A generated image must not carry technical detail a reader would rely on: no text or labels inside the image, no pin numbers, no exact port positions. The guides' interactive SVGs carry the facts. A Raspberry Pi in an image may be stylised; it must not be mistaken for a reference drawing.
- No logos or trademarks (no Raspberry Pi raspberry logo, no Volumio, Spotify or Apple marks).
- Self-contained: files served from the site, nothing from a CDN (AGENTS.md §9).
- Keep each file small (target under ~150 KB at 2x; PNG or WebP, whichever is smaller for the image).
- Never launch a browser to check them (AGENTS.md §8). Look at the files directly.

## Acceptance criteria

1. `docs/guide-image-prompts-pi.md` exists with the seven prompts and the style block, and is linked from `docs/README.md`.
2. Seven images, 1x and 2x, under `web/public/img/guides/pi/`, each shown in its guide with alt text.
3. The work log records the Codex command and model, and which images needed a re-roll and why.
4. `ISSUE=0722 scripts/check.sh` passes, plus `internal/guides`, `internal/seo` and `cmd/opencircuit`.
