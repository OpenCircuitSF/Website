## Description

> Renumbered on 2026-11-18 from `#0698`, and rewritten the same day: the first version invented a new in-page illustration process. "Like we have done before" is `#0709`'s process, below.

The user asked for the first batch of Raspberry Pi guides (`#0719`, `#0720`, `#0721`) to get images generated by Codex "like we have done before". That is `#0709` (`96b04a45`): one **unfurl image** per guide, generated with the Codex CLI from `assets/og/guides/PROMPTS.md`, saved as `internal/seo/cardassets/guides/<slug>.png`, and served as the guide's `og:image` and Bluesky thumbnail. All 43 guides before this batch have one.

The three guide issues each add their guides' `### <slug>` sections to `PROMPTS.md` (the `#0709` guard requires a section for every catalog guide). This issue generates the seven images once those three are merged:

`pi-imager-setup`, `pi-wifi-2-4ghz`, `pi-bookworm-changes`, `pi-undervoltage`, `pi-sd-card-corruption`, `pi-volumio-streaming`, `pi-rgb-matrix-flicker`.

Follow `PROMPTS.md`'s "How to use this file" exactly: the STYLE block plus each guide's prompt, then centre-crop to exactly 1200×630 PNG, compress with `pngquant --quality 65-90`, under 1,000,000 bytes, saved at the Output path. Check each prompt first: the style says no text, logos or trademarks (no Raspberry Pi logo; no Volumio, Spotify or Apple marks), and the subject in the middle band.

## Acceptance criteria

1. Seven PNGs at `internal/seo/cardassets/guides/<slug>.png`, 1200×630, each under 1,000,000 bytes.
2. Each looked at directly (not in a browser, AGENTS.md §8) at full size and about 400 px wide; any regenerated, with the reason, in the work log.
3. The work log records the exact Codex command and model.
4. `ISSUE=0722 scripts/check.sh go ./internal/seo/... ./cmd/opencircuit/...` passes.
