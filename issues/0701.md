| Tool | Method, path | Scope | Flags |
|---|---|---|---|
| `schedule_outreach_wave` | POST `/api/v1/events/{id}/outreach/schedule` | outreach:write | **PUBLIC** (the wave posts at that time) |
| `unschedule_outreach_wave` | POST `/api/v1/events/{id}/outreach/unschedule` | outreach:write | — |
| `send_outreach_post` | POST `/api/v1/outreach-posts/{id}/send` | outreach:write | **PUBLIC** (posts now) |
| `mark_outreach_post_posted` | POST `/api/v1/outreach-posts/{id}/posted` | outreach:write | — (records a hand post) |
| `unmark_outreach_post_posted` | POST `/api/v1/outreach-posts/{id}/unmark` | outreach:write | — |
| `takedown_outreach_post` | POST `/api/v1/outreach-posts/{id}/takedown` | outreach:write | **PUBLIC + DESTRUCTIVE** (deletes the remote post) |

The schedule output lists `left_alone` (posted, posting now, not connected), the same as the admin. The time window rule is the same as for guide posts.

**Tests:** a fake publisher; send on an unconnected channel gives 409 or 503 as the admin does; takedown is retry-safe (its key is derived per post, per `outreach/takedown.go`); the PUBLIC/DESTRUCTIVE prefixes are present.
