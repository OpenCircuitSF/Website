## Description

Second-batch Raspberry Pi guides. **Read `#0723`'s description first**: it carries the shared rules (no new set, `demoLoaders.ts`, `PROMPTS.md` sections, counts, links inside demos, the pattern in `#0719`–`#0721`).

Guides in this issue:

- `pi-wifi-dropouts` — a Pi that joins WiFi and then drops off. Band support is `pi-wifi-2-4ghz`'s job; this covers a network the Pi *can* see: WiFi power saving (check with `iw wlan0 get power_save`; turn it off with NetworkManager, `nmcli connection modify <name> 802-11-wireless.powersave 2`), weak signal (the Zero's small antenna, metal cases), the address changing (use `hostname.local` or a DHCP reservation; link `pi-find-on-network`), under-voltage (link `pi-undervoltage`), and router band steering. Demo: a diagnosis flow, as in `esp32-c3-wont-upload`: answer a few questions and get the likely cause and fix.
- `pi-run-on-boot` — start a program on boot with a systemd service and restart it when it crashes: a unit file (`[Unit]` Description, `After=`/`Wants=network-online.target`; `[Service]` `ExecStart` with an absolute path, `WorkingDirectory`, `User`, `Restart=on-failure`, `RestartSec`; `[Install]` `WantedBy=multi-user.target`), `sudo systemctl enable --now`, `systemctl status`, `journalctl -u <name> -f`; why not `rc.local` or `cron @reboot`. Demo: build the service file one line at a time; turn a line off and see the failure it causes (relative path → not found; no `Restart` → stays dead after a crash; no network wait → fails on boot; no `[Install]` → doesn't start at boot).
- `pi-backup-sd-card` — copy the whole SD card before changing anything: on a Mac with `diskutil list` and `sudo dd if=/dev/rdiskN of=pi.img bs=4m` (then compress), on Linux with `lsblk` and `dd`, on the Pi desktop with SD Card Copier; restore with Raspberry Pi Imager's "Use custom". The danger is choosing the wrong disk or swapping `if` and `of`. Demo: a disk list with the SD card and the laptop's own disk; build the `dd` command by picking source and destination, and see a clear warning when it would overwrite the wrong disk. Never present a command that writes to a disk without a bold warning.
