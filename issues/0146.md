# 0146 — A cleared workshop capacity comes back, because `null` and "absent" are the same value on the wire

## Description

`#0139` made every optional **string** field clearable by sending an explicit `""`. `capacity` cannot be fixed that way: it is `*int` on the wire, and JSON `null` and an absent key both decode to Go `nil`. `patchWorkshopRequest`'s merge is `if req.Capacity != nil { … }`, so there is no client-sendable value that means "clear it".

Symptom, from the admin's side: clear the capacity box, save, reload — the old number is back, with no error and no indication anything was ignored.

This is the same defect `#0139` fixed for strings, surviving in the one field whose type cannot express the distinction.

## Acceptance criteria

- [ ] `capacity` can be cleared. Pick a wire representation that distinguishes "clear" from "unchanged" — a `json.RawMessage`, a wrapper type with an `explicitly set` flag, a `**int`, or a sentinel — and say why the chosen one fits this codebase
- [ ] "Unchanged" still means unchanged: a PATCH that never mentions `capacity` leaves it alone. Prove it, the way `#0139`'s review proved the string case, by mutating the guard and watching a test fail
- [ ] The admin UI actually sends the clear when the box is emptied
- [ ] An end-to-end test reads the value back from the **database**, not the response body, for both clear and leave-alone
- [ ] Check whether any other non-string optional field has the same shape and fix them together if so
- [ ] `ISSUE=0146 scripts/check.sh go ./internal/...` and `scripts/check.sh web` both pass

## Notes

Scoped out of `#0139` deliberately by its implementer and confirmed out of scope by its reviewer, both noting it needs a Go-side wire-type change that `#0052`'s original finding never named.

Worth deciding rather than defaulting: the `**int`-style trick works but reads badly, and a small `Optional[T]` wrapper would serve every future field of this shape. This is the second time the codebase has needed the three-state distinction, so the general fix may now be cheaper than the specific one.
