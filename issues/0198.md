## Description

`#0193` unified the two guards' `PRD §` whitespace handling, and its phase-3
review proved the result exhaustively: sweeping U+0000–U+10FFFF in both real
engines, the Go class, the web class, and V8's native `\s` are **the same
25-codepoint set**, with no disagreement in any direction.

But they are equivalent in *meaning*, not in *text*. Go spells `\x{00A0}` and
`[0-9]{3}`; web spells ` ` and `\d{3}`. Both divergences are proven
cosmetic today — and **nothing keeps them in step**. Editing one guard's
character class would not fail the other guard's tests, so the next change to
either can silently re-open the divergence `#0193` just closed.

The coupling is currently conventional (two files that happen to agree) where it
should be structural (one source of truth, or a test that fails when they drift).

That matters because the divergence `#0193` fixed was itself invisible for as
long as it existed: `PRD\s*§` looked identical in both files and meant different
things, and it took a reviewer extracting both patterns and running a 38-case
battery to notice.

## Acceptance criteria

- [ ] A test fails when the two guards' patterns cease to accept the same set of codepoints — driven by comparing behaviour, not by comparing pattern text
- [ ] The comparison runs in both real engines, not against a transcription of either
- [ ] Editing one guard's whitespace class without editing the other makes that test fail — demonstrated by mutation
- [ ] Whatever form is chosen, the guards still pass with zero changes to their current matching behaviour
- [ ] `#0187`'s 34-case matrix and `#0193`'s 17 whitespace shapes still hold
- [ ] `ISSUE=0198 scripts/check.sh go ./internal/...` and `scripts/check.sh web` both pass

## Notes

Reported by `#0193`'s phase-3 review under `CLAUDE.md` §9.

The hard part is that the two halves run in different languages, so "one source
of truth" means either generating one from the other or asserting agreement from
a shared fixture list. A shared codepoint list that both suites read and assert
against is the smaller change and probably the right one.

Read `#0193`'s `## Review notes` first — the exhaustive sweep and its
near-miss set (U+0085, U+00AD, U+180E, U+200B–U+200D, U+2060, U+2064, U+3164,
U+FFFC) are the fixture list, already derived. U+180E is the one worth keeping:
it was `Zs` before Unicode 6.3, so it is the plausible drift if either engine's
version moves.

`CLAUDE.md` §8's three invisible-character entries apply directly to any work in
these files.

A separate optional tightening, also deferred twice and still standing: the
consumed-boundary form `(?:^|[^:/\w])docs/\S*\.md|(?:^|[^:/\w])issues/[0-9]{4}\.md`
would close the accepted `docs/*.md` external-URL false positive and is valid
verbatim in both engines. It is a judgement call, not a defect — see `#0187` and
`#0193`.
