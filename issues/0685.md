## Description

These are follow-ups from `#0679`'s review.

1. **No idempotency for MCP writes.** REST creates accept `Idempotency-Key`, but MCP tool calls have no equivalent. An agent that retries `create_guide_posts` or `create_event` after a timeout can create duplicates. One option is an optional `idempotency_key` argument on create tools, mapped onto the same store (`#0675`, `#0684`). Another is to have the tool description tell agents to check with `list_*` before retrying.
2. **No cancellation policy.** `PropagateRequestCancellation` is unset, so a tool call keeps running after the client disconnects. For `send_guide_post`, finishing the send is probably the right behaviour. Decide this per operation and document it.
