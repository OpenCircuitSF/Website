## Description

`scripts/check.sh`'s repo-wide `gofmt -l .` step fails on
`internal/db/issue_citation_guard_test.go`. The defect is one misaligned
end-of-line comment in a table of test cases: a row whose comment sits at the
natural single-space position inside a run of rows whose comments gofmt aligns
to a much wider column.

The fix is whitespace only. No identifier, no string literal, no assertion and
no comment *text* changes — `gofmt -d` shows a single row moving its `//` out
to the column its neighbours already use.

## How it was found

Reported by `#0058`'s implementation pass, which hit it on an ordinary
`ISSUE=0058 scripts/check.sh` run and correctly declined to fix it as
out-of-scope, reporting it instead (`CLAUDE.md` §9). Attribution was then
confirmed independently: `git log` puts the last touch on this file at
`f22e940` (`#0268`, third pass, 2026-09-09), and the file was clean in the
working tree, so this is committed state rather than an artifact of concurrent
work.

## Why this matters more than a whitespace fix normally would

`CLAUDE.md` §5a records the same failure shape for
`scripts/go_file_visit_floor_guard_test.sh`: two floor constants sat below
their own margin, `HEAD` was red for days, and four agents ran the guard
directly while reading only its `PASS` lines. The lesson recorded there is that
**a guard nobody acts on catches nothing**.

This is that lesson's sibling, one step further along: the guard *is* wired
into an ordinary run and *is* failing, and the failure has been surviving
anyway — every agent that has run `scripts/check.sh` since `#0268` landed has
had this in its output. It is benign in content and costly in effect, because a
red `HEAD` trains readers to skim past a failing step, which is exactly how a
real defect gets missed.

## Acceptance criteria

1. `gofmt -w internal/db/issue_citation_guard_test.go`, and nothing else.
   Confirm with `gofmt -d` beforehand that the change is whitespace only.
2. `gofmt -l .` reports **no files** repo-wide afterwards.
3. Confirm the file was not dirty from another agent before writing
   (`CLAUDE.md` §8a — a bulk formatter is the dangerous shape; this is a single
   named file, but check anyway).
4. The guard's own tests still pass: `ISSUE=0497 scripts/check.sh go ./internal/db/...`.
5. **Do not** reflow, re-sort or otherwise tidy the surrounding table. The rows
   and their comments are `#0268`'s corpus accounting; only the formatter's
   column alignment changes.
