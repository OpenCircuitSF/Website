## Description

Non-blocking findings from the reviews of `#0695`'s children, collected in one place. None blocks the deploy.

**Behaviour**
1. `#0701`: a refused takedown on v1 returns the network client's raw error text, against `api.AsError`'s rule that underlying error text stays out of v1 responses. Map it to a reason code, the way `linkFailureReason` does.
2. `#0705`: the upload ticket is used up before the body is checked, so a HEIC, oversize or corrupt upload burns it and the agent has to mint another. Consume the ticket only after `storeImage` succeeds (still single use on success).
3. `#0705`: the v1 upload route is outside the failed-auth limiter. Low risk at the ticket's entropy; add it for consistency.
4. `#0704`: the admin guide view doesn't show guide-post likes/reposts/replies yet (optional in `#0704`'s plan).
5. `scripts/check.sh`: the `gofmt -l` step reaches into `.claude/worktrees/`, so another agent's worktree mid-rebase fails an unrelated run. Skip that directory.
10. `#0706`: a guide-post store that doesn't implement the engagement reader returns zero silently. Add `var _ guidePostEngagementReader = (*guideposts.Store)(nil)` or fail loudly in `guideRows`.
11. `#0706`: `eventRows` calls `resultsFor` per workshop and discards flyer data; a narrower helper would be cheaper.
12. `#0703`: `isSafeCoverImage` and the flyer-photo check accept `/media/../admin` (same-site, admin too). Reject `..` segments.
13. `#0703`: a ShortLinks rate limit gives 503 with no `Retry-After` on v1 where the admin gives 429; this is `outreachAPIError`'s mapping, so it affects every v1 outreach link op. Return 429 with `Retry-After`.
14. `#0707`: name `OCSF_API_KEY` and `OCSF_SKIP_KEY_CHECK` in `scripts/mcp-connect.sh`'s header comment.

**Tests**
6. `#0705`: no test covers the 5 MiB cap on the v1 upload route.
7. `#0698`: no test adds a mention, so the Pacific conversion of mention times never runs. `TestV1OutreachResults_ForEvent` also ignores the error from `RecordEngagement`.
8. `#0702`: `TestV1OutreachLocations_RouterHasBothPaths` builds the full router but sends requests to a smaller one. Route them through the full router with `V1Deps{Outreach: e.h}`, check the not-found messages, and expect 200 from GET `/locations`.
9. `#0704`: `TestTracker_GuideSourceIsPolledAndRecorded`'s second-pass check (`len != 1`) also fires when nothing was captured; make it distinguish the two.
