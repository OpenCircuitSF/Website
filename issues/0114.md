# 0114 — The audit log cannot be filtered to a campaign, so a demoted campaign's recorded reason is unreachable

| | |
|---|---|
| **Status** | open |
| **Module** | admin / audit |
| **Platform** | All |
| **Phase** | 5 — Campaigns |
| **First seen** | 2026-08-21 |

## Description

`GET /admin/audit` filters only by `user_id`. `#0045`'s send worker writes a
`email_campaign.send_refused` row with a **NULL actor** — the worker is not a user —
so the one row explaining why a campaign was demoted from `scheduled` back to
`draft` cannot be filtered to by any means the admin UI offers.

## Acceptance criteria

- [ ] The audit list can be filtered by `target_type` and `target_id`, so a
      campaign's own history is reachable
- [ ] Rows with a NULL actor are reachable — a filter that implicitly requires
      a user excludes exactly the machine-written rows that most need reading
- [ ] `#0047`'s campaign screen can deep-link to the filtered view rather than
      linking to the audit tab unfiltered, which is its current workaround
- [ ] Tests cover a NULL-actor row and a `target_type`/`target_id` filter that
      returns it

> **Corrected 2026-08-21 from `#0041`'s review.** This issue originally named
> the action `campaign.send_refused`. The `campaign.*` prefix was retired when
> `#0068` deleted ShortLinks' campaign audit constants; `#0041` established the
> `email_campaign.*` namespace with `TargetEmailCampaign`. `#0045` must use
> `email_campaign.send_refused`, or the campaign audit trail splits across two
> namespaces and this issue's filter will not reach the refusal rows.

## Notes

Filed from `#0047`'s planning pass (2026-08-21), which found the gap while
designing how an operator discovers *why* a scheduled campaign came back as a
draft. `#0047` works around it by showing the current unmet-requirements list
as the actionable answer, which is the better primary answer anyway — but the
audit row is the durable record, and right now it is written and then
effectively lost.

Not urgent, and it does not block `#0045` or `#0047`. It matters the first time
someone has to explain a demotion after the fact.
