## Description

The last step in the handoff: after the public server (`#0729`) and its discovery pieces (`#0731`) are live, submit it to the official MCP registry (registry.modelcontextprotocol.io), then run the manual end-to-end check.

**Submitting is outward-facing and publishes the listing.** It needs the user's go-ahead at the time, and may need their GitHub or DNS identity for namespace verification.

## Acceptance criteria

- [ ] Look up the registry's current submission process (publisher CLI, `server.json` schema, namespace verification by DNS or GitHub) and record it in `docs/` with the date checked. Follow the live docs; don't rely on this issue.
- [ ] Commit any required metadata file, for example `server.json`, generated from or checked against the public tool list so it does not drift.
- [ ] With the user's approval, submit the listing, then confirm it in the registry's API or UI and record the listing URL.
- [ ] Manual check on production: add the public server to Claude Code with no key, then ask "What Open Circuit SF events are coming up?" and "Is there an ESP32 workshop in December?" Record both answers in `## Verification`.
