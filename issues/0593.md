## Acceptance criteria

- [ ] **Settings (#0584):** `Admin.svelte` mounts `ServerSettings` twice
      (`scope="server"` and `scope="outreach"`) — one fetch, shared; the
      precedence note appears once. Add a test for the `?section=server` deep
      link.
- [ ] **Reset (#0592):** the "Outreach was reset…" note clears on the next
      state change instead of lingering until reload.
- [ ] **Flyers (#0589):** a collapsible preview thumbnail under 64rem (H2);
      submitting the location form with errors focuses the first invalid
      field; a flyer saved with no photo and no locations does not get
      new-flyer defaults re-applied on reopen (track "new" explicitly); the
      §4.4 "More" disclosure (description, title position, copies).
- [ ] **Navigation (#0586):** `aria-label="Promote <title>"` / `"Open outreach
      for <title>"` on the Outreach list's row buttons; a "Past" section (or a
      link from Results) for past workshops that had outreach; the Locations
      view's panel title reads "Flyer spots"; Dashboard uses
      `Promise.allSettled` so a failed connections call keeps the unannounced
      count.
- [ ] **Posting (#0581):** the native-confirm guard also catches
      `confirm(<identifier>)`.
- [ ] **Results (#0590):** `internal/devmocks` rollup honours the requested
      `from`/`to`; `ResultsSummary` replaces its per-workshop `ListPosts`
      (N+1) with one grouped query; `queued` posts appear in the posts cell
      ("1 posting").
- [ ] **Mastodon account (plan obstacle 3):** store the Mastodon
      `@user@host` from `verify_credentials` at connection test/reload so the
      post dialog names the account, not just the instance.
- [ ] **Announcement (#0582):** "Use shared message" also restores the
      channel's link/hashtag tail when the customized body lost it (or defer
      to `#0575`'s Adapt); a message ending in a hashtag-only paragraph stays
      editable in the Message field; show the stale-draft warning on the
      Announcement section, not only inside Customize…; delete the now-unused
      `OutreachLinks.svelte` and its test.
- [ ] **Previews (#0583):** the panel sends the canonical card host
      (`BASE_URL`'s host) rather than the SPA using `location.host`; a
      server-side `thumb_ok` fact so the Bluesky preview drops the picture
      exactly when the publisher would (missing file, wrong type, over
      `MaxThumbBytes`).
- [ ] **Scheduling (#0587):** drop the Schedule all dialog's dead
      "Announce is always chosen" branch; let a row skipped as `time_passed`
      be rescued with a per-row time in the dialog.
- [ ] Verified with `ISSUE=0593 scripts/check.sh web` and the Go packages
      touched, zero skips; jsdom evidence stated as such.
