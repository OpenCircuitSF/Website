## Description

After `#0519`, a slow page load shows the server fallback content, then `App.svelte`'s `Loading…` state while `/api/me` answers, then the real page. `#0519`'s plan records this flash rather than hiding it.

## Acceptance criteria

1. On public routes, the server content stays visible until the SPA can render the route, with no intermediate `Loading…` screen.
2. Admin and account routes, which genuinely need `/api/me`, keep correct gating.
3. No duplicated content and exactly one `<h1>` at every stage (`#0519` criterion 4).
4. Verified in a real browser with a throttled network, not only jsdom.
5. `scripts/check.sh web` passes.
