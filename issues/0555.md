# 0555 — A Bluesky mention containing a NUL byte stalls Bluesky mention collection

| | |
|---|---|

## Description

From `#0547`'s review. JSON allows an escaped NUL (`\u0000`) in a post's
text; Postgres rejects NUL in `text` columns ("null character not
permitted"). `InsertMention` fails on that item, the Bluesky walk stops there
every pass, its high-water mark never advances, and once the item ages past
the 10-page cap older mentions on those pages are skipped. Mastodon is not
affected (its HTML-to-text step drops NUL).

## Acceptance criteria

- [ ] `bskyMention` (`internal/outreach/tracker.go`) strips NUL from `Text` and `Author` (and any other stored string from the payload); a `TestBskyMention` case proves it.
- [ ] A test walks 10 full Bluesky pages and asserts the cap's Warn log line; another serves a full 80-item Mastodon page followed by a second page and asserts the same.
