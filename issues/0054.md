## Description

`/workshops/{slug}` — the page a social link points at for a specific session.

- [ ] External `signup_url` surfaced as a primary action when present

## Notes

PRD §7.3, §7.4. The pre-checked subscribe form is the conversion path that makes this page worth building — someone reading about a soldering workshop should get "Soldering & Assembly" already ticked.

This is the route whose meta tags matter most, since individual workshop links are what get posted to social.

## Carried in from `#0014`'s review (2026-08-18)

- [ ] **Reserve final height before paint, or re-apply the scroll offset once
      the fetch settles.** The router restores scroll after a single
      `await tick()`. That suffices only because every current view renders
      synchronously from the bundle. A view that fetches its own content is
      still short when `tick()` resolves, so the restore clamps against a
      document that has not grown yet and Back silently lands at the top.
      `/workshops/:slug` is the first route that will fetch, so it is the first
      that will hit this.
