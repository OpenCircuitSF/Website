## Description

Brennan's instruction, 2026-10-17: "Add the rule to CLAUDE.md and rename it to
AGENTS.md to use going forward."

Two parts.

1. **The rule.** During `#0549` an agent launched Chrome for Testing on the
   host with a fresh profile per run, which flooded Brennan's screen with
   permission windows. The rule that came out of it: never launch a browser on
   the host; browser checks run in a disposable Tart VM with Safari and
   WebDriver.
2. **The rename.** `AGENTS.md` becomes the authoritative agent-guidance file.
   Claude Code loads `CLAUDE.md`, not `AGENTS.md`, so `CLAUDE.md` stays as a
   stub that imports it.
