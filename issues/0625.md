## Description

Announcement is always expanded above two accordion rows, and any number of sections can be open at once. Reviewing one wave means scrolling past the others.

## Acceptance criteria

- [ ] Announce is a row like Reminder and Final, and exactly one wave is open at a time.
- [ ] Selecting a board row opens that wave and brings it into view.
- [ ] By default, the first wave that is not fully posted is open.
- [ ] An unsaved message edit is not lost silently when switching waves.
- [ ] Keyboard and screen-reader use of the wave rows and board are covered by tests.
