## Description

**Low priority, and deliberately so — fold this into the next touch of the file
rather than spinning up a pass for it.** `#0459`'s second reviewer said as much
when it reported these, and it was right.

Two comments in `internal/handlers/migration_citation_content_guard_test.go`
record measurements that have since moved:

1. The **floor constants' doc comment** parenthesises the corpus as **74**
   citations. The tree reports **73** — falsified by `#0459`'s own second
   commit, which deleted a dead branch whose doc comment self-cited a migration
   twice. The floors themselves (40 and 15) are unaffected.
2. The **forward-window bullet's file list** is a pre-deletion snapshot. Its
   direction and magnitude still hold — `#0459`'s reviewer independently
   reproduced 21 extra checks and 5 false positives — but one of the named
   locations is now a different file, since two of the original five were that
   guard's own deleted comments.

## Why it is worth recording at all

This is the same class `#0456` and `#0459` are about: a comment asserting a
measured fact that has stopped being true. Both are explicitly labelled as
"while writing this guard" snapshots, which is honest and is why neither was a
bounce — but a snapshot that is silently wrong still costs the next reader a
re-derivation to discover it was only nearly right.

## Acceptance criteria

1. The floor comment's parenthetical matches what the tree reports. **Re-derive
   the count** rather than writing 73 from this issue — `#0459`'s review
   recorded that the harness's own file is inside the scan roots, so a
   measurement taken with a temporary same-package file reads one higher than
   the tree's own figure. That subtlety is exactly how a corrected number goes
   wrong again.
2. The forward-window bullet's file list reflects the current tree.
3. **Do not change the floors** (40 and 15) or any of the three load-bearing
   extraction parts — clause bounding, negation markers, and the field-name
   conversion path. `#0459`'s two reviews verified all of it, and its second
   bounce was for adding machinery that could not execute.
4. **No new mechanism** (§8, `#0258`). Comment text only.
5. If you are here for another reason and these are merely nearby, fix them and
   say so; if this is the whole task, keep it to one commit.
