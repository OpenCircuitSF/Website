## Description

`#0537` relocated `release.sh`/`deploy.sh`'s disposable worktrees into
gitignored `.scratch/` per the operator's 2026-09-13 directive that all writes
stay inside the repository. Three shell guard harnesses still `mktemp -d`
under system TMPDIR for their own mutation copies:

- `scripts/check_guard_test.sh`
- `scripts/go_file_visit_floor_guard_test.sh`
- `scripts/deploy_guard_test.sh`

Same defect `#0537` fixed, one layer out — and these run on every
`scripts/check.sh guards` / `go`-arm invocation, so they are the most
frequently executed offenders.

## Acceptance criteria

- [ ] All three harnesses create their mutation copies and scratch under `.scratch/` inside the repository
- [ ] Cleanup semantics preserved: mutation copies removed on success AND failure paths; a failed run must not leave residue in `.scratch/` any more than it did in TMPDIR
- [ ] `scripts/check.sh guards` passes; each guard still proves discrimination (mutation actually flips its verdict — verify one by hand)
- [ ] `bash -n` + `shellcheck` clean on all three
- [ ] No assertion weakened; if a harness pins its tmpdir location, the pin moves with it and the change is noted

## Relation

- Follows [#0537](0537.md) — same directive applied to the remaining
  shell-layer offenders the #0537 pass identified but left out of scope
- Operator directive 2026-09-13: all writes stay inside the repo without
  explicit permission; `.scratch/` is the sanctioned scratch location
