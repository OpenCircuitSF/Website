## Description

`docs/seo.md` opens:

> Not yet implemented — lands with the public marketing pages (Phase 2) and
> is refined in Phase 7. This is a stub with real headings pending that
> work; `PRD.md` §7.4 is authoritative

`internal/seo` has been fully built for many issues now — per-route meta
injection, the workshop source, Event JSON-LD, the sitemap, `robots.txt`, the
archive integration, the invalidator seams, and most recently `#0273`'s
server-side per-workshop Open Graph card. `#0273` itself added 56 lines to this
file **underneath a heading still declaring the subsystem unbuilt.**

The file is 115 lines. It is not empty — it is a stub that grew, so a reader is
told the subsystem does not exist and then handed real detail about it.

**Reported independently by both `#0273`'s implementation pass and its review.**

## Why this is worth doing rather than deleting the sentence

The header is the visible symptom; the underlying question is whether the file
still describes the system. Several issues have landed in `internal/seo` since
the stub was written (`#0019`, `#0054`, `#0055`, `#0135`, `#0141`, `#0153`,
`#0318`, `#0319`, `#0325`, `#0337`, `#0273`), and a stub that accreted sections
issue by issue is likely to be inconsistent in more than its heading.

Note the same class of drift has cost real time this session: `#0407` (a range
in `CLAUDE.md` that was true when written), `#0414` and `#0418` (runbooks naming
an address and a region production does not use).

## Acceptance criteria

1. The "Not yet implemented" framing is gone, and the file describes the
   subsystem as it actually exists.
2. **Verify each factual claim against the code** rather than editing around the
   header. Nine issues this phase bounced for prose claiming more than the code
   delivers; a rewrite that inherits stale detail is the same failure.
3. `PRD.md` §7.4 is cited as authoritative — check that it still is, and that it
   itself is accurate. If §7.4 has drifted too, say so rather than deferring to
   something wrong.
4. Cover what exists today, at minimum: per-route meta injection, the workshop
   and archive sources, Event JSON-LD, the sitemap and `robots.txt`, cache
   invalidation, and `#0273`'s card generation with its Pacific-time and
   canceled-workshop rules.
5. **Record the limits that are deliberate**, not just the features: `#0153`'s
   no-upload decision, `#0135`'s canceled-workshop fallback, and `#0273`'s
   `og:type: website` decision with its reasoning. A doc that lists only
   capabilities invites someone to "fix" a deliberate choice.
6. **No mechanism** (`#0330`/`#0347`/`#0356`/`#0381`) — this is prose.
7. Run `./internal/seo/...`, `./internal/db/...` and `./internal/handlers/...`
   (§5's repo-wide-guard table; the citation guards resolve paths named in Go
   comments, and `docs/seo.md` is a citation target). Per §5 name the specific
   tests that ran. No Go-file-plus-line-number citation (`#0352`), scanned with
   `python3` bytes rather than BSD `grep -P`.
