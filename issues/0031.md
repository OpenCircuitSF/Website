## Description

Token-authenticated page where a subscriber manages their interests or leaves entirely, reached from every email footer.

## Acceptance criteria

- [ ] `GET /api/preferences?token=` returns the subscriber's interests and the full active interest list
- [ ] Email is masked (`b•••••n@gmail.com`) unless the token was just issued by a confirm
- [ ] `PATCH /api/preferences` replaces the interest set
- [ ] An empty selection keeps the subscriber `active` on general announcements only, and the UI says so explicitly
- [ ] A separate, clearly labelled "Unsubscribe from everything" action is present alongside
- [ ] Invalid or rotated tokens render a neutral page offering to re-subscribe — never a raw 404
- [ ] Changes are saved with visible confirmation and an audit row
- [ ] Handler and component tests pass

## Notes

PRD §6.4. "Uncheck everything" is how a lot of people *try* to unsubscribe. Silently leaving them subscribed is a complaint waiting to happen, so the empty state must state plainly what it means and the real unsubscribe action must be equally prominent.

Granular management measurably reduces full unsubscribes — someone tired of homelab posts drops one interest instead of leaving the list.

The email mask exists because these URLs end up in browser history and shared screenshots.
