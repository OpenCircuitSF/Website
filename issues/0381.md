## Description

Several guards in this family **scan the whole tree from a package other than
the one being edited**. `#0356`'s `TestNoCommentCitesGoFileByLineNumber` lives
in `internal/handlers` and scans every Go comment in the repo.

So `ISSUE=NNNN scripts/check.sh go ./internal/outbox/...` — a correctly scoped
run under §5a — **cannot see a violation an `internal/outbox` edit introduces.**

**This left HEAD red for roughly 18 minutes.** `be1f08d` added 61 comment lines
to `internal/outbox/claim_comment_referent_guard_test.go` recording two guard
limits (`#0374`, `#0375`). Two of them cited `store.go:463` and
`internal/mailing/outbox_worker.go:475` by line number. The implementer's scoped
run passed; `#0376`'s reviewer found the failure while verifying an unrelated
diff in `internal/handlers`.

**The irony is the point**: the records were doc comments *about a guard*, and
they violated the rule `#0352` and `#0356` settled — replace a line citation
with a stable identifier, never a corrected number.

**And the citation was already wrong.** `#0365`'s work moved that site from line
475 to line **517** within the hour, which `#0374`/`#0375`'s reviewer noted as
empirical vindication.

## Acceptance criteria

1. Record, where an agent choosing a verification scope will meet it — CLAUDE.md
   §5, and/or each repo-wide guard's own doc comment — that **an edit to a file
   within a repo-wide guard's scan roots must also run that guard's owning
   package**.
2. **Name which packages own repo-wide guards**, measured rather than assumed.
   `#0356`'s line-citation guard in `internal/handlers` is one; enumerate the
   rest by finding the guards whose scan roots extend beyond their own package.
   Report the list.
3. **Do not build a mechanism** unless the enumeration shows it is warranted.
   §8's `#0258` case is six passes of adding checks, and `#0330`, `#0347` and
   `#0356` each ended by recording a limit rather than closing it. A sentence in
   §5 naming the owning packages may be the whole deliverable — if you think it
   is, say so and stop.
4. If you do consider a mechanism, weigh the obvious one honestly: making
   `scripts/check.sh` always include repo-wide guard packages would slow every
   scoped run, and §5a's whole point is that scoped runs are the default. Say
   what it would cost.
5. Any figure or file path you state is **re-measured**, not transcribed —
   **seven unsupported details reached issues this phase**, several written by
   the orchestrator.
6. Documentation only unless criterion 3's exception applies. `gofmt` stability
   if any Go file is touched.
