## Description

`#0519`'s first slice omits a workshop's external sign-up URL from the server HTML, because the URL safety check that governs it (`#0152`) is enforced in the SPA and at the API boundary but has no reusable Go helper for rendering.

## Acceptance criteria

1. A published workshop's raw HTML includes its sign-up link when one is set.
2. The link passes the same validation the API applies (`#0152`); an invalid or protocol-relative URL is never rendered.
3. Rendered with `rel` attributes consistent with the SPA's own external links.
4. `ISSUE=NNNN scripts/check.sh go ./internal/seo/... ./internal/workshops/...` passes.
