## Description

Brennan, 2026-10-17, on the `#0570` drafts and the `#0569` cards:

> I feel like you can drop the time. It feels too technical with it. Anyone
> who is interested can click the link to see the time. You can simply
> include the summary from the workshop.
>
> I also see when I open the editor for the content it appears below which
> is confusing. It should replace the content which is being displayed with
> the editor, basically toggling between display and edit mode.

## Acceptance criteria

- [ ] **No clock time in any draft.** For every channel and wave in
      `internal/outreach/templates.go`, the generated text no longer contains
      the start time (for example "at 6:30 PM"). Keep the weekday and date
      ("on Monday, Oct 19"), and the venue, in a short natural opening
      sentence, then the workshop summary, then the call to action and link
      where the channel has one, then the hashtags. Reminder and Last call
      use relative wording without a clock time ("this Monday", "tomorrow").
      `TestDraftGolden` is updated, and a test asserts that no draft for any
      channel × wave contains a time pattern such as `\d{1,2}:\d{2}`. The
      `Fingerprint` and stale logic stay correct.
- [ ] **Edit toggles in place.** On `OutreachPostCards.svelte`, pressing
      **Edit** replaces that card's display (text, link, status, actions)
      with the composer inside the same card. Save, Cancel or Close returns
      the card to display mode, showing the updated text. Only one card
      edits at a time; opening another closes the first, and unsaved changes
      ask before being discarded. Schedule… gets the same in-place
      behaviour. The composer gains a **Cancel** button if it has none.
      Focus moves into the composer on open and back to the card's Edit
      button on close.
- [ ] jsdom tests:
      - while editing, the card's display text is absent and the composer
        is present
      - Cancel restores the display
      - Save shows the new text
      - opening a second card closes the first
- [ ] Verified with `ISSUE=0579 scripts/check.sh` (Go and web) plus
      `ISSUE=0579 scripts/check.sh go ./internal/outreach/... ./internal/handlers/... ./internal/db/...`.
      Zero skips. The SPA evidence is jsdom only.

## Resolution

- Drafts: `draftParts` formats the date only ("Monday, Oct 19"); Last call
  reads "Tomorrow: ..." (Bluesky) and "..., tomorrow." (Mastodon). Reminder
  keeps "One week out" / "One week to go" plus the date. `TestDraftGolden`
  updated; `TestDraftsCarryNoClockTime` asserts no `\d{1,2}:\d{2}` or AM/PM in
  any channel x wave. `Fingerprint` untouched. Existing posts not rewritten.
- Cards: `OutreachPostCards.svelte` renders the composer in place of the
  card's display while editing (`openEditor`/`closeEditor`); Schedule... uses
  the same path. The composer gained optional `onClose` (Cancel button, and
  Save returns to display), `onDirtyChange` (confirm before discarding when
  another card opens or Cancel is pressed). Focus: textarea on open, the
  card's Edit button on close. OutreachPanel's use is unchanged.
