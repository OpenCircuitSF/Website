## Description

A static page covering who Open Circuit SF is, the philosophy behind the workshops, how venues work, and how to reach the group.

## Acceptance criteria

- [x] Sections: what the group is, how workshops run, venues, how to get involved, contact
- [x] Links to the Discord server and the contact address
- [x] Composed from the motif components — no bespoke one-off styling
- [x] Single `<h1>`, correct heading hierarchy
- [x] Copy explicitly states that Open Circuit SF hosts at varied locations and is not tied to a single venue

## Root cause

Feature build, not a bug fix — the page didn't exist yet.

## Fix

`web/src/views/About.svelte`: an intro `TerminalPanel` (`Prompt text="whoami"`
+ `<h1>About Open Circuit SF</h1>` + a short "what this is" paragraph
matching Home's), followed by four `<section>`s — "How workshops run"
(`StatusList` inside a `Panel`), "Venues", "Get involved" (Discord link +
mention of the forthcoming mailing list), and "Contact"
(`mailto:hello@opencircuitsf.com`) — each a `<h2>` plus a `Panel`. No
component is new; the page reuses `TerminalPanel`, `Prompt`, `StatusList`,
`Panel`, and `TraceDivider` exactly as Home does, per "composed from the
motif components — no bespoke one-off styling."

Copy provenance (per the issue's own instruction to flag rather than invent):
the "what this is" paragraph and the Discord URL are carried over verbatim
from `placeholder/index.html` (the validated reference). "Roughly monthly" in
the How-workshops-run list is sourced from PRD §4.1's own reference layout
example line (`[ OK ] monthly · beginners`), not invented for this issue.
Everything else — the exact phrasing of "Venues" and "Get involved" — is new
copy written for this issue, consistent with the established
venue-independence positioning but not sourced from any existing document.
**Flagged for the user**: nothing here asserts a specific cadence guarantee,
a named contact person, or any fact beyond what PRD §4.1/placeholder already
established; if the group has more specific practices, this copy should be
treated as a first draft, not final.

`App.svelte` renders `<About />` for `$currentRoute.name === 'about'`,
inside `#0017`'s header shell, the same pattern `#0015` established for Home.
