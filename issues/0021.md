## Description

A 1200×630 image in the terminal style, used as the fallback preview card for every route that has no image of its own.

## Acceptance criteria

- [ ] `og-default.png` at 1200×630 in `web/public/`
- [ ] Composed in the terminal language: dark ground, green prompt line, the group name in the display face, the logo mark
- [ ] Text remains legible at the ~500 px width most feeds render
- [ ] File under 300 KB
- [ ] Referenced as the default `og:image` by #0019's route table
- [ ] Rendered preview checked in at least two of: Discord, iMessage, Slack

## Notes

A first-pass version already exists at `placeholder/og-default.png`, set in Arial Black as a stand-in for Archivo and generated by a measured-layout script (text is fitted to the available width rather than positioned by eye). This issue replaces it once the real display face is available.

PRD §4.5, §7.4. Feeds downscale aggressively — anything smaller than roughly 40 px tall in the source will be unreadable in a timeline. Favor a few large words over a dense composition.
