## Description

Two minor defects in `cmd/opencircuit/servepostgres_seo_instance_guard_test.go`
(`cbb11a5`), both found by `#0326`'s review, neither live.

**1. The anti-vacuity floor is one too low.** The scan finds **4** site-shaped
consumer positions — `mountAndServe`'s parameter 34 is included — but
`knownConsumersAsOfWriting` is **3**. So a silent degradation from 4 consumers
to 3 passes the floor. The floor exists precisely to catch discovery quietly
losing a consumer (§8, and the `#0275`/`#0298` shape: a tree-walking guard that
visits nothing reports "no findings"), and at 3 it cannot catch the first such
loss.

**2. `interfaceIsInvalidateOnly`'s doc comment overstates what it checks.** It
says the interface has "no results", but the function only inspects parameters.
A method with a return value would pass a check the comment claims rejects it.

Neither is exploitable today: the guard's other assertions are sound, and
`#0326`'s review added four further mutations (including a synthetic fourth
consumer passed `nil`, caught with no edit to the guard) confirming the
mechanism works. These are margin and documentation defects, not failures.

## Acceptance criteria

1. `knownConsumersAsOfWriting` equals the **measured** consumer count, with the
   measurement method stated in its doc comment — re-measured, not copied from
   this issue.
2. A degradation from the real count to one below it FAILS. Prove it by
   mutation in a throwaway worktree, restored and hash-verified.
3. The floor's doc comment says what it is for — catching silent discovery loss
   — and what would legitimately change it.
4. `interfaceIsInvalidateOnly`'s doc comment matches what the function checks,
   or the function is extended to check results as the comment claims. State
   which was chosen and why.
5. If results are now checked, confirm the intended satisfiers still pass and
   re-run `#0326`'s seven mutation proofs.
6. `gofmt` stability proved: file sha256 equals sha256 of `gofmt` stdout (§8).
7. The guard still needs no built SPA — `#0326`'s review verified it passes in a
   fresh worktree with no `node_modules`. Keep that true.
