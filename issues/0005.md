## Description

`./scripts/dev.sh` must bring up the full site locally with no PostgreSQL, no migrations, and an auto-logged-in mock admin — the same one-command experience ShortLinks has. The `STORAGE=json` dev store needs rewiring to the new entity set.

## Acceptance criteria

- [ ] `./scripts/dev.sh` starts the Go API on `:8080` with `STORAGE=json` and Vite on `:5173`, and Ctrl-C stops both
- [ ] `./scripts/dev.sh --built` builds the SPA and serves the embedded production path on `:8080`
- [ ] Dev auto-login middleware still injects a session for the mock admin
- [ ] `internal/devstore/` implements the store interfaces that survive #0002 and is refused unless `STORAGE=json` is set
- [ ] Vite proxy prefixes updated to the routes this project actually serves (`/api`, `/auth`, `/account`, `/admin`) — `/u` removed
- [ ] `scripts/sim.sh` retained and pointed at the new port/URL for iOS Safari checks
- [ ] Dev-mode defaults documented in `docs/dev.md`

## Notes

PRD §3.1. The dev store gains subscriber/interest/campaign/workshop fakes incrementally as those phases land — here it only needs to cover users, sessions, credentials, settings, and audit.

`docs/dev.md` in ShortLinks is a good template; the iOS Simulator section is worth keeping since this site has a real mobile audience arriving from social apps.
