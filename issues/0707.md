## Description

Part of `#0695` (Agent API, part 2). Docs, skill, per-agent keys.

## Plan
- **`docs/api.md`:** a full section per new op, plus the media upload `curl` flow.
- **`docs/mcp.md`:** the tool table with PUBLIC/DESTRUCTIVE marks, and new workflows: "announce an event" (start, then draft all, then review, then schedule the Announce wave), "put up flyers", "add a cover image", and "how did last week's posts do?" (`get_post_performance`).
- **`docs/mcp.md`, new section "More than one agent on one machine":**
  - A user-scope `ocsf` entry in `~/.claude.json` is inherited by every Claude Code or Agent-SDK process run by that user, Buzz agents included.
  - A **local**-scope entry for an agent's working directory overrides it, so that agent can get its own key.
  - State plainly that an agent under `bypass-permissions` (Buzz) runs PUBLIC and DESTRUCTIVE tools with no human confirmation. The user chose full access for Buzz (2026-11-17), so describe the Read-only key as an option, not a recommendation.
  - Revoke a key per agent from Settings → API keys.
  - Never use **project** scope with a key: it writes the key into `.mcp.json`, which may be committed.
- **`scripts/mcp-connect.sh`:**
  - Add `--scope user|local` (default `user`) and `--dir <path>` for local. Run `claude mcp add --scope local` from that directory in a subshell.
  - Refuse `--scope project` with that reason.
  - Make the `claude mcp remove` call match the chosen scope.
  - Bash 3.2 only (AGENTS.md §8). Check with `bash -n` and `shellcheck`.
- **`.claude/skills/ocsf-ops/SKILL.md`:**
  - Extend house rule 1 to list the new PUBLIC and DESTRUCTIVE tools.
  - Add workflows for event outreach and engagement questions, and the cover-upload steps.
  - Note that waves are scheduled as a whole.
  - Keep it under ~150 lines.
- **`docs/README.md` index:** add a row if a new doc is added. None is planned.

- **From `#0696`'s review:** `docs/api.md` still says the Agent preset leaves out `engagement:read`, and its scope table lacks the four new scopes; `docs/mcp.md` still names the old button "Agent (all guide and event scopes)" (now "Agent (every scope)", plus a "Read-only" button).
