## Description

`#0187`'s phase-3 review found two robustness problems with the guard, distinct
from its pattern text.

**1. Adding `web/` to the walk made `filepath.WalkDir` descend into
`web/node_modules` and `web/dist`.** There is no `.go` under either today. But
an npm dependency shipping Go source would be parsed by the guard, and **a parse
failure there is a `t.Fatalf`** — so a routine dependency bump could take the
guard down, with a failure pointing at a vendored file nobody in this project
wrote. A two-line `SkipDir` closes it.

This is a consequence of `#0187`'s otherwise-correct widening, not an argument
against it.

**2. The shape matrix should be committed, not re-derived.** Three passes have
now each rebuilt, run, and **deleted** the same 20–34 case matrix proving the
guard catches the Svelte expression forms and misses the acceptable ones:
`#0181`'s pass-2 review, `#0187`'s implementation, and `#0187`'s review.

The evidence for the guard's most contested property therefore exists only as
prose in three sets of review notes, and each pass pays to reconstruct it. That
is the opposite of what a regression test is for. `#0187`'s review ran 34 cases
against the shipped code by temporarily re-exporting `scanSvelteSource`,
`scanTsSource`, and `citationPattern` — that harness is most of the work
already.

## Acceptance criteria

- [ ] The Go walk skips `web/node_modules` and `web/dist` (and any other vendored directory under a scanned root)
- [ ] A dependency shipping a `.go` file under `web/node_modules` does not fail the guard — demonstrated, not assumed
- [ ] The shape matrix is committed as a real test, running against the shipped `scanSvelteSource`/`scanTsSource`/`citationPattern` rather than a replica
- [ ] The committed matrix covers what `#0187`'s review ran: 4 bounce forms, 12 further Svelte shapes, 5 structural misses, 7 acceptable misses, 6 boundary checks
- [ ] Each acceptable miss carries a one-line note on **why** it is acceptable, so a future pass can tell a deliberate miss from a regression
- [ ] `ISSUE=0194 scripts/check.sh go ./internal/...` and `scripts/check.sh web` both pass

## Notes

Reported by `#0187`'s phase-3 review under `CLAUDE.md` §9.

Criterion 3 is the one with lasting value. The guard's whole purpose is to be
the thing nobody has to re-verify by hand, and it is currently the thing every
pass re-verifies by hand.

A minor point the same review recorded rather than filed, worth folding in if
the file is open anyway: `toRepoRelativePath`'s else branch assumes a `./`
prefix and would mangle a bare glob key. Vite emits none today — the review
measured 83 keys, exactly two prefix shapes.
