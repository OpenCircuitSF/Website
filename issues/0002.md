## Description

Delete every Go package that exists only to serve short links, along with the dependencies they pull in. The auth, config, db, audit, events, and middleware packages stay.

## Acceptance criteria

- [ ] Deleted: `internal/links/`, `internal/clicks/`, `internal/campaigns/`, `internal/filters/`, `internal/cache/`, `internal/qr/`
- [ ] Deleted from `internal/handlers/`: `redirect.go`, `links.go`, `campaigns.go`, `campaigns_export.go`, `url_filters.go`, `qr.go`, and their test files
- [ ] Route table in `cmd/opencircuit/main.go` no longer registers `/u/{key}`, `/api/links*`, `/api/campaigns*`, or `/admin/url-filters*`
- [ ] Dependencies dropped from `go.mod`: `gozxing`, `go-qrcode`, `ristretto`; `go mod tidy` run
- [ ] `internal/devstore/` reduced to the entities that survive (adapted further in #0005)
- [ ] `go build ./...`, `go vet ./...`, `go test ./...` all pass on the reduced tree

## Notes

PRD §3.2.

Keep `internal/events/` — the SSE broker is reused for live campaign send progress (#0048).

`internal/cache/` goes entirely: the Ristretto redirect cache and the filter rule cache both exist for a hot redirect path this project does not have. Do not preserve it "just in case".

ShortLinks' `campaigns` package groups short links; this project's `email_campaigns` is an unrelated concept that shares a word. Port none of it.
