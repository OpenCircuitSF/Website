## Description

**1. `#0172`'s defect, one layer down — in Go.** `#0172` removed tracker and `CLAUDE.md` citations from admin-facing copy, and both its sweep and its review read **`web/` only**. But `lib/preflight.ts` deliberately owns no code→message table: `parseUnmet` passes the **server's** `message` through untouched. That makes Go strings admin-facing copy, and three of them cite our internal documents:

- `internal/mailing/preflight.go:171` — "…**PRD §6.6** requires a monitored reply address…", rendered in the pre-send checks panel
- `internal/handlers/admin_subscribers.go:553` — "…and **CLAUDE.md §9** refuses to let unsubscribe touch a complained row…"
- `internal/handlers/admin_subscribers.go:728` — the same shape

An admin has read neither document. **CAN-SPAM §7704 in the same family is fine** — a statute is something they can look up; our PRD is not. The `EMAIL_REPLY_TO` / `EMAIL_LIST_DOMAIN` env names are defensible too, being deploy-time codes with no in-SPA affordance.

**2. `demotionExplanation` has no test.** It is not imported by any `*.test.ts`, despite having a real branch (`scheduled_at` present versus the `'an earlier time'` fallback) and being **the only explanation an admin gets for a campaign that was demoted back to draft**.

`#0175`'s review flagged this as the genuine test gap, while explicitly arguing the *opposite* for the physical-address hint: that one should **not** be pinned verbatim, because the refusal is already enforced in three places in Go, and `#0174` exists precisely because a phrase-match test masqueraded as a behavior guard.

## Acceptance criteria

- [ ] The three Go strings say what happened in the admin's terms, with the citation moved to a code comment beside the string
- [ ] The `complained` messages keep their force — `CLAUDE.md` §9 says a complained subscriber never auto-resubscribes and only an admin clears that state; the copy must not imply the refusal is incidental or bypassable
- [ ] **Sweep the Go side the way `web/` was swept**: find every string that reaches an admin through an API `message`/`error` field and read it. `#0172` swept `web/`; nobody has swept the strings Go authors
- [ ] `demotionExplanation` gets a semantic test covering both branches — asserting what the sentence *claims*, not one phrasing of it
- [ ] Decide whether any other `web/src/lib/` copy function reaching admins is untested, and say what you found
- [ ] `ISSUE=0178 scripts/check.sh go ./internal/...` and `scripts/check.sh web` both pass
