## Description

The only overview is the summary line in `OutreachWorkshop.svelte`, which gives counts. It cannot say what each channel does for each wave, or when.

## Acceptance criteria

- [ ] A status board replaces the summary line, with one row per wave and one column per enabled channel.
- [ ] Each cell states status in text and, where there is one, the date and time: posted, scheduled, draft, or post by hand.
- [ ] The board remains readable at phone width and does not rely on colour.
- [ ] Cell values come from a pure, unit-tested function in `web/src/lib/outreachCards.ts`.

## Notes

Five channels make the board wider than the review's sketch, so the plan must handle the narrow layout explicitly.
