## Resolution

- `ResultsForWorkshop`, `ResultsSummary`, `Timeline` and `Luma` now wrap transport-free cores (`resultsFor`, `resultsSummary`, `timeline`, `lumaReport`); `fillEngagement` returns an error instead of writing. Admin bodies are byte-for-byte the same shape (summary and timeline still emit the same keys).
- New `internal/handlers/v1_outreach_results.go`: `get_outreach_results`, `outreach_results_summary`, `outreach_timeline`, `outreach_luma`, all `outreach:read`; results, summary and Luma carry `MayBeUnavailable`. A ShortLinks failure is a `status` in the body, as in the admin. Every time is converted to Pacific (`resultsInPacific`, `mentionsInPacific`, `pacificPanel` for timeline events).
- Registered in `BuildV1Registry`; names added to `TestBuildV1RegistryListsOperations`, `specTools`, `docs/api.md`, `docs/mcp.md`.
