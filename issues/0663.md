# 0663 — Guide posts store the campaign EnsureCampaign returned, not the campaign the link actually sits in

## Description

From `#0658`'s review, low priority. `guideposts.Linker.Ensure` stores the campaign slug that `EnsureCampaign` returned, not the campaign the minted link actually belongs to. ShortLinks can suffix a campaign slug when two requests race to create it. If that happens, a retried mint can return a link from a different campaign, and that post's clicks would then be read under the wrong campaign.

Fixing it needs ShortLinks to report a link's campaign, which `shortlinks.Link` doesn't carry today. That change belongs in ShortLinks, which is a separate repo; this issue then adopts it.

## Acceptance criteria

- [ ] `Ensure` stores the campaign the link really belongs to, or refuses the link when it differs from the row's campaign. A test uses a fake whose campaign was suffixed.
