## Description

Two minor follow-ups from `#0690`'s review:

1. No test drives a resistor band in `ResistorBandsDemo.svelte` from the keyboard (Enter, ArrowUp, ArrowDown).
2. `LedResistorDemo.svelte`'s custom supply-voltage input accepts values above its `max="24"`; nothing clamps them before the calculation.

## Acceptance criteria

1. A jsdom test cycles a band with the keyboard and asserts the value changes.
2. The custom supply is clamped to the input's range (or shows an out-of-range message), with a test.
