## Description

Found in `#0623`'s review of `POST /admin/workshops/{id}/outreach/hand-links`. None blocks use, because the card's Draft button recovers a missing draft.

1. **Measured:** if the browser reloads or closes mid-pass, links can be left without their draft. Cancelling after the second create left 1 link and 0 drafts, and that slot is never drafted automatically afterward.
2. **Measured:** a draft made while its slot had no link, then deleted, returns on the pass that creates the link, because no record of the delete exists. Current production data cannot hit this; it needs a Draft click during a ShortLinks outage followed by a delete.
3. **Read in the code, not run:** two tabs opening at once could create one unused upstream link, because `idx_links_user_destination` in ShortLinks is not unique. The local slot still holds one link.

## Root cause

`EnsureHandLinks` ran on the request context, so a reload or closed tab cancelled it between making a slot's link and making its draft, stranding the slot.

## Fix

Per `#0638`'s plan (shared commit): the pass runs on `context.WithoutCancel`; `outreachLinksTimeout` still bounds ShortLinks calls. Item 2 (deleted draft returns once) and item 3 (upstream duplicate link from overlapping passes) are accepted and documented in `EnsureHandLinks`'s doc comment; the overlap test pins the local one-link/one-draft guarantee.

## Plan

Planned 2026-11-05 together with `#0638` and `#0629`. **The full plan, the tests, the verification and `## Obstacles` are in `issues/0638.md`.** In short:

1. **Fixed.** `EnsureHandLinks` runs its whole pass on `context.WithoutCancel(r.Context())`, so a reload or a closed tab can no longer leave a link without its draft. Test: `TestAdminOutreachHandLinks_ClientGoneMidPassStillDrafts`, which cancels the request after the second create.
2. **Accepted, with the reason in `EnsureHandLinks`'s doc comment.** A record of the delete would need a migration. The trigger needs a ShortLinks outage plus a Draft click plus a delete, and the result is one draft returning once.
3. **Documented, not fixed.** Locally each slot keeps one link and at most one draft. The upstream orphan has no clicks and shows nowhere, and the real fix is a unique index in ShortLinks, a separate repo. Test: `TestAdminOutreachHandLinks_OverlappingPassesMakeEachSlotOnce`.

- [ ] A committed test covers overlapping passes, where a throwaway one exists only in the review.
