## Description

Flyers go on the same neighborhood bulletin boards every time. Save them once
— name, short code, address, notes, active — so each flyer run can make one
tracked link per location. Design doc "Flyers → Locations"; mockup artboard 7
(https://claude.ai/artifact/4Ckwb6QmWYyfYyAEszAKa2).

## Acceptance criteria

- [ ] Migration for `outreach_locations`: `name`, `code` (unique, **short**: lowercase letters, digits and dashes, 2–16 chars), `address`, `notes`, `active`, timestamps. A code is immutable once any flyer link uses it.
- [ ] Admin CRUD endpoints with audit rows; deactivate rather than delete when a location has links.
- [ ] UI: Outreach tab → **Locations** sub-view (list with name/address/code/notes/status, add/edit form, code auto-suggested from the name). Validation logic in a tested `web/src/lib` module.
- [ ] Verified with `ISSUE=0548 scripts/check.sh`.
