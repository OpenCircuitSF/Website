## Description

Adding one column to `subscribers` requires four hand edits:

| Site | Kind | Failure if missed |
|---|---|---|
| `subscriberColumns` | list | — |
| `qualifiedSubscriberColumns` (`Store.List`'s JOIN-safe duplicate) | list | **runtime 500** |
| `scanSubscriber`'s `Scan` order | positional | runtime |
| the struct | fields | compile |

Three are positional, so a wrong-order addition fails at **runtime**, not at
compile time. And `qualifiedSubscriberColumns` is **the one with no by-name
test**.

**This already fired.** `#0312`'s implementer added `invite_resent_at`, missed
`qualifiedSubscriberColumns`, and 500'd the admin subscribers list. It was caught
by the existing suite and fixed, and the implementer disclosed it — but the
minimum fix leaves the duplication in place for the next column.

## Acceptance criteria

1. `qualifiedSubscriberColumns` is **derived** from `subscriberColumns` (by
   prefixing) **or** the two parsed identifier sequences are pinned against each
   other, so adding a column to one and not the other fails.
2. Prove it discriminates: add a column to `subscriberColumns` alone and confirm
   the check fails, naming what diverged. **A check that cannot fail pins
   nothing** — `#0354`, `#0358` and `#0363` each shipped exactly that this
   phase, and `#0364` exists because a passing assertion can pass for the wrong
   reason.
3. If you choose the pinning route rather than derivation, the oracle must not
   be **a copy of the answer stored next to the question** (§8). Derive both
   sequences from the source, do not transcribe either into a fixture.
4. Consider whether `scanSubscriber`'s positional order can be pinned the same
   way, and say explicitly whether you did or why not — a positional list that
   fails at runtime is the worse of the two hazards, even though it is not the
   one that fired.
5. **Do not over-build.** If derivation closes it in a few lines, stop there;
   `#0330`, `#0347` and `#0356` all ended with "record the limit rather than add
   another mechanism", and §8's `#0258` case is six passes of the opposite. If
   the sound fix needs more machinery than the defect costs, say so and stop.
6. `gofmt` stability; the floor harness stays **42 total / 12 non-exempt**
   (`#0323`); per §5 name the specific tests that ran.
