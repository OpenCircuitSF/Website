## Description

Swap ShortLinks' SES SMTP transport for the SES v2 API using the EC2 instance role, keeping the `Mailer` interface seam so tests can inject a recorder.

## Acceptance criteria

- [ ] `github.com/aws/aws-sdk-go-v2/service/sesv2` added; credentials resolved via the default chain (instance role in production)
- [ ] `Mailer` interface returns the SES `MessageId` alongside the error
- [ ] Every send specifies `SES_CONFIGURATION_SET` so event publishing is enabled
- [ ] Custom headers supported on the send path — `List-Unsubscribe`, `List-Unsubscribe-Post`, `List-Id` (used by #0035)
- [ ] `multipart/alternative` with both HTML and plain-text parts
- [ ] Retry with exponential backoff on `ThrottlingException`; other errors surface to the caller
- [ ] A recording mailer implementation captures messages for assertion in tests
- [ ] All static SMTP credential config removed
- [ ] `go test ./internal/mailing/...` passes, including a test asserting the configuration set is attached to every send

## Notes

PRD §6.6. Three reasons the API beats SMTP here: authentication via the instance role (no long-lived password in `/etc/opencircuit/config.env`), the returned `MessageId` (the join key for bounce and complaint events in #0038), and per-message configuration-set support.

Keep ShortLinks' `Mailer` interface shape — the seam that lets tests avoid the network is worth preserving verbatim.

A plain-text part is not optional. Text-only alternatives measurably improve inbox placement, and some recipients genuinely read mail that way.
