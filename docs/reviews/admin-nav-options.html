Admin navigation — four options

Companion to admin-nav-options.md. Every mockup shows the same state, Workshops → Outreach → Posts, at a desktop width and at 390px. Colours and spacing are the site's own tokens from app.css; the self-hosted fonts are not bundled, so this renders in the system fallbacks. Buttons marked ▾ or Menu toggle the mock menus and drawer.

Recommendation

Option A, with the shared information architecture (Overview · Workshops · Mailing list · System; Campaigns first in Mailing list; "Pending confirmations" and "Home screen" as labels), the Account/Admin pair folded into the header, and one chip style for Outreach's and Settings' sub-navs. It answers "organize by sections so they don't all have to be visible" literally, keeps the daily pair one click apart, changes no route and no layout, and reuses the two active styles the console already has. D's palette can be added later on top of the same tables if wanted. Details, costs and the issue plan are in the markdown note.
